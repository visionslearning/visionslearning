Q.1 (i)
Addition theorem for mutually exclusive events: P(A∪B) =
✔ Answer: P(A) + P(B)
Explanation Mutually exclusive: A∩B = φ → P(A∩B) = 0 P(A∪B) = P(A) + P(B) + 0 = P(A) + P(B)
Q.1 (ii)
Mean of a Poisson distribution equals:
✔ Answer: λ (the parameter)
Explanation For Poisson(λ): Mean = λ, Variance = λ, SD = √λ
Q.1 (iii)
The regression coefficient b_yx =
✔ Answer: (Σxy − nx̄ȳ)/(Σx² − nx̄²) = r·σy/σx
Explanation b_yx = r × (σy/σx) = slope of regression line y on x It measures: for unit increase in x, the average change in y

✔ Answer: may have an optimal (maximum or minimum) value
Explanation The optimal value of the objective function in a bounded feasible region always occurs at one of the corner (vertex) points Evaluated at ALL corner points; the best value is the optimal solution

Secular trend in time series refers to:
✔ Answer: long-term direction of movement in data over many years
Explanation Secular trend (T): the overall long-term tendency of data to increase, decrease or remain constant over a long period Estimated by: least squares method, moving averages, semi-average method
Q.1 (vi)
Fisher's ideal index is considered ideal because:
✔ Answer: it satisfies both time reversal and factor reversal tests
Explanation Time reversal test: P₀₁ × P₁₀ = 1 (reversing base and current year gives reciprocal) Factor reversal test: (price index × quantity index) = value ratio Fisher's (geometric mean of L and P) is the only index satisfying BOTH tests → "ideal"
Q.1 (vii)
For standard normal Z, P(Z < 0) =
✔ Answer: 0.5

Binomial distribution is symmetric when:
✔ Answer: p = 1/2 (p = q)
Explanation When p = q = 1/2, the binomial distribution is perfectly symmetric (skewness = 0) p < 1/2: right-skewed; p > 1/2: left-skewed

LPP farmer problem: max profit with crop A and B.
Formulation Let x = acres for crop A, y = acres for crop B Constraints: x + y ≤ 10 (land), 30x + 20y ≤ 250 (water) → 3x+2y ≤ 25, 4x + 8y ≤ 50 → x+2y ≤ 12.5, x,y ≥ 0 Objective: Maximise Z = 200x + 300y
Solution Corner points: O(0,0), A(10,0), B(5,5 — from land and fertiliser), C(0,6.25) Find intersection x+y=10 and x+2y=12.5: y=2.5, x=7.5 Z(0,0)=0, Z(10,0)=2000, Z(7.5,2.5)=1500+750=2250, Z(0,6.25)=1875
Maximum profit = ₹2250 when x = 7.5 acres (crop A) and y = 2.5 acres (crop B)
Q.4 (iv)
(a) Point and interval estimation. (b) 95% CI: n=100, x̄=50, σ=10.
Point EstimationA single value used to estimate a population parameter. Example: x̄ = 50 estimates μ. Simple but gives no information about precision.
Interval EstimationA range of values (interval) that is likely to contain the true population parameter with a specified probability (confidence level).
Numerical n=100, x̄=50, σ=10, confidence level = 95%, z₀.₀₂₅ = 1.96 CI = x̄ ± z × σ/√n = 50 ± 1.96 × 10/10 = 50 ± 1.96
95% Confidence Interval: (48.04, 51.96)
Q.4 (vi)
Explain the complete procedure of hypothesis testing.
Steps 1. Set up hypotheses: H₀ (null = no effect) and H₁ (alternative = effect exists) 2. Level of significance: α (typically 0.05 or 0.01) 3. Test statistic: Calculate z, t, χ², or F from sample data 4. Critical region: Find critical value(s) from statistical tables for given α and df 5. Decision: If |test statistic| > critical value → Reject H₀; otherwise → Do not reject H₀ Type I error (α): Rejecting H₀ when it is true (false positive) Type II error (β): Accepting H₀ when it is false (false negative) p-value: Probability of observing result as extreme as the sample result when H₀ is true. If p < α → Reject H₀.
