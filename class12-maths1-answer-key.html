SECTION A — MCQ Answers 8 × 1 = 8 Marks
(i) |adj A| when |A| = 5, order 3
Answer: (C) 125
For a square matrix of order n: |adj A| = |A|^(n−1) Here n = 3, |A| = 5 |adj A| = 5^(3−1) = 5² = 25 Wait — |adj A| = |A|^(n−1) = 5² = 25 (B). But if question asks for |A^n| or adj(adjA), the answer may differ. Standard formula: |adj A| = |A|^(n-1) = 25. Let us check: for n=3, |adj A| = |A|^2 = 25. Answer is 25.
Corrected Answer: (B) 25   [|adj A| = |A|^(n−1) = 5² = 25]
(ii) cos⁻¹(−√3/2)
Answer: (B) 5π/6
cos⁻¹ has range [0, π] cos(5π/6) = cos(π − π/6) = −cos(π/6) = −√3/2 cos⁻¹(−√3/2) = 5π/6

(iv) Derivative of sin(x²)
Answer: (D) 2x·cos(x²)
Let y = sin(x²). Using chain rule: dy/dx = cos(x²) × d(x²)/dx cos(x²) × 2x dy/dx = 2x cos(x²)
(v) ∫ eˣ(x + 1) dx
Answer: (A) x·eˣ + c
Using: ∫ eˣ[f(x) + f'(x)] dx = eˣ f(x) + c Here f(x) = x, f'(x) = 1 → x + 1 = f(x) + f'(x) ∫ eˣ(x+1)dx = x·eˣ + c
(vi) Order and degree of d²y/dx² + (dy/dx)³ = x
Answer: (B) Order 2, Degree 1
Highest derivative = d²y/dx² → Order = 2 Power of highest order derivative = 1 → Degree = 1 (dy/dx)³ is not the highest order term; it does not affect degree)

a⃗·b⃗ = 0 → angle θ = 90° |a⃗ × b⃗| = |a⃗||b⃗|sinθ = 3 × 4 × sin90° = 3 × 4 × 1 |a⃗ × b⃗| = 12
(viii) Slope of normal to y = x³ at x = 1
Answer: (B) −1/3
y = x³ → dy/dx = 3x² At x = 1: slope of tangent = 3(1)² = 3 Slope of normal = −1/(slope of tangent) = −1/3 Slope of normal = −1/3

(iii) Prove tan⁻¹(1/2) + tan⁻¹(1/3) = π/4
Using formula: tan⁻¹(a) + tan⁻¹(b) = tan⁻¹[(a+b)/(1−ab)] when ab < 1 a = 1/2, b = 1/3; ab = 1/6 < 1 ✓ tan⁻¹(1/2) + tan⁻¹(1/3) = tan⁻¹[(1/2 + 1/3)/(1 − 1/6)] tan⁻¹[(3/6 + 2/6)/(5/6)] tan⁻¹[(5/6) ÷ (5/6)] tan⁻¹[1] = π/4 ✓
(v) dy/dx if y = (log x)^(sin x)
Take log both sides: log y = sin x · log(log x) Differentiate both sides with respect to x: (1/y)(dy/dx) = sin x · d/dx[log(log x)] + log(log x) · cos x d/dx[log(log x)] = 1/(log x) · (1/x) = 1/(x log x) (1/y)(dy/dx) = sin x/(x log x) + cos x · log(log x) dy/dx = y · [sin x/(x log x) + cos x · log(log x)]
(vi) y = eˣ sin x, find d²y/dx²
y = eˣ sin x dy/dx = eˣ sin x + eˣ cos x = eˣ(sin x + cos x) d²y/dx² = d/dx[eˣ(sin x + cos x)] eˣ(sin x + cos x) + eˣ(cos x − sin x) eˣ[sin x + cos x + cos x − sin x] eˣ[2 cos x] d²y/dx² = 2eˣ cos x
(vii) Maxima and minima of f(x) = 2x³ − 3x² − 12x + 4
f'(x) = 6x² − 6x − 12 = 6(x² − x − 2) = 6(x−2)(x+1) f'(x) = 0 → x = 2 or x = −1 f''(x) = 12x − 6 At x = 2: f''(2) = 24 − 6 = 18 > 0 → local minimum At x = −1: f''(−1) = −12 − 6 = −18 < 0 → local maximum f(2) = 2(8) − 3(4) − 12(2) + 4 = 16 − 12 − 24 + 4 = −16 f(−1) = 2(−1) − 3(1) − 12(−1) + 4 = −2 − 3 + 12 + 4 = 11 Local Maximum = 11 at x = −1  |  Local Minimum = −16 at x = 2

(iii) Area between y² = 4x and x² = 4y
y² = 4x (parabola, opening right) and x² = 4y (parabola, opening up) Finding intersections: from x² = 4y → y = x²/4. Substituting in y² = 4x: (x²/4)² = 4x → x⁴/16 = 4x → x⁴ = 64x → x(x³−64) = 0 x = 0 or x = 4. Points: (0,0) and (4,4) Area = ∫₀⁴ [√(4x) − x²/4] dx ∫₀⁴ [2√x − x²/4] dx [2 · (2x^(3/2)/3) − x³/12]₀⁴ [4x^(3/2)/3 − x³/12]₀⁴ 4(8)/3 − 64/12 = 32/3 − 16/3 = 16/3 Area = 16/3 sq. units
(iv) Solve: x·dy/dx + 2y = x²·log x
Rewrite: dy/dx + (2/x)y = x·log x (dividing by x) This is linear form: dy/dx + Py = Q where P = 2/x, Q = x·log x Integrating factor: IF = e^(∫P dx) = e^(∫2/x dx) = e^(2 log x) = x² Solution: y·x² = ∫ x² · x·log x dx = ∫ x³·log x dx Using IBP: ∫ x³·log x dx = x⁴/4·log x − ∫ x⁴/4 · 1/x dx x⁴/4·log x − (1/4)∫ x³ dx x⁴/4·log x − x⁴/16 + c y·x² = x⁴/4·log x − x⁴/16 + c y = x²/4·log x − x²/16 + c/x²
(vii) Evaluate ∫₀^π x·sin x/(1 + cos²x) dx
Let I = ∫₀^π x·sin x/(1 + cos²x) dx Using property: ∫₀^a f(x)dx = ∫₀^a f(a−x)dx, with a = π: I = ∫₀^π (π−x)·sin(π−x)/(1 + cos²(π−x)) dx sin(π−x) = sin x; cos(π−x) = −cos x; cos²(π−x) = cos²x I = ∫₀^π (π−x)·sin x/(1+cos²x) dx Adding both expressions: 2I = π·∫₀^π sin x/(1+cos²x) dx Let t = cos x → dt = −sin x dx; when x=0, t=1; x=π, t=−1 2I = π·∫₁^(−1) −dt/(1+t²) = π·∫₋₁^1 dt/(1+t²) π·[tan⁻¹t]₋₁^1 = π·[π/4−(−π/4)] = π·(π/2) = π²/2 I = π²/4
