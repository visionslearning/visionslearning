Q 5What is an Operating System? State its functions. ⭐ Most IMPCh1
Definition An Operating System (OS) is system software that acts as an interface between the user and the computer hardware. It manages all hardware and software resources. Functions of OS: 1. Process Management: Manages running programs (processes); CPU scheduling 2. Memory Management: Allocates and deallocates RAM to programs 3. File Management: Creates, organises, stores, retrieves files and folders 4. Device Management: Controls input/output devices through drivers 5. Security: Password protection, user authentication, access control 6. User Interface: GUI (Windows) or CLI (Linux terminal) Examples of OS: Windows 10/11, Linux (Ubuntu), Android, iOS, macOS

Chapter 2 — Introduction to DBMS

Database · DBMS · SQL · Keys · Tables · Queries

Q 8What is a Database? Define DBMS and state its advantages. ⭐ Most IMPCh2
Database An organised collection of related data stored in a structured format so it can be easily accessed, managed, and updated. Example: Student records, library catalogue. DBMS Database Management System — software that creates, manages, and controls access to databases. Examples: MySQL, Oracle, MS Access, PostgreSQL, SQLite Advantages of DBMS: 1. Reduced data redundancy — no duplicate data 2. Data integrity — accurate and consistent data 3. Data security — password protection, access control 4. Easy data sharing — multiple users can access simultaneously 5. Backup and recovery — data can be restored after failure 6. Data independence — changing structure doesn't affect applications
Q 9Define: Table, Field, Record, Primary Key, Foreign Key. ⭐ Most IMPCh2
Table (Relation) A collection of data arranged in rows and columns. Example: Student table with columns RollNo, Name, Marks. Field (Column/Attribute) A single piece of information in a table — one column. Example: 'Name' is a field in Student table. Record (Row/Tuple) A complete set of related fields — one row of a table. Example: (101, Ravi, 85) is one record. Primary Key A field (or combination) that uniquely identifies each record in a table. Must be unique and NOT NULL. Example: RollNo in Student table. Foreign Key A field in one table that refers to the Primary Key of another table — used to link two tables. Example: DeptID in Employee table links to DeptID in Department table. Candidate Key Any field that can be a Primary Key. E.g., both RollNo and AadharNo can uniquely identify a student.
Q 10Write SQL commands — DDL, DML, DCL with examples. ⭐ Most IMPCh2
DDL — Data Definition Language Defines database structure (schema). CREATE TABLE Student (RollNo INT PRIMARY KEY, Name VARCHAR(50), Marks INT); ALTER TABLE Student ADD Email VARCHAR(100); DROP TABLE Student; DML — Data Manipulation Language Manipulates data in tables. INSERT INTO Student VALUES (101, 'Ravi', 85); UPDATE Student SET Marks=90 WHERE RollNo=101; DELETE FROM Student WHERE RollNo=101; SELECT * FROM Student WHERE Marks > 75; DCL — Data Control Language Controls access permissions. GRANT SELECT ON Student TO user1; REVOKE SELECT ON Student FROM user1;
Q 11Write SQL SELECT queries with WHERE, ORDER BY, GROUP BY. ⭐ Most IMPCh2
Table: Student (RollNo, Name, Class, Marks, City) Q1 Display all students with marks above 80: SELECT * FROM Student WHERE Marks > 80; Q2 Display names in alphabetical order: SELECT Name FROM Student ORDER BY Name ASC; Q3 Count students in each city: SELECT City, COUNT(*) FROM Student GROUP BY City; Q4 Find maximum marks: SELECT MAX(Marks) FROM Student; Q5 Display students from Mumbai with marks > 70: SELECT * FROM Student WHERE City='Mumbai' AND Marks > 70; Q6 Display distinct cities: SELECT DISTINCT City FROM Student;

Q 16Explain Internet concepts — WWW, URL, HTTP, Browser, Search Engine, Email. ⭐ Most IMPCh3
Internet A global network connecting millions of computers worldwide for communication and information sharing. WWW (World Wide Web) A system of interlinked web pages (hypertext) accessed via the Internet. Created by Tim Berners-Lee (1991). Not the same as Internet — WWW runs on the Internet. URL (Uniform Resource Locator) The address of a web page. Example: https://www.google.com Structure: Protocol://Domain/Path → https://visionslearning.in/notes.html HTTP/HTTPS HyperText Transfer Protocol — rules for transferring web pages. HTTPS = Secure (encrypted) version. Browser Software to access and display web pages. Examples: Chrome, Firefox, Edge, Safari. Search Engine Tool that searches and indexes web content. Examples: Google, Bing, Yahoo, DuckDuckGo. Email (Electronic Mail) Digital messages sent over the internet. Structure: username@domain.com. Example: student@gmail.com IP Address Unique numerical address assigned to each device on a network. Example: 192.168.1.1 DNS (Domain Name System) Translates domain names (google.com) to IP addresses (142.250.195.238).

Chapter 4 — Cyber Law

Cyber Crime · IT Act 2000 · Digital Signature · Privacy · Security

Q 18What is Cyber Crime? Classify cyber crimes with examples. ⭐ Most IMPCh4
Cyber Crime Any illegal or criminal activity that involves a computer, network, or the internet as a tool, target, or place of the crime. Types of Cyber Crimes: 1. Hacking: Unauthorised access to a computer/network. E.g., breaking into a bank's server. 2. Phishing: Fake emails/websites to steal passwords and financial info. E.g., fake bank email. 3. Identity Theft: Stealing someone's personal information to commit fraud. 4. Cyberbullying: Harassment, threats, or intimidation online — via social media, messages. 5. Virus/Malware Attack: Spreading harmful software to damage systems. E.g., ransomware. 6. Online Fraud/Scam: Fake lottery, investment schemes, UPI fraud. 7. Cyber Stalking: Repeatedly following/harassing someone online. 8. Data Theft: Stealing confidential data from a company/individual. 9. Child Pornography: Creating/distributing illegal content involving minors. 10. Denial of Service (DoS) Attack: Overloading a server to crash a website.

Q 20What is a Digital Signature? How does it work? ⭐ IMPCh4
Digital Signature A mathematical technique used to validate the authenticity and integrity of a digital document or message — the electronic equivalent of a handwritten signature. How it works: 1. Sender creates the document and applies their private key to create a digital signature (encrypted hash). 2. The digitally signed document is sent to the receiver. 3. Receiver uses the sender's public key to decrypt and verify the signature. 4. If signature matches → document is authentic and unaltered. Benefits: • Authentication — confirms sender's identity • Integrity — ensures document was not modified • Non-repudiation — sender cannot deny sending Used in: Income tax filing, banking, e-commerce, government documents (Aadhaar, PAN). Certificate Authority (CA): Certifying Authorities (like Infosys, NIC) issue Digital Signature Certificates. Under IT Act 2000, digital signatures are legally valid in India.
Q 21Explain cyber security — threats and prevention measures. ⭐ IMPCh4
Cyber Security The practice of protecting computers, networks, programs, and data from digital attacks, unauthorized access, damage, or theft. Common Threats: • Virus: Self-replicating malware that attaches to programs • Worm: Spreads across network without attaching to files • Trojan Horse: Disguised as legitimate software; opens backdoor • Spyware: Secretly monitors user activity and sends data • Ransomware: Encrypts files and demands money for decryption • Phishing: Fake emails/sites to steal credentials Prevention Measures: ✅ Use strong, unique passwords (minimum 8 characters with symbols) ✅ Install and update antivirus/anti-malware software ✅ Keep OS and software updated (security patches) ✅ Use HTTPS websites for online transactions ✅ Enable 2-Factor Authentication (2FA) ✅ Use Firewall to monitor network traffic ✅ Don't click suspicious links or download unknown attachments ✅ Regular data backups
