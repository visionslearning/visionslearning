(vii) Approximate value of √26
Let f(x) = √x → f(x+Δx) ≈ f(x) + f'(x)·Δx Take x = 25, Δx = 1: f'(x) = 1/2√x = 1/10 √26 ≈ √25 + (1/10)×1 = 5 + 0.1 √26 ≈ 5.1

(i) Cramer's rule: x−y+z=4, x+y+z=2, 2x+y−3z=0
D = |1,−1,1;1,1,1;2,1,−3| = 1(−3−1)+1(−3−2)+1(1−2) = −4−5−1 = −10 Dx = |4,−1,1;2,1,1;0,1,−3| = 4(−3−1)+1(−6−0)+1(2−0) = −16−6+2 = −20 Dy = |1,4,1;1,2,1;2,0,−3| = 1(−6−0)−4(−3−2)+1(0−4) = −6+20−4 = 10 Dz = |1,−1,4;1,1,2;2,1,0| = 1(0−2)+1(0−4)+4(1−2) = −2−4−4 = −10 x = Dx/D = −20/−10 = 2   y = Dy/D = 10/−10 = −1   z = Dz/D = −10/−10 = 1

(viii) Window optimisation — maximum area
Let width = 2r, height = h. Semicircle on top (radius = r). Perimeter: 2h + 2r + πr = 30 → h = (30 − 2r − πr)/2 Area: A = 2r·h + πr²/2 = 2r·(30−2r−πr)/2 + πr²/2 = r(30−2r−πr) + πr²/2 A = 30r − 2r² − πr² + πr²/2 = 30r − 2r² − πr²/2 dA/dr = 30 − 4r − πr = 0 → r = 30/(4+π) r = 30/(4+π) ≈ 30/7.14 ≈ 4.2 m   h = (30−2r−πr)/2 ≈ 4.2 m
