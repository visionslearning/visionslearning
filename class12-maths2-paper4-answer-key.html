Section A — MCQ Answers 8 × 1 = 8 Marks
Q.1 (i)
P(A|B) =
✔ Answer: P(A∩B)/P(B)
Explanation P(A|B) = P(A∩B)/P(B) — conditional probability of A given B has occurred Valid when P(B) > 0
Q.1 (ii)
For B(10, 1/2), the mean is:
✔ Answer: 5
Solution Mean = np = 10 × 1/2 = 5 Variance = npq = 10 × 1/2 × 1/2 = 2.5
Q.1 (iii)
The value of r always satisfies:
✔ Answer: −1 ≤ r ≤ 1
Explanation Pearson's correlation coefficient r always lies in [−1, 1] |r| = 1: perfect linear correlation; r = 0: no linear correlation
Q.1 (iv)
If feasible region is unbounded in LPP, then:
✔ Answer: optimal solution may or may not exist
Explanation Unbounded feasible region: maximum may not exist (for maximisation); minimum always exists if the feasible region extends only in one direction Must check whether optimal value is finite or unbounded
Q.1 (v)
Irregular variation in time series is:
✔ Answer: unpredictable random fluctuation
Explanation Irregular (residual) variation: random, unpredictable changes caused by accidents, natural disasters, strikes, pandemics Cannot be forecast or predicted
Q.1 (vi)
Consumer Price Index is also known as:
✔ Answer: Cost of Living Index (CLI)
Explanation CPI measures the change in prices of a basket of goods and services purchased by a typical household Used to adjust wages, pensions, social security benefits for inflation
Q.1 (vii)
The normal distribution curve is:
✔ Answer: bell-shaped, symmetric about the mean
Explanation Normal curve: bell-shaped (mesokurtic), symmetric about μ, unimodal, asymptotic to x-axis Mean = Median = Mode = μ. Area under entire curve = 1.
Q.1 (viii)
Poisson distribution: n→∞, p→0 and:
✔ Answer: np → λ (constant)
Explanation Poisson is the limiting case of binomial as n→∞, p→0 such that np = λ (constant) remains finite Example: Radioactive decay, call centre arrivals, typing errors per page
Section B — Short Answer I 8 × 2 = 16 Marks
Q.2 (i)
From 52 cards, one drawn. Find P(king or red card).
Solution P(King) = 4/52  |  P(Red) = 26/52  |  P(Red King) = 2/52 P(King or Red) = 4/52 + 26/52 − 2/52 = 28/52
P = 28/52 = 7/13 ≈ 0.538
Q.2 (ii)
X ~ Poisson(3). Find P(X=0). [e⁻³ = 0.0498]
Solution P(X=0) = e^(−λ)λ⁰/0! = e⁻³ × 1 = 0.0498
P(X = 0) = 0.0498 ≈ 5%
Q.2 (iii)
If b_xy = 0.4 and b_yx = 0.9, find r.
Solution r = ±√(b_xy × b_yx) = ±√(0.4 × 0.9) = ±√0.36 = ±0.6 Both positive → r = +0.6
r = 0.6
Q.2 (vi)
P(A)=0.6, P(B)=0.5, P(A∩B)=0.3. Are A and B independent?
Solution P(A)×P(B) = 0.6 × 0.5 = 0.30 P(A∩B) = 0.3 P(A∩B) = P(A)×P(B) = 0.3
Yes, A and B ARE independent
Q.2 (ix)
For N(μ=50, σ=5), find P(45 < X < 55).
Solution z₁ = (45−50)/5 = −1  |  z₂ = (55−50)/5 = +1 P(45<X<55) = P(−1<Z<1) = 2×P(0<Z<1) = 2×0.3413
P = 0.6826 = 68.26%
Q.2 (x)
Given x̄=10, ȳ=6, r=0.8, σx=3, σy=2. Write regression line y on x.
Solution b_yx = r × σy/σx = 0.8 × 2/3 = 1.6/3 = 8/15 y − 6 = (8/15)(x − 10) → y = (8/15)x − 80/15 + 6 = (8/15)x + 10/15 = (8/15)x + 2/3
y = (8/15)x + 2/3 ≈ 0.533x + 0.667
Q.2 (xii)
PMF: P(X=x) = x/10 for x=1,2,3,4. Find P(X ≤ 2).
Solution Verify: P(1)+P(2)+P(3)+P(4) = 1/10+2/10+3/10+4/10 = 10/10 = 1 ✓ P(X≤2) = P(X=1)+P(X=2) = 1/10+2/10 = 3/10
P(X ≤ 2) = 3/10 = 0.3

Find both regression lines and r: n=6, Σx=42, Σy=48, Σx²=332, Σy²=432, Σxy=354.

Q.3 (ix)
Test if correlation is significant: r=0.7, n=25.
Solution H₀: ρ = 0 (no correlation), H₁: ρ ≠ 0 t = r√(n−2)/√(1−r²) = 0.7√23/√(1−0.49) = 0.7×4.796/√0.51 = 3.357/0.714 = 4.70 |t| = 4.70 > 2.069 (critical value for 23 df at 5%)
Reject H₀. Correlation r = 0.7 IS statistically significant at 5% level.
Q.3 (xi)
Compute CPI (Laspeyre's) for working-class family.
Solution Food: p₀=100,q₀=40,p₁=140 | Clothing: p₀=50,q₀=10,p₁=75 | Rent: p₀=200,q₀=1,p₁=350 Σp₁q₀ = 140×40 + 75×10 + 350×1 = 5600+750+350 = 6700 Σp₀q₀ = 100×40 + 50×10 + 200×1 = 4000+500+200 = 4700 CPI = (6700/4700)×100
CPI = 142.55 (prices rose by 42.55% from 2015 to 2024)

Q.4 (iv)
Explain properties of normal distribution.
Properties 1. Bell-shaped, symmetric about mean μ 2. Mean = Median = Mode = μ 3. Total area under curve = 1 (probability = 1) 4. Curve extends infinitely on both sides (asymptotic to x-axis) 5. 68-95-99.7 rule: μ±σ: 68.27%, μ±2σ: 95.45%, μ±3σ: 99.73% 6. Unimodal (single peak at μ) 7. Points of inflection at μ±σ 8. Sum of two independent normal variables is normal

y = 1.1x + 11.8 | x = 0.64y − 3.41 | r ≈ 0.84 (strong positive correlation)

Compare Fisher's, Laspeyre's and Paasche's indices.
Solution A(p₀=5,q₀=8,p₁=7,q₁=10), B(p₀=8,q₀=5,p₁=11,q₁=6), C(p₀=4,q₀=10,p₁=6,q₁=12) Σp₁q₀ = 56+55+60=171  |  Σp₀q₀ = 40+40+40=120 → L = 171/120×100 = 142.5 Σp₁q₁ = 70+66+72=208  |  Σp₀q₁ = 50+48+48=146 → P = 208/146×100 = 142.47 Fisher's = √(L×P) = √(142.5×142.47) ≈ 142.49
