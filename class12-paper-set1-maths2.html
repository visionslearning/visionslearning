SECTION A — MCQ Answers 8 × 1
(i) P(A∪B) when A, B mutually exclusive
Answer: (B) 0.7
Mutually exclusive → P(A∩B) = 0 P(A∪B) = P(A) + P(B) = 0.3 + 0.4 = 0.7
(ii) p when mean=4, variance=2 for B(n,p)
Answer: (C) 1/2
Mean = np = 4; Variance = npq = 2 npq/np = q = 2/4 = 1/2 → p = 1 − q = 1/2
(iii–viii) Remaining MCQs
(iii) r lies between −1 and 1 (B) — by definition of correlation coefficient (iv) Feasible region = set of all feasible solutions (C) (v) Seasonal variation repeats within a year (C) — e.g., sales peak in festivals (vi) Paasche's index uses current year quantities q₁ (B) (vii) Standard normal: μ = 0, σ = 1 (B) (viii) Poisson: mean = variance = λ (C)
SECTION B — Solutions 2 marks each
(i) P(sum = 7) when two dice thrown
n(S) = 36 Favourable outcomes: {(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)} → 6 outcomes P(sum = 7) = 6/36 = 1/6
(ii) X ~ B(6, 1/3), find P(X=2)
P(X=r) = ⁿCᵣ × pʳ × qⁿ⁻ʳ, p=1/3, q=2/3, n=6, r=2 P(X=2) = ⁶C₂ × (1/3)² × (2/3)⁴ = 15 × 1/9 × 16/81 15 × 16/729 = 240/729 = 80/243 P(X=2) = 80/243
(iv) Mean of 5, 8, 12, 15, 20
Mean = Σx/n = (5+8+12+15+20)/5 = 60/5 Mean = 12
(vi) Are A and B independent? P(A)=1/3, P(B)=1/4, P(A∩B)=1/12
For independence: P(A∩B) = P(A) × P(B) P(A) × P(B) = 1/3 × 1/4 = 1/12 P(A∩B) = 1/12 ✓ Yes, A and B are independent events.
(viii) Laspeyre's index: p₀: 5,8; q₀: 10,6; p₁: 7,10
Laspeyre's = (Σp₁q₀ / Σp₀q₀) × 100 Σp₁q₀ = 7×10 + 10×6 = 70 + 60 = 130 Σp₀q₀ = 5×10 + 8×6 = 50 + 48 = 98 Laspeyre's = (130/98) × 100 = 132.65
(ix) P(X < 70) when μ=60, σ=10
Z = (X − μ)/σ = (70 − 60)/10 = 1 P(X < 70) = P(Z < 1) = 0.8413
(x) Find x̄, ȳ from x + 2y = 5 and 2x + 3y = 8
Regression lines pass through (x̄, ȳ). Solve simultaneously: x + 2y = 5 ...(1); 2x + 3y = 8 ...(2) (2) − 2×(1): −y = −2 → y = 2. From (1): x = 5 − 4 = 1 x̄ = 1, ȳ = 2
(xii) E(X): P(X=1)=1/2, P(X=2)=1/3, P(X=3)=1/6
E(X) = 1×(1/2) + 2×(1/3) + 3×(1/6) 1/2 + 2/3 + 1/2 = 3/6 + 4/6 + 3/6 = 10/6 E(X) = 5/3 ≈ 1.67
SECTION C — Solutions 3 marks each
(i) P(one red, one blue) — 3R 4B, without replacement
P(1R 1B) = P(R first then B) + P(B first then R) = (3/7)(4/6) + (4/7)(3/6) = 12/42 + 12/42 = 24/42 = 4/7
(ii) E(X) and Var(X): x: 1,2,3,4; P: 0.1,0.3,0.4,0.2
E(X) = 1(0.1)+2(0.3)+3(0.4)+4(0.2) = 0.1+0.6+1.2+0.8 = 2.7 E(X²) = 1(0.1)+4(0.3)+9(0.4)+16(0.2) = 0.1+1.2+3.6+3.2 = 8.1 Var(X) = E(X²) − [E(X)]² = 8.1 − 7.29 = 0.81
(iii) Regression line y on x: x: 1,2,3,4,5; y: 3,5,4,6,7
n=5, Σx=15, Σy=25, x̄=3, ȳ=5 Σxy = 3+10+12+24+35 = 84 Σx² = 1+4+9+16+25 = 55 byx = (Σxy − nx̄ȳ)/(Σx² − nx̄²) = (84−75)/(55−45) = 9/10 = 0.9 Line: y − ȳ = byx(x − x̄) → y − 5 = 0.9(x − 3) y = 0.9x + 2.3 For x = 6: y = 0.9(6) + 2.3 = 7.7
(iv) LPP: Max Z = 3x + 5y; x≤4, y≤6, x+y≤8, x,y≥0
Corner points: A(0,0)→Z=0; B(4,0)→Z=12; C(4,4)→Z=32; D(2,6)→Z=36; E(0,6)→Z=30 Intersection of x+y=8 and y=6: x=2, y=6 → D(2,6) Maximum Z = 36 at point (2, 6)
(vi) Poisson: P(X=1) = 3P(X=2)
P(X=1) = e⁻λ·λ/1! = e⁻λ·λ P(X=2) = e⁻λ·λ²/2! e⁻λ·λ = 3 × e⁻λ·λ²/2 → 1 = 3λ/2 → λ = 2/3 Mean λ = 2/3 P(X=0) = e⁻(2/3) = e⁻²/³ ≈ 0.5134

SECTION D — Solutions 4 marks each
(i) Multiplication theorem + P(both hearts)
Multiplication Theorem: For two events A and B, P(A∩B) = P(A) × P(B|A) Proof: P(B|A) = P(A∩B)/P(A) [by definition of conditional probability] ∴ P(A∩B) = P(A) × P(B|A) ✓ Numerical: P(both hearts from 52 cards) P(1st heart) = 13/52 = 1/4 P(2nd heart | 1st was heart) = 12/51 = 4/17 P(both hearts) = 1/4 × 4/17 = 4/68 = 1/17
(iii) LPP: Max Z = 4x + 6y; x+y≤6, 2x+y≤8, x,y≥0
Find corner points of feasible region: A(0,0): Z=0 B(4,0): Z=16 [from 2x+y=8, y=0 → x=4] C — intersection of x+y=6 and 2x+y=8:   Subtract: x = 2, y = 4 → C(2,4): Z = 8+24 = 32 D(0,6): Z = 0+36 = 36 [from x+y=6, x=0] Maximum Z = 36 at point D(0, 6)
(v) Regression lines and r from n=5, Σx=30, Σy=40, Σx²=220, Σy²=340, Σxy=262
x̄ = 30/5 = 6, ȳ = 40/5 = 8 Sxx = Σx²−nx̄² = 220−5(36) = 220−180 = 40 Syy = Σy²−nȳ² = 340−5(64) = 340−320 = 20 Sxy = Σxy−nx̄ȳ = 262−5(48) = 262−240 = 22 byx = Sxy/Sxx = 22/40 = 0.55 Regression line y on x: y−8 = 0.55(x−6) → y = 0.55x + 4.7 bxy = Sxy/Syy = 22/20 = 1.1 Regression line x on y: x−6 = 1.1(y−8) → x = 1.1y − 2.8 r = √(byx × bxy) = √(0.55 × 1.1) = √0.605 r = 0.778
(vii) Laspeyre's, Paasche's, Fisher's index
A: p₀=10,q₀=6,p₁=12,q₁=5 | B: p₀=8,q₀=5,p₁=10,q₁=6 | C: p₀=6,q₀=8,p₁=8,q₁=9 Σp₀q₀ = 60+40+48 = 148  |  Σp₁q₀ = 72+50+64 = 186 Σp₀q₁ = 50+48+54 = 152  |  Σp₁q₁ = 60+60+72 = 192 Laspeyre's = (186/148)×100 = 125.68 Paasche's = (192/152)×100 = 126.32 Fisher's = √(125.68 × 126.32) = √(15879.3) = 126.01
