SECTION A — MCQ Answers 8 × 1 = 8
(i) If A is a square matrix, then |A·Aᵀ| = ?
Answer: |A|²
|A·Aᵀ| = |A|·|Aᵀ| = |A|·|A| = |A|² (since |Aᵀ| = |A|)
(ii) sin⁻¹(sin 3π/4)
Answer: π/4
sin⁻¹ range is [−π/2, π/2]. sin(3π/4) = sin(π−π/4) = sin(π/4). So sin⁻¹(sin(3π/4)) = π/4
(iii) Distance of point (3,4) from y-axis
Answer: 3
Distance from y-axis = |x-coordinate| = |3| = 3
(iv) d/dx(log(sinx))
Answer: cotx
d/dx[log(sinx)] = (1/sinx)·cosx = cosx/sinx = cotx
(v) ∫1/(1+x²) dx
Answer: tan⁻¹x + c
∫1/(1+x²)dx = tan⁻¹x + c (standard result)
(vi) If dy/dx = y, then y = ?
Answer: Ce^x
dy/y = dx → ∫dy/y = ∫dx → lny = x + c → y = Ce^x
(vii) a⃗·b⃗ = 0 means vectors are
Answer: perpendicular
a⃗·b⃗ = |a||b|cosθ = 0 → cosθ = 0 → θ = 90° → perpendicular vectors
(viii) Equation of XY-plane
Answer: z = 0
XY-plane: all points where z = 0  |  XZ-plane: y = 0  |  YZ-plane: x = 0

SECTION C — Short Answer II (selected) 8 × 3 = 24
(i) Prove tan⁻¹(1/2) + tan⁻¹(1/3) = π/4
Using formula: tan⁻¹a + tan⁻¹b = tan⁻¹[(a+b)/(1−ab)] when ab < 1 a = 1/2, b = 1/3, ab = 1/6 < 1 ✓ = tan⁻¹[(1/2 + 1/3)/(1 − 1/6)] = tan⁻¹[(5/6)/(5/6)] = tan⁻¹(1) = π/4 ✓
(iii) Integration by parts: ∫x·sinx dx
∫u·dv = uv − ∫v·du u = x → du = dx   dv = sinx dx → v = −cosx = x(−cosx) − ∫(−cosx)dx = −xcosx + sinx + c ∫x·sinx dx = −xcosx + sinx + c
(v) LHL and RHL of f(x) = |x|/x at x = 0
LHL: lim(x→0⁻) |x|/x = lim(x→0⁻)(−x/x) = −1 RHL: lim(x→0⁺) |x|/x = lim(x→0⁺)(x/x) = +1 LHL ≠ RHL → limit does not exist at x = 0 (not continuous)
