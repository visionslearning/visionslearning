Q.1 (iv)

Q.1 (v)

✔ Answer: (A) xeˣ + c
Explanation ∫eˣ[f(x) + f'(x)] dx = eˣf(x) + c   (standard result) Here f(x) = x, f'(x) = 1. So ∫eˣ(x + 1)dx = eˣ × x + c = xeˣ + c
Q.1 (vi)
For d²y/dx² + (dy/dx)³ = x, the order and degree are:
✔ Answer: (B) order 2, degree 1
Explanation Order = highest order derivative = d²y/dx² → order = 2 Degree = power of highest order derivative = (d²y/dx²)¹ → degree = 1 The (dy/dx)³ does NOT determine degree — only highest order derivative matters

Q.1 (viii)
