Advanced Web Designing
20 Marks
Q.1
What is CSS? Explain different types of CSS with examples.
🔥 Sure Shot
Definition
CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation (look and formatting) of an HTML document.
3 Types
  • Inline CSS: Applied directly to an HTML element using style attribute. e.g. <p style="color:red;">
  • Internal CSS: Written inside <style> tag in the <head> section.
  • External CSS: Separate .css file linked using <link rel="stylesheet" href="style.css">
∴ External CSS is best practice as it separates content from design and is reusable.
Q.2
What is a CSS Selector? Explain any 4 types of CSS selectors.
⭐ Very Imp
Definition
A CSS selector is used to select HTML elements to apply styles. It targets elements based on their name, id, class, attribute, etc.
Types
  • Element Selector: Selects by tag name. e.g. p { color: blue; }
  • ID Selector: Selects by id. e.g. #header { font-size: 20px; }
  • Class Selector: Selects by class. e.g. .box { border: 1px solid; }
  • Universal Selector: Selects all elements. e.g. * { margin: 0; }
  • Group Selector: Multiple elements. e.g. h1, h2, p { font-family: Arial; }
∴ Selectors make styling efficient by targeting specific HTML elements.
Q.3
What is the CSS Box Model? Explain its components.
🔥 Sure Shot
Definition
The CSS Box Model is a box that wraps every HTML element. It consists of content, padding, border, and margin.
Components
  • Content: The actual content (text/image) inside the box.
  • Padding: Space between content and border (inside the border).
  • Border: A line that surrounds the padding and content.
  • Margin: Space outside the border (between elements).
∴ Total element width = content + padding + border + margin.
Q.4
What is Responsive Web Design? Explain Media Query with example.
⭐ Very Imp
Definition
Responsive Web Design (RWD) is a design approach that makes web pages render well on all devices (desktop, tablet, mobile) by adapting layout to screen size.
Media Query
Media queries apply CSS rules only for specific screen sizes.
Example: @media (max-width: 600px) { body { font-size: 14px; } }
Features
  • Fluid grids, flexible images, media queries
  • Viewport meta tag: <meta name="viewport" content="width=device-width">
∴ RWD ensures one website works perfectly on all screen sizes.
Q.5
Explain HTML5 semantic tags with examples.
📌 Important
Definition
Semantic tags clearly describe their meaning to both browser and developer.
Tags
  • <header> — Page or section header
  • <nav> — Navigation links
  • <main> — Main content of page
  • <section> — A section of content
  • <article> — Independent content like blog post
  • <footer> — Page footer
  • <aside> — Sidebar content
∴ Semantic tags improve SEO, accessibility, and code readability.

Introduction to SEO
10 Marks
Q.1
What is SEO? Explain On-Page and Off-Page SEO.
🔥 Sure Shot
Definition
SEO (Search Engine Optimization) is the process of improving a website's visibility in search engine results (like Google) to get more organic (free) traffic.
On-Page SEO
Optimizations done within the website:
  • Using proper keywords in title, headings, content
  • Meta tags (description, keywords)
  • Image alt attributes
  • Fast loading speed, mobile-friendly design
  • Clean URL structure
Off-Page SEO
Optimizations done outside the website:
  • Backlinks from other websites
  • Social media sharing
  • Guest blogging
  • Online directory listings
∴ Good SEO increases website ranking on search engines without paying for ads.
Q.2
What are Meta Tags? Explain their role in SEO.
⭐ Very Imp
Definition
Meta tags are HTML tags inside <head> section that provide information about the webpage to search engines and browsers.
Types
  • <meta name="description" content="..."> — Page description shown in search results
  • <meta name="keywords" content="..."> — Keywords for search engines
  • <meta name="robots" content="index, follow"> — Controls indexing
  • <meta name="viewport" content="width=device-width"> — For mobile responsiveness
∴ Meta tags help search engines understand the page content and improve ranking.
Q.3
What is a Keyword? Explain keyword research and types of keywords.
📌 Important
Definition
Keywords are words or phrases that users type in search engines to find information. They are the foundation of SEO.
Types
  • Short-tail keywords: 1–2 words, high competition. e.g. "shoes"
  • Long-tail keywords: 3+ words, less competition. e.g. "best running shoes for men"
  • LSI Keywords: Related terms that support the main keyword
Keyword Research
Process of finding best keywords using tools like Google Keyword Planner, Ubersuggest, etc.
∴ Proper keyword research is the first step of effective SEO.

Advanced Javascript
15 Marks
Q.1
What are JavaScript Events? Explain any 5 events with examples.
🔥 Sure Shot
Definition
JavaScript Events are actions that occur in the browser (user interaction or browser action) that can be detected and responded to using JavaScript.
5 Events
  • onclick: Fires when element is clicked. e.g. onclick="alert('Hello')"
  • onmouseover: Fires when mouse moves over element.
  • onkeypress: Fires when a key is pressed on keyboard.
  • onload: Fires when page has finished loading.
  • onchange: Fires when value of input field changes.
  • onsubmit: Fires when a form is submitted.
∴ Events make web pages interactive and dynamic.
Q.2
What is DOM (Document Object Model)? Explain DOM manipulation methods.
🔥 Sure Shot
Definition
DOM (Document Object Model) is a programming interface that represents an HTML document as a tree structure. JavaScript uses DOM to access and manipulate HTML elements dynamically.
Methods
  • document.getElementById("id") — Select element by ID
  • document.getElementsByClassName("class") — Select by class
  • document.querySelector("selector") — Select first matching element
  • element.innerHTML = "text" — Change HTML content
  • element.style.color = "red" — Change CSS
  • element.setAttribute("attr","val") — Change attribute
∴ DOM manipulation allows JavaScript to dynamically update webpage content.
Q.3
What is Form Validation in JavaScript? Write a program to validate a form.
🔥 Sure Shot
Definition
Form Validation is the process of checking user input before submitting a form to ensure data is correct and complete.
Types
  • Client-side validation: Done using JavaScript before sending to server (faster)
  • Server-side validation: Done at the server (more secure)
Example
function validate() {
 var name = document.getElementById("name").value;
 if(name == "") {
  alert("Name is required!");
  return false;
 }
}
∴ Validation prevents incorrect/empty data from being submitted to the server.
Q.4
What are JavaScript Arrays? Explain array methods with examples.
⭐ Very Imp
Definition
An Array is a special variable that can hold multiple values in a single variable. e.g. var fruits = ["Apple", "Mango", "Banana"];
Methods
  • push() — Add element at end
  • pop() — Remove last element
  • shift() — Remove first element
  • unshift() — Add element at beginning
  • length — Returns number of elements
  • sort() — Sort array elements
  • reverse() — Reverse the array
  • splice() — Add/remove elements at specific index
∴ Arrays make it easy to store and manage multiple values in JavaScript.
Q.5
What are JavaScript Cookies? How to create, read and delete cookies?
📌 Important
Definition
Cookies are small text files stored on the user's computer by the browser. Used to remember user information between sessions.
Create
document.cookie = "username=Rahul; expires=Thu, 01 Jan 2026 00:00:00 UTC";
Read
var c = document.cookie; // returns all cookies as string
Delete
document.cookie = "username=; expires=Thu, 01 Jan 1970 00:00:00 UTC"; (set past date)
∴ Cookies are used for session management, user preferences, and tracking.

Emerging Technologies (IoT, Cloud, AI, 5G)
18 Marks
Q.1
What is IoT (Internet of Things)? Explain its components and applications.
🔥 Sure Shot
Definition
IoT (Internet of Things) refers to the network of physical devices (things) embedded with sensors, software, and connectivity to exchange data over the internet.
Components
  • Sensors/Devices: Collect data from environment
  • Connectivity: WiFi, Bluetooth, 5G to transmit data
  • Data Processing: Cloud/edge processing of collected data
  • User Interface: App or dashboard to control devices
Applications
Smart Home, Smart City, Healthcare (wearables), Agriculture, Industrial automation, Smart vehicles
∴ IoT connects everyday objects to internet for smarter, automated living.
Q.2
What is Cloud Computing? Explain types of cloud services (IaaS, PaaS, SaaS).
🔥 Sure Shot
Definition
Cloud Computing is the delivery of computing services (servers, storage, databases, networking, software) over the internet ("the cloud") on a pay-as-you-go basis.
IaaS
Infrastructure as a Service: Provides virtualized computing resources. e.g. AWS EC2, Microsoft Azure. User manages OS and applications.
PaaS
Platform as a Service: Provides platform for developing and deploying apps. e.g. Google App Engine, Heroku.
SaaS
Software as a Service: Ready-to-use software over internet. e.g. Gmail, Google Docs, Dropbox.
Advantages
Cost-effective, Scalable, Accessible anywhere, Automatic updates, Reliable backup
∴ Cloud computing eliminates the need for local hardware/software maintenance.
Q.3
What is Artificial Intelligence (AI)? Explain its types and applications.
🔥 Sure Shot
Definition
Artificial Intelligence (AI) is the simulation of human intelligence in machines programmed to think, learn, and problem-solve like humans.
Types
  • Narrow AI (Weak AI): Designed for specific tasks. e.g. Siri, Alexa, Chess engine
  • General AI (Strong AI): Can perform any intellectual task like human (still theoretical)
  • Super AI: Exceeds human intelligence (future concept)
Applications
Virtual assistants (Siri, Alexa), Self-driving cars, Medical diagnosis, Fraud detection, Chatbots, Recommendation systems (Netflix, YouTube)
∴ AI is transforming every industry from healthcare to entertainment.
Q.4
What is 5G technology? Explain its features and advantages over 4G.
⭐ Very Imp
Definition
5G is the 5th generation mobile network technology that provides faster data speeds, lower latency, and supports more connected devices simultaneously.
Features
  • Speed: Up to 10–20 Gbps (100x faster than 4G)
  • Low Latency: 1ms vs 30–50ms in 4G
  • Massive Connectivity: Supports 1 million devices per km²
  • Energy Efficient: Better battery life for IoT devices
Applications
Autonomous vehicles, Smart cities, Remote surgery, AR/VR, Industrial automation
∴ 5G will revolutionize communication and enable next-generation technologies like IoT and AI.

Server-Side Scripting (PHP)
15 Marks
Q.1
What is PHP? Explain features and advantages of PHP.
🔥 Sure Shot
Definition
PHP (Hypertext Preprocessor) is a server-side scripting language designed for web development. PHP code is executed on the server and the result is sent as plain HTML to the browser.
Features
  • Open-source and free
  • Platform independent (Windows, Linux, Mac)
  • Supports all major databases (MySQL, Oracle)
  • Easy to learn, similar to C syntax
  • Embedded directly in HTML
  • Fast and secure
Syntax
<?php
echo "Hello World!";
?>
∴ PHP powers over 70% of websites including WordPress, Facebook (initial), Wikipedia.
Q.2
Explain PHP variables, data types and operators.
⭐ Very Imp
Variables
Start with $ sign. e.g. $name = "Rahul";   $age = 20;
Rules: Start with letter/underscore, case-sensitive, no spaces.
Data Types
  • String: $name = "Hello";
  • Integer: $age = 20;
  • Float: $price = 9.99;
  • Boolean: $flag = true;
  • Array: $arr = array(1,2,3);
  • NULL: $val = NULL;
Operators
Arithmetic (+,-,*,/,%), Comparison (==,!=,>,<), Logical (&&, ||, !), Assignment (=,+=,-=)
∴ PHP supports all standard programming constructs for web development.
Q.3
How does PHP connect to MySQL database? Write code to connect and fetch data.
🔥 Sure Shot
Steps
  • Step 1: Create connection using mysqli_connect()
  • Step 2: Select database
  • Step 3: Run SQL query
  • Step 4: Fetch results
  • Step 5: Close connection
Code
$conn = mysqli_connect("localhost","root","","mydb");
$sql = "SELECT * FROM students";
$result = mysqli_query($conn, $sql);
while($row = mysqli_fetch_array($result)) {
 echo $row['name'];
}
mysqli_close($conn);
∴ PHP + MySQL is the most popular combination for dynamic web applications.
Q.4
What are PHP functions? Explain user-defined functions with example.
📌 Important
Definition
A function is a block of code that performs a specific task and can be reused. PHP has 1000+ built-in functions and allows user-defined functions.
Syntax
function functionName($parameter) {
 // code
 return value;
}
Example
function add($a, $b) {
 return $a + $b;
}
echo add(5, 3); // Output: 8
∴ Functions improve code reusability, readability, and reduce repetition.

E-Commerce and E-Governance
10 Marks
Q.1
What is E-Commerce? Explain types of E-Commerce with examples.
🔥 Sure Shot
Definition
E-Commerce (Electronic Commerce) refers to buying and selling of products/services over the internet. It involves online transactions, electronic data exchange, and digital payments.
Types
  • B2C (Business to Consumer): Business sells to consumers. e.g. Amazon, Flipkart
  • B2B (Business to Business): Business sells to another business. e.g. Alibaba
  • C2C (Consumer to Consumer): Consumer sells to consumer. e.g. OLX, eBay
  • C2B (Consumer to Business): Consumer provides service to business. e.g. Freelancing
  • G2C (Government to Citizen): Govt services online. e.g. IRCTC, income tax filing
∴ E-Commerce has transformed the way businesses operate and consumers shop worldwide.
Q.2
What is E-Governance? Explain its types and advantages.
🔥 Sure Shot
Definition
E-Governance (Electronic Governance) is the use of IT and internet by the government to deliver services, information, and communication to citizens, businesses, and other government departments.
Types
  • G2C (Govt to Citizen): Online birth/death certificate, tax filing, Aadhaar
  • G2B (Govt to Business): Online business registration, GST, tenders
  • G2G (Govt to Govt): Data sharing between departments
  • G2E (Govt to Employee): Online salary, leave management
Advantages
  • Transparency and reduced corruption
  • 24/7 availability of services
  • Faster processing, less paperwork
  • Cost effective
  • Reaches remote areas
∴ E-Governance improves efficiency, transparency, and accessibility of government services.
Q.3
What is Online Payment? Explain different online payment methods.
⭐ Very Imp
Definition
Online Payment is the process of paying for goods or services over the internet using digital payment methods instead of cash.
Methods
  • Credit/Debit Card: Visa, MasterCard payments online
  • Net Banking: Direct bank account transfer via bank portal
  • UPI (Unified Payment Interface): GPay, PhonePe, Paytm — instant mobile payments
  • Mobile Wallets: Paytm wallet, Amazon Pay — store money digitally
  • EMI: Pay in installments through bank/NBFCs
  • Cash on Delivery (COD): Pay cash when product delivered
∴ Digital payments have made e-commerce transactions fast, secure, and convenient.
Q.4
What is Cyber Security? Explain types of cyber threats and protection measures.
⭐ Very Imp
Definition
Cyber Security is the practice of protecting computers, servers, networks, and data from digital attacks, damage, or unauthorized access.
Threats
  • Malware: Viruses, worms, ransomware that damage systems
  • Phishing: Fake emails/websites to steal credentials
  • Hacking: Unauthorized access to systems
  • DOS Attack: Overloading server to make it unavailable
  • Identity Theft: Stealing personal information for fraud
Protection
Use strong passwords, antivirus software, firewall, HTTPS, regular updates, two-factor authentication
∴ Cyber security is essential for safe e-commerce and digital transactions.
