Theory — Key Concepts & Definitions

✅ Continuity at a Point

A function f(x) is continuous at a point x = a if and only if all three conditions are satisfied:

① f(a) is defined
② limx→a f(x) exists
③ limx→a f(x) = f(a)

📌 Continuity from Right and Left

Continuous from Right at a : limx→a⁺ f(x) = f(a)
Continuous from Left at b : limx→b⁻ f(x) = f(b)

📌 Continuity over an Interval

Open Interval (a,b): f is continuous at every point in the interval.

Closed Interval [a,b]: f is continuous at every point in (a,b), continuous from right at a, and continuous from left at b.
⚠️
Types of Discontinuity
Removable Discontinuity: f(x) is discontinuous at a, but limx→a f(x) exists. f(a) may or may not be defined. It can be "fixed" by redefining f(a).
Jump Discontinuity: Both limx→a⁻ f(x) and limx→a⁺ f(x) exist, but
limx→a⁻ f(x) ≠ limx→a⁺ f(x). The function "jumps" at a.
Infinite Discontinuity: limx→a⁺ f(x) = ±∞ or limx→a⁻ f(x) = ±∞.
📈
Intermediate Value Theorem (IVT)
IVT Statement: If f is continuous on a closed interval [a, b], and y₀ is any value between f(a) and f(b), then y₀ = f(c) for some c in [a, b].
Geometric meaning: Any horizontal line y = y₀ crossing between f(a) and f(b) will cross the curve y = f(x) at least once over [a, b].
Important: The continuity of f on the interval is essential. If f is discontinuous at even one point, the conclusion may fail.

Exercise 8.1 — All Questions Solved
Q.1 — Examine the continuity
1(i)
Examine the continuity of f(x) = x³ + 2x² − x − 2 at x = −2.
Solution

Step 1: Find f(−2)

f(−2) = (−2)³ + 2(−2)² − (−2) − 2

= −8 + 8 + 2 − 2 = 0

Step 2: Find limx→−2 f(x)

f(x) is a polynomial → continuous everywhere

limx→−2 f(x) = f(−2) = 0

Step 3: Check condition

f(−2) = 0 = limx→−2 f(x) ✓

∴ f(x) is continuous at x = −2.
1(ii)
f(x) = sin x, for x ≤ π/4  |  cos x, for x > π/4   at x = π/4
Solution

Step 1: f(π/4)

f(π/4) = sin(π/4) = 1/√2

Step 2: Left-hand limit (LHL)

limx→(π/4)⁻ f(x) = lim sin x = sin(π/4) = 1/√2

Step 3: Right-hand limit (RHL)

limx→(π/4)⁺ f(x) = lim cos x = cos(π/4) = 1/√2

Step 4: Check

LHL = RHL = f(π/4) = 1/√2 ✓

∴ f(x) is continuous at x = π/4.
1(iii)
f(x) = (x² − 9)/(x − 3), for x ≠ 3  |  = 8, for x = 3   at x = 3
Solution

Step 1: f(3) = 8 (given)

Step 2: Find limx→3 f(x)

limx→3 (x² − 9)/(x − 3)

= limx→3 (x+3)(x−3)/(x−3)

= limx→3 (x + 3) = 3 + 3 = 6

Step 3: Check

limx→3 f(x) = 6 ≠ 8 = f(3) ✗

∴ f(x) is NOT continuous at x = 3. (Removable discontinuity)
💡 If we redefine f(3) = 6, it becomes continuous.
Q.2 — Examine whether the function is continuous at the given points
2(i)
f(x) = x³ − 2x + 1, if x ≤ 2  |  = 3x − 2, if x > 2   at x = 2
Solution

Step 1: f(2) (using x ≤ 2 branch)

f(2) = (2)³ − 2(2) + 1 = 8 − 4 + 1 = 5

Step 2: LHL

limx→2⁻ f(x) = lim (x³ − 2x + 1) = 8 − 4 + 1 = 5

Step 3: RHL

limx→2⁺ f(x) = lim (3x − 2) = 6 − 2 = 4

Step 4: Check

LHL = 5 ≠ RHL = 4 ✗

∴ f(x) is NOT continuous at x = 2. (Jump discontinuity)
2(ii)
f(x) = (x² + 18x − 19)/(x − 1), for x ≠ 1  |  = 20, for x = 1   at x = 1
Solution

Step 1: f(1) = 20 (given)

Step 2: Find limx→1 f(x)

limx→1 (x² + 18x − 19)/(x − 1)

Factor numerator: (x − 1)(x + 19)

= limx→1 (x + 19) = 1 + 19 = 20

Step 3: Check

limx→1 f(x) = 20 = f(1) ✓

∴ f(x) is continuous at x = 1.
2(iii)
f(x) = x/(tan 3x) + 2, for x < 0  |  = 7/3, for x ≥ 0   at x = 0
Solution

Step 1: f(0) = 7/3 (given)

Step 2: LHL

limx→0⁻ [x/(tan 3x) + 2]

= limx→0 x/(tan 3x) + 2

= limx→0 (x/3x) · (3x/tan 3x) + 2

= (1/3) · 1 + 2 = 7/3

Step 3: Check

LHL = 7/3 = f(0) ✓

∴ f(x) is continuous at x = 0.
Q.3
Find all the points of discontinuities of f(x) = ⌊x⌋ on the interval (−3, 2).
Solution

The greatest integer function ⌊x⌋ is discontinuous at every integer value.

Integers in the open interval (−3, 2):

−2, −1, 0, 1

∴ f(x) is discontinuous at x = −2, −1, 0, 1.
💡 At each integer n: LHL = n−1, RHL = n → LHL ≠ RHL (Jump discontinuity)
Q.4
Discuss the continuity of f(x) = |2x + 3|, at x = −3/2.
Solution

Step 1: f(−3/2)

f(−3/2) = |2(−3/2) + 3| = |−3 + 3| = |0| = 0

Step 2: limx→−3/2 f(x)

|2x + 3| is continuous everywhere (modulus of a polynomial)

lim = |2(−3/2) + 3| = 0

Step 3: Check

lim = 0 = f(−3/2) ✓

∴ f(x) is continuous at x = −3/2.
Q.5 — Test the continuity of the following functions
5(i)
f(x) = [√(x−1) − (x−1)^(1/3)] / (x − 2), for x ≠ 2  |  = 1/5, for x = 2, at x = 2
Solution

Step 1: f(2) = 1/5 (given)

Step 2: Find limx→2 f(x)

Let x − 1 = t, so as x→2, t→1

= limt→1 (t^(1/2) − t^(1/3)) / (t − 1)

= limt→1 [t^(1/2) − 1 − (t^(1/3) − 1)] / (t − 1)

Using: limt→1 (t^n − 1)/(t − 1) = n

= 1/2 − 1/3 = 3/6 − 2/6 = 1/6

Step 3: Check

lim = 1/6 ≠ 1/5 = f(2) ✗

∴ f(x) is NOT continuous at x = 2.
5(ii)
f(x) = (x³ − 8) / (√(x+2) − √(3x−2)), for x ≠ 2  |  = −24, for x = 2, at x = 2
Solution

Step 1: f(2) = −24 (given)

Step 2: Find limx→2 f(x)

Rationalise denominator: multiply by (√(x+2) + √(3x−2))

Denominator becomes: (x+2) − (3x−2) = −2x + 4 = −2(x−2)

Numerator: x³ − 8 = (x−2)(x² + 2x + 4)

lim = limx→2 [(x−2)(x²+2x+4)(√(x+2)+√(3x−2))] / [−2(x−2)]

= (4+4+4)(√4 + √4) / (−2)

= 12 × 4 / (−2) = −24

Step 3: Check

lim = −24 = f(2) ✓

∴ f(x) is continuous at x = 2.
5(iii)
f(x) = 4x + 1, for x ≤ 8/3  |  = (59 − 9x)/3, for x > 8/3, at x = 8/3
Solution

Step 1: f(8/3)

f(8/3) = 4(8/3) + 1 = 32/3 + 3/3 = 35/3

Step 2: LHL

limx→(8/3)⁻ (4x + 1) = 4(8/3) + 1 = 35/3

Step 3: RHL

limx→(8/3)⁺ (59 − 9x)/3 = (59 − 24)/3 = 35/3

Step 4: Check

LHL = RHL = f(8/3) = 35/3 ✓

∴ f(x) is continuous at x = 8/3.
5(iv)
f(x) = [(27 − 2x)^(1/3) − 3] / [9 − 3(243 + 5x)^(1/5)], for x ≠ 0  |  = 2, for x = 0, at x = 0
Solution

Step 1: f(0) = 2 (given)

Step 2: Find limx→0 f(x)

At x=0: Numerator = (27)^(1/3) − 3 = 3 − 3 = 0

Denominator = 9 − 3(243)^(1/5) = 9 − 3(3) = 0 → 0/0 form

Let 27 − 2x = t³  ⟹  t → 3 as x → 0, and 2x = 27 − t³

For denominator: 243 + 5x → use linear approximation

Using derivative approach (L'Hôpital or expansion):

d/dx[(27−2x)^(1/3)] at x=0 = (1/3)(27)^(−2/3)(−2) = −2/27

d/dx[9 − 3(243+5x)^(1/5)] at x=0 = −3·(1/5)(243)^(−4/5)·5 = −3·(1/5)·(1/81)·5 = −3/81 = −1/27

lim = (−2/27) / (−1/27) = 2

Step 3: Check

lim = 2 = f(0) ✓

∴ f(x) is continuous at x = 0.
5(v)
f(x) = (x²+8x−20)/(2x²−9x+10) for 0<x<3, x≠2  |  = 12 for x=2  |  = (2−2x−x²)/(x−4) for 3≤x<4, at x=2
Solution

Step 1: f(2) = 12 (given)

Step 2: Find limx→2 (x²+8x−20)/(2x²−9x+10)

Factor: x²+8x−20 = (x−2)(x+10)

2x²−9x+10 = (2x−5)(x−2)

lim = limx→2 (x+10)/(2x−5) = 12/(−1) = −12

Step 3: Check

lim = −12 ≠ 12 = f(2) ✗

∴ f(x) is NOT continuous at x = 2.
Q.6 — Identify discontinuities as jump or removable
6(i)
f(x) = (x² − 10x + 21) / (x − 7)
Solution

f(x) is undefined at x = 7.

limx→7 (x²−10x+21)/(x−7) = limx→7 (x−3)(x−7)/(x−7) = lim (x−3) = 4

Limit exists but f(7) is not defined.

∴ Removable discontinuity at x = 7. Redefine f(7) = 4 to make it continuous.
6(ii)
f(x) = x² + 3x − 2, for x ≤ 4  |  = 5x + 3, for x > 4
Solution

LHL: limx→4⁻ (x²+3x−2) = 16+12−2 = 26

RHL: limx→4⁺ (5x+3) = 20+3 = 23

LHL ≠ RHL

∴ Jump discontinuity at x = 4.
6(iii)
f(x) = x² − x − 2, for x ≤ −1  |  = x + 1, for x > −1
Solution

LHL: limx→−1⁻ (x²−x−2) = 1+1−2 = 0

RHL: limx→−1⁺ (x+1) = 0

f(−1) = (−1)² − (−1) − 2 = 1+1−2 = 0

LHL = RHL = f(−1) = 0 ✓

∴ f(x) is continuous at x = −1. No discontinuity.
6(iv)
f(x) = 4 + sin x, for x < π  |  = 3 − cos x, for x > π
Solution

LHL: limx→π⁻ (4 + sin x) = 4 + sin π = 4 + 0 = 4

RHL: limx→π⁺ (3 − cos x) = 3 − cos π = 3 − (−1) = 4

LHL = RHL = 4, but f(π) is not defined in the given function.

∴ Removable discontinuity at x = π. Define f(π) = 4 to make it continuous.
Q.7 — Show continuous extensions & find the extension value
7(i)
f(x) = (1 − cos 2x) / sin x, for x ≠ 0
Solution

Find limx→0 (1 − cos 2x) / sin x

Use: 1 − cos 2x = 2sin²x

= limx→0 2sin²x / sin x = limx→0 2sin x = 2 × 0 = 0

∴ Define f(0) = 0. The continuous extension value is 0.
7(ii)
f(x) = (3sin²x + 2cos x(1 − cos 2x)) / (2(1 − cos²x)), for x ≠ 0
Solution

Simplify numerator: 1 − cos 2x = 2sin²x, 1 − cos²x = sin²x

= limx→0 [3sin²x + 2cos x · 2sin²x] / [2sin²x]

= limx→0 [3 + 4cos x] / 2

= (3 + 4·1) / 2 = 7/2

∴ Define f(0) = 7/2. The continuous extension value is 7/2.
7(iii)
f(x) = (x² − 1) / (x³ + 1), for x ≠ −1
Solution

limx→−1 (x²−1)/(x³+1)

= limx→−1 (x−1)(x+1) / (x+1)(x²−x+1)

= limx→−1 (x−1)/(x²−x+1) = (−2)/(1+1+1) = −2/3

∴ Define f(−1) = −2/3. The continuous extension value is −2/3.
Q.8 — Discuss the continuity of the following functions
8(i)
f(x) = (√3 − tan x) / (π − 3x), x ≠ π/3  |  = 3/4, for x = π/3, at x = π/3
Solution

Step 1: f(π/3) = 3/4 (given)

Step 2: Find limx→π/3

Let x = π/3 + h, as x → π/3, h → 0

tan x = tan(π/3 + h) = (tan(π/3) + tan h)/(1 − tan(π/3)·tan h)

π − 3x = π − 3(π/3 + h) = π − π − 3h = −3h

√3 − tan x: using tan x ≈ √3 + (1+3)h = √3 + 4h as h→0

= limh→0 (√3 − √3 − 4h) / (−3h) = (−4h)/(−3h) = 4/3

Step 3: Check

lim = 4/3 ≠ 3/4 = f(π/3) ✗

∴ f(x) is NOT continuous at x = π/3.
8(ii)
f(x) = (e^(1/x) − 1) / (e^(1/x) + 1), for x ≠ 0  |  = 1, for x = 0, at x = 0
Solution

Step 1: f(0) = 1

Step 2: LHL (x → 0⁻, i.e. 1/x → −∞)

e^(1/x) → e^(−∞) = 0

LHL = (0 − 1)/(0 + 1) = −1

Step 3: RHL (x → 0⁺, i.e. 1/x → +∞)

e^(1/x) → +∞

RHL = (∞−1)/(∞+1) → divide by e^(1/x): (1 − 0)/(1 + 0) = 1

LHL = −1 ≠ RHL = 1 → limit doesn't exist

∴ f(x) is NOT continuous at x = 0. (Jump discontinuity)
8(iii)
f(x) = (4ˣ − 2ˣ⁺¹ + 1) / (1 − cos 2x), for x ≠ 0  |  = (log 2)²/2, for x = 0, at x = 0
Solution

Step 1: f(0) = (log 2)²/2

Step 2: Find limx→0

Numerator: 4ˣ − 2·2ˣ + 1 = (2ˣ)² − 2·2ˣ + 1 = (2ˣ − 1)²

Denominator: 1 − cos 2x = 2sin²x

lim = (2ˣ − 1)² / (2sin²x)

= lim [(2ˣ − 1)/x]² / [2(sin x/x)²] as x → 0

= (log 2)² / (2 × 1) = (log 2)²/2

Step 3: Check

lim = (log 2)²/2 = f(0) ✓

∴ f(x) is continuous at x = 0.
Q.9 — Removable discontinuity? If yes, redefine.
9(i)
f(x) = (e^(5 sin x) − e^(2x)) / (5 tan x − 3x), for x ≠ 0  |  = 3/4, for x = 0, at x = 0
Solution

Find limx→0 (e^(5sin x) − e^(2x)) / (5tan x − 3x)

Divide numerator and denominator by x:

Numerator: e^(2x)(e^(5sin x − 2x) − 1) → as x→0, e^(5sin x − 2x) − 1 ≈ (5sin x − 2x)

lim ≈ (5sin x − 2x) / (5tan x − 3x) divide by x

= (5·1 − 2) / (5·1 − 3) = 3/2

lim = 3/2, but f(0) = 3/4 → lim ≠ f(0)

∴ Removable discontinuity. Redefine f(0) = 3/2 to make it continuous.
9(ii)
f(x) = log₍₁₊₃ₓ₎(1 + 5x) for x > 0  |  = (3²ˣ − 1)/(8ˣ − 1) for x < 0, at x = 0
Solution

RHL (x → 0⁺):

limx→0⁺ log₍₁₊₃ₓ₎(1+5x) = lim ln(1+5x)/ln(1+3x)

≈ 5x/3x = 5/3

LHL (x → 0⁻):

limx→0⁻ (3²ˣ − 1)/(8ˣ − 1) = lim (9ˣ − 1)/(8ˣ − 1)

= log 9 / log 8 = 2 log 3 / 3 log 2

LHL ≠ RHL → limit doesn't exist

∴ NOT a removable discontinuity (Jump discontinuity at x = 0).
9(iii)
f(x) = [(3 − 8x)/(3 − 2x)]^(1/x), for x ≠ 0, at x = 0
Solution

limx→0 [(3−8x)/(3−2x)]^(1/x)

= lim exp{(1/x) · ln[(3−8x)/(3−2x)]}

Let L = lim (1/x) · ln(3−8x) − ln(3−2x))

As x→0: ln(3−8x) ≈ ln3 − 8x/3, ln(3−2x) ≈ ln3 − 2x/3

L = lim (1/x)(−8x/3 + 2x/3) = lim (−6x/3)/x = −2

lim f(x) = e^(−2)

∴ Removable discontinuity. Define f(0) = e^(−2) to make it continuous.
9(iv)
f(x) = 3x + 2, for −4 ≤ x ≤ −2  |  = 2x − 3, for −2 ≤ x ≤ 6
Solution

Check at x = −2 (junction point):

LHL: limx→−2⁻ (3x+2) = −6+2 = −4

RHL: limx→−2⁺ (2x−3) = −4−3 = −7

LHL ≠ RHL

∴ Jump discontinuity at x = −2. Not removable.
9(v)
f(x) = (x³ − 8)/(x² − 4) for x > 2  |  = 3 for x = 2  |  = (e^(3(x−2)²−1))/(2(x−2)²) for x < 2
Solution

f(2) = 3

RHL: limx→2⁺ (x³−8)/(x²−4) = lim (x−2)(x²+2x+4)/[(x−2)(x+2)]

= lim (x²+2x+4)/(x+2) = 12/4 = 3

LHL: limx→2⁻ (e^(3(x−2)²) − 1)/(2(x−2)²)

Let t = (x−2)², t→0: lim (eᵗ − 1)/(2t) × 3 → ... = 3/2

= limt→0 3(eᵗ−1)/2t × (1/1) where t = 3(x-2)²:

Actually: lim = lim (e^u − 1)/u × 3/2 where u=3(x-2)² → 0, = 1 × 3/2 = 3/2

LHL = 3/2 ≠ RHL = 3

∴ f(x) is NOT continuous at x = 2. Jump discontinuity.
Q.10 — Find f(value) if f is continuous
10(i)
f(x) = (√(2 + sin x) − √3) / cos²x, for x ≠ π/2. Find f(π/2) if continuous.
Solution

f(π/2) = limx→π/2 (√(2+sin x) − √3) / cos²x

Rationalise: multiply by (√(2+sin x) + √3)

= lim (2+sin x − 3) / [cos²x · (√(2+sin x)+√3)]

= lim (sin x − 1) / [(1−sin²x)(√(2+sin x)+√3)]

= lim (sin x − 1) / [(1−sin x)(1+sin x)(√(2+sin x)+√3)]

= lim −1 / [(1+sin x)(√(2+sin x)+√3)]

At x = π/2: = −1 / [(1+1)(√3+√3)] = −1/(2·2√3) = −1/(4√3)

∴ f(π/2) = −1/(4√3)
10(ii)
f(x) = (cos²x − sin²x − 1) / (√(3x²+1) − 1), for x ≠ 0. Find f(0) if continuous.
Solution

f(0) = limx→0 (cos²x − sin²x − 1)/(√(3x²+1) − 1)

Numerator: cos2x − 1 = −2sin²x

Rationalise denominator: multiply by (√(3x²+1)+1)

= lim −2sin²x (√(3x²+1)+1) / (3x²+1−1)

= lim −2sin²x (√(3x²+1)+1) / 3x²

= −2(sin x/x)² × (1+1)/3 = −2×1×2/3 = −4/3

∴ f(0) = −4/3
10(iii)
f(x) = (4^(x−π) + 4^(π−x) − 2) / (x − π)², for x ≠ π. Find f(π) if continuous.
Solution

f(π) = limx→π (4^(x−π) + 4^(π−x) − 2) / (x−π)²

Let t = x − π, t → 0

= limt→0 (4ᵗ + 4^(−t) − 2) / t²

Let u = 4ᵗ: = lim (u + 1/u − 2)/t² = lim (u−1)²/(u·t²)

= lim [(4ᵗ−1)/t]² / 4ᵗ = (log 4)² / 1 = (log 4)² = (2 log 2)²

∴ f(π) = (log 4)² = 4(log 2)²
Q.11 — Find k if f is continuous at x = 0
11(i)
f(x) = (24ˣ − 8ˣ − 3ˣ + 1) / (12ˣ − 4ˣ − 3ˣ + 1), for x ≠ 0  |  = k, for x = 0
Solution

For continuity at x = 0: k = limx→0 f(x)

Numerator: 24ˣ − 8ˣ − 3ˣ + 1 = (8ˣ − 1)(3ˣ − 1)

Denominator: 12ˣ − 4ˣ − 3ˣ + 1 = (4ˣ − 1)(3ˣ − 1)

lim = lim [(8ˣ−1)/x] / [(4ˣ−1)/x] = log 8 / log 4

= 3 log 2 / 2 log 2 = 3/2

∴ k = 3/2
11(ii)
f(x) = (5ˣ + 5^(−x) − 2) / x², for x ≠ 0  |  = k, for x = 0
Solution

k = limx→0 (5ˣ + 5^(−x) − 2)/x²

Let u = 5ˣ: = lim (u + 1/u − 2)/x² = lim (u−1)²/(u·x²)

= lim [(5ˣ−1)/x]² / 5ˣ = (log 5)² / 1 = (log 5)²

∴ k = (log 5)²
11(iii)
f(x) = sin 2x/(5x) − a for x > 0; = 4 for x = 0; = x² + b − 3 for x < 0. Find a and b.
Solution

For continuity at x = 0:

RHL = f(0):

limx→0⁺ [sin 2x/(5x) − a] = (2/5) − a = 4

⟹ a = 2/5 − 4 = 2/5 − 20/5 = −18/5

LHL = f(0):

limx→0⁻ (x² + b − 3) = b − 3 = 4

⟹ b = 7

∴ a = −18/5, b = 7
11(iv)
f(x) = ax + 2b + 18 for x ≤ 0; = x² + 3a − b for 0 < x ≤ 2; = 8x − 2 for x > 2. Find a, b for continuity for all x.
Solution

At x = 0 (continuity):

limx→0⁻ (ax+2b+18) = 2b+18

limx→0⁺ (x²+3a−b) = 3a−b

f(0) = 2b+18

⟹ 2b + 18 = 3a − b  ⟹  3a − 3b = 18  ⟹  a − b = 6 …(I)

At x = 2 (continuity):

limx→2⁻ (x²+3a−b) = 4+3a−b

limx→2⁺ (8x−2) = 14

⟹ 4 + 3a − b = 14  ⟹  3a − b = 10 …(II)

From (I): b = a − 6; substitute in (II): 3a−(a−6)=10 → 2a+6=10 → a=2

b = 2 − 6 = −4

∴ a = 2, b = −4
11(v)
f(x) = (x²−4)/(x−2) for x < 2; = ax²−bx+3 for 2≤x<3; = 2x−a+b for x≥3. Find a, b for continuity on ℝ.
Solution

At x = 2:

limx→2⁻ (x²−4)/(x−2) = lim (x+2) = 4

f(2) = 4a − 2b + 3

⟹ 4a − 2b + 3 = 4  ⟹  4a − 2b = 1 …(I)

At x = 3:

limx→3⁻ (ax²−bx+3) = 9a − 3b + 3

limx→3⁺ (2x−a+b) = 6 − a + b

⟹ 9a − 3b + 3 = 6 − a + b  ⟹  10a − 4b = 3 …(II)

From (I): 8a − 4b = 2; subtract from (II): 2a = 1 → a = 1/2

b = (4×(1/2) − 1)/2 = (2−1)/2 = 1/2

∴ a = 1/2, b = 1/2
Q.12
Discuss the continuity of f on its domain: f(x) = |x+1|, for −3≤x≤2  |  = |x−5|, for 2<x≤7
Solution

On [−3, 2]: f(x) = |x+1| is continuous (modulus of a polynomial)

On (2, 7]: f(x) = |x−5| is continuous

Check at x = 2 (junction):

LHL = |2+1| = 3

RHL = |2−5| = 3

f(2) = |2+1| = 3

LHL = RHL = f(2) = 3 ✓

∴ f(x) is continuous on its entire domain [−3, 7].
Q.13
Discuss the continuity of f(x) at x = π/4, where f(x) = [(sin x + cos x)³ − 2√2]/(sin 2x − 1), for x ≠ π/4  |  = 3/√2, for x = π/4
Solution

f(π/4) = 3/√2

Find limx→π/4 f(x):

Let t = sin x + cos x. At x=π/4, t = √2

t² = 1 + sin 2x  ⟹  sin 2x = t² − 1

sin 2x − 1 = t² − 2

lim = limt→√2 (t³ − 2√2)/(t² − 2)

= lim (t − √2)(t² + √2t + 2) / [(t−√2)(t+√2)]

= lim (t² + √2t + 2)/(t + √2) = (2 + 2 + 2)/(2√2) = 6/(2√2) = 3/√2

lim = 3/√2 = f(π/4) ✓

∴ f(x) is continuous at x = π/4.
Q.14
Determine p and q such that f(x) = x+1 for 1<x<3; = x²+px+q for |x−2|≥1 is continuous on ℝ.
Solution

|x−2| ≥ 1 means x ≤ 1 or x ≥ 3.

At x = 1 (continuity from right):

limx→1⁺ (x+1) = 2

f(1) = 1 + p + q (from x²+px+q branch)

⟹ 1 + p + q = 2  ⟹  p + q = 1 …(I)

At x = 3 (continuity from left):

limx→3⁻ (x+1) = 4

f(3) = 9 + 3p + q

⟹ 9 + 3p + q = 4  ⟹  3p + q = −5 …(II)

(II) − (I): 2p = −6 → p = −3; q = 1−(−3) = 4

∴ p = −3, q = 4
Q.15
Show that there is a root for 2x³ − x − 16 = 0 between 2 and 3.
Solution (IVT)

Let f(x) = 2x³ − x − 16

f(x) is a polynomial → continuous everywhere.

f(2) = 2(8) − 2 − 16 = 16 − 2 − 16 = −2 < 0

f(3) = 2(27) − 3 − 16 = 54 − 3 − 16 = 35 > 0

f(2) < 0 and f(3) > 0, so by IVT there exists c ∈ (2, 3) such that f(c) = 0.

∴ There is a root of 2x³ − x − 16 = 0 between 2 and 3.
Q.16
Show that there is a root for x³ − 3x = 0 between 1 and 2.
Solution (IVT)

Let f(x) = x³ − 3x

f(x) is a polynomial → continuous everywhere.

f(1) = 1 − 3 = −2 < 0

f(2) = 8 − 6 = 2 > 0

f(1) < 0 and f(2) > 0, so by IVT there exists c ∈ (1, 2) such that f(c) = 0.

∴ There is a root of x³ − 3x = 0 between 1 and 2.

Part (I) — Multiple Choice Questions
MCQ 1
f(x) = (2^(cot x) − 1)/(π − 2x), for x ≠ π/2; = log√2 for x = π/2. Nature of f at x = π/2?
Answer

limx→π/2 (2^(cot x) − 1)/(π − 2x)

Let t = cot x → 0 as x → π/2, and π−2x → 0

cot x ≈ (π/2 − x) = t near π/2, and π−2x = 2(π/2−x) = 2t

= limt→0 (2ᵗ−1)/(2t) = (log 2)/2 = log√2

lim = log√2 = f(π/2) ✓

Answer: (A) f is continuous at x = π/2
MCQ 2
f(x) = (1 − √2 sin x)/(π − 4x), for x ≠ π/4, continuous at x = π/4. Find f(π/4).
Answer

limx→π/4 (1−√2 sin x)/(π−4x)

Let x = π/4 + h: sin x = sin(π/4+h) = (cos h + sin h)/√2

1 − √2 sin x = 1 − (cos h + sin h) = (1 − cos h) − sin h ≈ h² /2 − h as h→0

π − 4x = π − 4(π/4+h) = −4h

lim = (−h)/(−4h) = 1/4

Answer: (D) f(π/4) = 1/4
MCQ 3
f(x) = (sin 2x · tan 5x) / (e^(2x) − 1)², continuous at x=0. Find f(0).
Answer

limx→0 (sin 2x)(tan 5x)/(e^(2x)−1)²

≈ (2x)(5x)/(2x)² = 10x²/4x² = 10/4 = 5/2

Answer: (D) f(0) = 5/2
MCQ 4
f(x) = (x² − 7x + 10)/(x² + 2x − 8), for x ∈ [−6, −3]. Where is f discontinuous?
Answer

Denominator: x² + 2x − 8 = (x+4)(x−2) = 0 ⟹ x = −4 or x = 2

In [−6, −3]: x = −4 is in range; x = 2 is not.

Answer: (B) f is discontinuous at x = −4.
MCQ 5
f(x) = ax²+bx+1 for |x−1|≥3; = 4x+5 for −2<x<4, is continuous everywhere. Find a, b.
Answer

|x−1| ≥ 3 means x ≤ −2 or x ≥ 4.

At x = −2: 4(−2)+5 = −3 = a(4)+b(−2)+1 → 4a−2b = −4 → 2a−b = −2 …(I)

At x = 4: 4(4)+5 = 21 = 16a+4b+1 → 16a+4b = 20 → 4a+b = 5 …(II)

(I)+(II): 6a = 3 → a = 1/2; b = 3

Answer: (A) a = 1/2, b = 3
MCQ 6
f(x) = (16ˣ−1)(9ˣ−1) / [(27ˣ−1)(32ˣ−1)], for x≠0; = k, for x=0. Continuous at x=0, find k.
Answer

k = limx→0 [(16ˣ−1)/x · (9ˣ−1)/x] / [(27ˣ−1)/x · (32ˣ−1)/x]

= (log16 · log9) / (log27 · log32)

= (4log2 · 2log3) / (3log3 · 5log2)

= 8 log2 · log3 / (15 log3 · log2) = 8/15

Answer: (B) k = 8/15
MCQ 7
f(x) = (32ˣ − 8ˣ − 4ˣ + 1) / (4ˣ − 2^(x+1) + 1), for x≠0; = k, for x=0. Find k.
Answer

Numerator: (8ˣ−1)(4ˣ−1)  |  Denominator: (2ˣ−1)²

k = lim [(8ˣ−1)/x · (4ˣ−1)/x] / [(2ˣ−1)/x]²

= (log8 · log4) / (log2)² = (3log2 · 2log2) / (log2)² = 6

Answer: (A) k = 6
MCQ 8
f(x) = (12ˣ − 4ˣ − 3ˣ + 1)/(1 − cos 2x), for x≠0, continuous at x=0. Find f(0).
Answer

Numerator: (4ˣ−1)(3ˣ−1)

Denominator: 1 − cos 2x = 2sin²x

f(0) = lim [(4ˣ−1)/x · (3ˣ−1)/x] / [2(sin x/x)²]

= (log4 · log3) / (2·1) = (log4 · log3)/2 = (log 2 · log 3 · 2)/2 = log 2 · log 3

Answer: (B) f(0) = log2 · log3
MCQ 9
f(x) = [(4+5x)/(4−7x)]^(4/x), for x≠0; f(0)=k. Continuous at x=0, find k.
Answer

k = limx→0 [(4+5x)/(4−7x)]^(4/x)

= exp{lim (4/x) · ln[(4+5x)/(4−7x)]}

lim (1/x)[ln(4+5x) − ln(4−7x)] = 5/4 + 7/4 = 12/4 = 3

k = e^(4×3) = e¹²

Answer: (C) k = e¹²
MCQ 10
f(x) = ⌊x⌋ for x ∈ (−1, 2). Where is f discontinuous?
Answer

⌊x⌋ is discontinuous at every integer in (−1, 2): at x = 0 and x = 1.

Answer: (C) x = 0, 1
Part (II) — Discuss Continuity
II.1
f(x) = (x²−3x−10)/(x−5) for 3≤x≤6, x≠5; = 10 for x=5; = (x²−3x−10)/(x−5) for 6<x≤9
Solution

At x = 5: limx→5 (x²−3x−10)/(x−5) = lim (x+2) = 7

f(5) = 10 ≠ 7 → Discontinuous at x = 5.

At x = 6 (junction of branches):

Both branches use same formula; lim from left = lim from right → Continuous at x = 6.

∴ f is discontinuous at x = 5 only (removable). Continuous elsewhere on [3,9].
II.2
f(x) = 2x²−2x+5 for 0≤x≤2; = (1−3x−x²)/(1−x) for 2<x<4; = (x²−25)/(x−5) for 4≤x≤7, x≠5; = 7 for x=5
Solution

At x = 2:

LHL: f(2) = 2(4)−2(2)+5 = 9

RHL: limx→2⁺ (1−3x−x²)/(1−x) = (1−6−4)/(1−2) = (−9)/(−1) = 9 ✓

At x = 4:

LHL: limx→4⁻ (1−3x−x²)/(1−x) = (1−12−16)/(1−4) = (−27)/(−3) = 9

RHL: limx→4⁺ (x²−25)/(x−5) = lim (x+5) = 9 ✓

At x = 5:

limx→5 (x²−25)/(x−5) = lim (x+5) = 10 ≠ 7 = f(5) ✗

∴ f is continuous everywhere on [0,7] except at x = 5 (removable discontinuity).
Part (III) — Identify Discontinuities
III.1
f(x) = x²+x−3 for x∈[−5,−2); = x²−5 for x∈(−2,5]
Solution

LHL at x=−2: lim (x²+x−3) = 4−2−3 = −1

RHL at x=−2: lim (x²−5) = 4−5 = −1

f(−2) is not defined (open intervals exclude −2).

∴ Removable discontinuity at x = −2. Define f(−2) = −1.
III.2
f(x) = x²+5x+1 for 0≤x≤3; = x³+x+5 for 3<x≤6
Solution

LHL at x=3: f(3) = 9+15+1 = 25

RHL at x=3: limx→3⁺ (x³+x+5) = 27+3+5 = 35

LHL ≠ RHL

∴ Jump discontinuity at x = 3.
III.3
f(x) = (x²+x+1)/(x+1) for x∈[0,3); = (3x+4)/(x²−5) for x∈[3,6]
Solution

LHL at x=3: lim (x²+x+1)/(x+1) = (9+3+1)/4 = 13/4 = 3.25

RHL at x=3: (9+4)/(9−5) = 13/4 = 3.25 ✓

f(3) = 13/4

Check denominator of 2nd branch: x²−5 = 0 at x = √5 ∉ [3,6] → no issue

∴ f is continuous at x = 3. No discontinuity on [0,6].
Part (IV) — Discuss, Identify Type, Redefine if Removable
IV.1
f(x) = (x+3)(x²−6x+8) / (x²−x−12)
Solution

x²−x−12 = (x−4)(x+3)

f(x) = (x+3)(x²−6x+8) / [(x−4)(x+3)] = (x²−6x+8)/(x−4) = (x−4)(x−2)/(x−4) = x−2, x≠4, x≠−3

At x = −3: limx→−3 f(x) = −3−2 = −5 (limit exists, f undefined)

→ Removable. Redefine f(−3) = −5.

At x = 4: limx→4 (x−2) = 2 (limit exists, f undefined)

→ Removable. Redefine f(4) = 2.

∴ Removable discontinuities at x = −3 (redefine as −5) and x = 4 (redefine as 2).
IV.2
f(x) = x²+2x+5 for x≤3; = x³−2x²−5 for x>3
Solution

LHL at x=3: 9+6+5 = 20

RHL at x=3: 27−18−5 = 4

LHL ≠ RHL

∴ Jump discontinuity at x = 3. Not removable.
Part (V) — Find k for continuity
V.1
f(x) = [(5x−8)/(8−3x)]^(3/(2x−4)), for x≠2; = k, for x=2
Solution

k = limx→2 [(5x−8)/(8−3x)]^(3/(2x−4))

At x=2: base = (10−8)/(8−6) = 2/2 = 1, exponent → ∞ → 1^∞ form

= exp{lim [3/(2x−4)] · ln[(5x−8)/(8−3x)]}

Let x = 2+h: base = (5(2+h)−8)/(8−3(2+h)) = (2+5h)/(2−3h)

ln[(2+5h)/(2−3h)] ≈ 5h/2 + 3h/2 = 4h as h→0

exponent = 3/(2h) · 4h = 6 as h→0

But more carefully: ln(1+5h/2) − ln(1−3h/2) ≈ 5h/2 + 3h/2 = 4h

= exp{(3/2h)·4h} = exp{6} ... Wait: 3/(2x−4) = 3/(2h), so = exp{(3/2h)·4h} = e^6

Actual: (2+5h)/(2−3h) = 1 + (8h)/(2−3h) ≈ 1 + 4h as h→0

ln base ≈ 4h; exponent = 3/(2h) × 4h = 6

∴ k = e⁶
V.2
f(x) = (45ˣ − 9ˣ − 5ˣ + 1) / [(kˣ−1)(3ˣ−1)], for x≠0; = 2/3, for x=0
Solution

For continuity: limx→0 f(x) = 2/3

Numerator: 45ˣ−9ˣ−5ˣ+1 = (9ˣ−1)(5ˣ−1)

lim = [(9ˣ−1)/x · (5ˣ−1)/x] / [(kˣ−1)/x · (3ˣ−1)/x]

= (log9 · log5) / (log k · log3) = 2/3

= (2log3 · log5) / (log k · log3) = log5 · 2 / log k = 2/3

⟹ log k / log5 = 3 ⟹ log k = 3 log5 ⟹ k = 5³ = 125

∴ k = 125
Part (VI) — Find a and b
VI.1
f(x) = (4tan x + 5sin x)/(aˣ−1) for x<0; = 9/log2 for x=0; = (11x+7x·cos x)/(bˣ−1) for x>0
Solution

For continuity, LHL = f(0) = RHL = 9/log2

LHL: limx→0⁻ (4tan x+5sin x)/(aˣ−1)

= lim (4·x + 5·x) / (x·log a) = 9/(log a)

9/log a = 9/log 2 ⟹ a = 2

RHL: limx→0⁺ (11x+7x·cos x)/(bˣ−1)

= lim x(11+7cos x)/(x·log b) = (11+7)/log b = 18/log b

18/log b = 9/log 2 ⟹ log b = 2 log 2 = log 4 ⟹ b = 4

∴ a = 2, b = 4
VI.2
f(x) = ax²+bx+1 for |2x−3|≥2; = x+2 for 1/2<x<5/2. Find a, b.
Solution

|2x−3| ≥ 2 means x ≤ 1/2 or x ≥ 5/2.

At x = 1/2:

RHL = limx→(1/2)⁺ (x+2) = 5/2

f(1/2) = a/4 + b/2 + 1 = 5/2 ⟹ a + 2b = 6 …(I)

At x = 5/2:

LHL = limx→(5/2)⁻ (x+2) = 9/2

f(5/2) = 25a/4 + 5b/2 + 1 = 9/2 ⟹ 25a + 10b = 10 ⟹ 5a+2b=2 …(II)

(II)−(I): 4a = −4 → a = −1; b = (6−a)/2 = 7/2

∴ a = −1, b = 7/2
Part (VII) — Find f(a) if f is continuous at x = a
VII.1
f(x) = (1 + cos(πx)) / [π(1−x)²], for x≠1. Find f(1).
Solution

f(1) = limx→1 (1+cos πx)/[π(1−x)²]

Let x = 1 − h, h→0: cos πx = cos π(1−h) = cos(π−πh) = −cos(πh)

1 + cos πx = 1 − cos πh = 2sin²(πh/2)

= limh→0 2sin²(πh/2) / (πh²)

= lim 2[sin(πh/2)/(πh/2)]² × (π/2)²/π

= 2 × 1 × π²/4 / π = π/2

∴ f(1) = π/2
VII.2
f(x) = (1 − cos[7(x−π)]) / [5(x−π)²], for x≠π. Find f(π).
Solution

f(π) = limx→π [1−cos 7(x−π)] / [5(x−π)²]

Let t = x − π, t→0:

= limt→0 (1−cos 7t)/(5t²) = lim 2sin²(7t/2)/(5t²)

= 2[sin(7t/2)/(7t/2)]² × (7/2)²/5 = 2×1×49/4 / 5 = 49/10

∴ f(π) = 49/10
Part (VIII) — Solve using Intermediate Value Theorem
VIII.1
Show that 5ˣ − 6x = 0 has a root in [1, 2].
Solution (IVT)

Let f(x) = 5ˣ − 6x

f is continuous on [1, 2] (exponential and linear functions are continuous).

f(1) = 5 − 6 = −1 < 0

f(2) = 25 − 12 = 13 > 0

f(1) < 0 and f(2) > 0 → By IVT, ∃ c ∈ (1, 2) such that f(c) = 0.

∴ 5ˣ − 6x = 0 has a root in [1, 2].
VIII.2
Show that x³ − 5x² + 3x + 6 = 0 has at least two real roots between x = 1 and x = 5.
Solution (IVT)

Let f(x) = x³ − 5x² + 3x + 6 (polynomial → continuous everywhere)

f(1) = 1 − 5 + 3 + 6 = 5 > 0

f(2) = 8 − 20 + 6 + 6 = 0 → x = 2 is itself a root!

f(3) = 27 − 45 + 9 + 6 = −3 < 0

f(5) = 125 − 125 + 15 + 6 = 21 > 0

Between 1 and 3: f(1) > 0, f(3) < 0 → root in (1, 3) ← (x=2 confirmed)

Between 3 and 5: f(3) < 0, f(5) > 0 → By IVT, ∃ root in (3, 5)

∴ x³−5x²+3x+6 = 0 has at least two real roots between x = 1 and x = 5.

Let's Remember — Quick Revision Summary

✅ 3 Conditions for Continuity at x = a

① f(a) is defined
② limx→a f(x) exists (LHL = RHL)
③ limx→a f(x) = f(a)

⚠️ Types of Discontinuity

TypeConditionFix?
RemovableLimit exists but ≠ f(a) or f(a) undefinedYes — redefine f(a)
JumpLHL ≠ RHL (both exist)No
InfiniteLimit = ±∞No

📈 Intermediate Value Theorem

If f is continuous on [a, b] and k is any value between f(a) and f(b), then
∃ c ∈ [a, b] such that f(c) = k
Use for root-finding: If f(a) and f(b) have opposite signs, f has a root in (a, b).
