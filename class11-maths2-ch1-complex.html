📚 Chapter 1 – Complex Numbers: Theory Notes
1.1 Introduction to Complex Numbers

What is a Complex Number?

A complex number is a number of the form z = a + ib, where:

  • a = Real part = Re(z)
  • b = Imaginary part = Im(z)
  • i = √−1 (iota), so i² = −1
i = √−1  |  i² = −1  |  i³ = −i  |  i⁴ = 1
Pattern repeats every 4: i⁵=i, i⁶=−1, i⁷=−i, i⁸=1 ...
💡 For any √(−n): √(−n) = √n × √(−1) = √n × i   e.g. √(−16) = 4i
1.2 Powers of i

Finding iⁿ for Large Powers

Divide the power by 4 and check the remainder:

Remainder when n÷40123
iⁿ =1i−1−i
iⁿ: divide n by 4 → use remainder
e.g. i³⁵: 35 ÷ 4 = 8 rem 3 → i³⁵ = i³ = −i
e.g. i⁸⁸⁸: 888 ÷ 4 = 222 rem 0 → i⁸⁸⁸ = 1
💡 For negative powers: i⁻ⁿ = 1/iⁿ. Multiply top and bottom by iⁿ to simplify.
1.3 Operations on Complex Numbers

Equality, Addition, Subtraction, Multiplication

  • Equality: a+ib = c+id ⟺ a=c AND b=d
  • Addition: (a+ib)+(c+id) = (a+c)+i(b+d)
  • Subtraction: (a+ib)−(c+id) = (a−c)+i(b−d)
  • Multiplication: (a+ib)(c+id) = (ac−bd)+i(ad+bc)

Division — Rationalising the Denominator

Multiply numerator and denominator by the conjugate of the denominator:

(a+ib)/(c+id) = [(a+ib)(c−id)] / [(c+id)(c−id)]
= [(ac+bd) + i(bc−ad)] / (c²+d²)
💡 Conjugate of (c+id) = (c−id). Product of conjugates = c²+d² (always real!)

Conjugate of a Complex Number

If z = a+ib, then conjugate z̄ = a−ib
z + z̄ = 2a (real)  |  z − z̄ = 2ib (imaginary)
z × z̄ = a²+b² = |z|²
1.4 Square Root of a Complex Number

Method to Find √(x+iy)

Let √(x+iy) = a+ib. Square both sides:

x+iy = (a+ib)² = (a²−b²) + 2abi
Equate real parts: x = a²−b²
Equate imaginary parts: y = 2ab

Use: (a²+b²)² = (a²−b²)² + (2ab)² = x² + y²
∴ a²+b² = √(x²+y²)

Then solve: a²+b² = √(x²+y²) and a²−b² = x
1.5 Quadratic Equations in Complex Numbers

Quadratic Formula

For ax² + bx + c = 0:
x = [−b ± √(b²−4ac)] / 2a

Discriminant D = b²−4ac
If D < 0 → roots are complex (conjugate pairs)
💡 If p+iq is a root with a,b,c ∈ R, then p−iq is also a root. Complex roots come in conjugate pairs!
1.6 Argand Diagram, Modulus & Argument

Argand Diagram

z = a+ib is represented as point P(a,b) in a plane:

  • X-axis = Real axis
  • Y-axis = Imaginary axis
  • Modulus |z| = r = √(a²+b²) = distance from origin to P
  • Argument (arg z) = θ = angle OP makes with positive X-axis
|z| = √(a²+b²)
arg z = θ = tan⁻¹(b/a)   [adjust for quadrant!]
