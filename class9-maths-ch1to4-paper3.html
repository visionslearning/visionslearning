Choose the correct alternative. (MCQ) ⭐ Most IMP
5 Marks
Ch1⭐ i. If A = {x | x is a prime number less than 10}, then n(A) = ________.
Step 1 Primes less than 10: 2, 3, 5, 7 → 4 elements n(A) = 4
Ch2⭐ ii. Which of the following is NOT a real number?
√−4 is NOT a real number (it is imaginary; √−4 = 2i). All others like √4=2, −3, 0.5 are real.
Ch3⭐ iii. By Factor Theorem, (x − a) is a factor of p(x) if and only if ________.
p(a) = 0   (Factor Theorem: (x−a) is a factor of p(x) if and only if p(a) = 0)
Ch4⭐ iv. The mean proportional of 9 and 16 is ________.
Formula Mean proportional = √(a × b) Step 1 = √(9 × 16) = √144 = 12 Mean proportional = 12
Ch3⭐ v. Using identity, (99)² = (100 − 1)² = ________.
Identity (a−b)² = a² − 2ab + b² Step 1 = (100)² − 2(100)(1) + (1)² = 10000 − 200 + 1 = 9801 99² = 9801
2
State whether True or False. Correct the false statements.
4 Marks
Ch1⭐ i. n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
TRUE ✓ — This is the Addition theorem (Inclusion-Exclusion principle) for two sets.
Ch3⭐ ii. A polynomial can have more zeros than its degree.
FALSE ✗ — A polynomial of degree n has AT MOST n zeros (real zeros ≤ degree).
Ch2⭐ iii. The product of a rational and irrational number is always irrational.
TRUE ✓ — (provided the rational number ≠ 0). E.g., 3 × √2 = 3√2 (irrational). Exception: 0 × √2 = 0 (rational).
Ch4⭐ iv. In proportion a:b::c:d, the product of means equals the product of extremes.
TRUE ✓ — b × c = a × d (means product = extremes product). This is the fundamental property of proportion.

Ch1⭐ i. The number of subsets of a set with n elements is ________.
2ⁿ   (e.g., if n=3 elements, number of subsets = 2³ = 8)
Ch2⭐ ii. 0.142857142857... is a ________ decimal (type of rational number).
Non-terminating repeating (recurring) decimal — hence a rational number. (0.142857̄ = 1/7)

a² − b² = (a+b)(a−b)   [Difference of squares identity]
Ch4⭐ iv. If a : b = 2 : 3 and b : c = 3 : 5, then a : b : c = ________.
Step 1 b value is common (3 in both), so a:b:c = 2:3:5 a : b : c = 2 : 3 : 5

Ch1⭐ A. Write all subsets of A = {p, q, r}.
Rule Number of subsets = 2³ = 8 Step 1 Subsets of 0 elements: { } (empty set) Step 2 Subsets of 1 element: {p}, {q}, {r} Step 3 Subsets of 2 elements: {p,q}, {p,r}, {q,r} Step 4 Subset of 3 elements: {p,q,r} Total 8 subsets: ∅, {p}, {q}, {r}, {p,q}, {p,r}, {q,r}, {p,q,r}
Ch2⭐ B. Simplify: (√5 + √2)²
Identity (a+b)² = a² + 2ab + b² Step 1 = (√5)² + 2(√5)(√2) + (√2)² Step 2 = 5 + 2√10 + 2 (√5 + √2)² = 7 + 2√10
Ch3⭐ C. Check whether (x + 2) is a factor of p(x) = x³ + 3x² + x − 2.
Factor Theorem (x+2) is factor iff p(−2) = 0 Step 1 p(−2) = (−2)³ + 3(−2)² + (−2) − 2 Step 2 = −8 + 12 − 2 − 2 = 0 p(−2) = 0 ∴ (x+2) IS a factor of p(x). ✓
Ch4⭐ D. The ratio of boys to girls in a class is 3:2. If there are 30 boys, how many girls are there? What is the total strength?
Step 1 Boys : Girls = 3 : 2    Boys = 30 Step 2 3 parts = 30 → 1 part = 10 Step 3 Girls = 2 × 10 = 20 Step 4 Total = 30 + 20 = 50 Girls = 20   Total strength = 50
Ch3⭐ E. Evaluate using identity: 103 × 97
Identity (a+b)(a−b) = a² − b² Step 1 103 × 97 = (100+3)(100−3) Step 2 = (100)² − (3)² Step 3 = 10000 − 9 103 × 97 = 9991

Ch2⭐ A. Express 0.3̄2̄ (= 0.323232...) as a rational number p/q.
Step 1 Let x = 0.323232... Step 2 Multiply by 100: 100x = 32.3232... Step 3 100x − x = 32.3232... − 0.3232... Step 4 99x = 32 Step 5 x = 32/99 0.32̄ = 32/99   (verify: 32÷99 = 0.323232... ✓)
Ch3⭐ B. Factorise using appropriate identities: (i) 8x³ + 27    (ii) x³ − 64    (iii) 2x² + 7x + 3
(i) 8x³ + 27: Identity a³ + b³ = (a+b)(a²−ab+b²) Step 1 = (2x)³ + (3)³  →  a=2x, b=3 (2x+3)(4x²−6x+9) (ii) x³ − 64: Identity a³ − b³ = (a−b)(a²+ab+b²) Step 1 = x³ − 4³  →  a=x, b=4 (x−4)(x²+4x+16) (iii) 2x² + 7x + 3: Step 1 Multiply: 2 × 3 = 6; find two numbers: product=6, sum=7 → 1 and 6 Step 2 = 2x² + x + 6x + 3 = x(2x+1) + 3(2x+1) 2x² + 7x + 3 = (2x+1)(x+3)
Ch4⭐ C. If a/b = c/d, prove that (a+b)/(a−b) = (c+d)/(c−d). (Componendo-Dividendo)
Given a/b = c/d  →  let a/b = c/d = k  →  a = bk, c = dk LHS: Step 1 (a+b)/(a−b) = (bk+b)/(bk−b) = b(k+1)/b(k−1) = (k+1)/(k−1) RHS: Step 2 (c+d)/(c−d) = (dk+d)/(dk−d) = d(k+1)/d(k−1) = (k+1)/(k−1) LHS = RHS = (k+1)/(k−1)   ∴ Proved ✓   (This is Componendo-Dividendo rule)

Ch3⭐ A. State and prove the Remainder Theorem. Use it to find the remainder when p(x) = 2x³ − 3x² + x − 5 is divided by (x − 2). Also check if (x−2) is a factor. (5M)
Remainder Theorem Statement: If a polynomial p(x) of degree ≥ 1 is divided by (x − a), then the remainder is p(a). Proof: Step 1 By division algorithm: p(x) = (x−a)·q(x) + r, where r is constant (remainder). Step 2 Substitute x = a: p(a) = (a−a)·q(a) + r = 0·q(a) + r = r ∴ Remainder = p(a)   Proved ✓ Application — p(x) = 2x³ − 3x² + x − 5, divided by (x−2): Step 3 Remainder = p(2) = 2(2)³ − 3(2)² + (2) − 5 Step 4 = 2(8) − 3(4) + 2 − 5 Step 5 = 16 − 12 + 2 − 5 = 1 Remainder = 1 Factor check Since remainder = 1 ≠ 0, (x−2) is NOT a factor of p(x).
Ch4⭐ B. Solve word problems on ratio & proportion: (6M)

(i) A map is drawn to a scale of 1:50000. If two cities are 15 cm apart on the map, find their actual distance in km.
(ii) A car covers 270 km in 3 hours. How far will it travel in 5 hours at the same speed?
(iii) 12 workers finish a job in 8 days. How many days will 16 workers take (assuming same work rate)?
(i) Map scale problem: Step 1 Scale 1:50000 means 1 cm = 50000 cm actual Step 2 15 cm on map = 15 × 50000 cm = 750000 cm actual Step 3 = 750000 ÷ 100000 = 7.5 km Actual distance = 7.5 km (ii) Direct proportion: Step 1 3 hours → 270 km; 1 hour → 90 km (speed = 90 km/h) Step 2 5 hours → 5 × 90 = 450 km Distance in 5 hours = 450 km (iii) Inverse proportion (more workers → fewer days): Step 1 Workers × Days = constant (total work) Step 2 12 × 8 = 16 × d  →  d = 96/16 = 6 days 16 workers will finish in 6 days
