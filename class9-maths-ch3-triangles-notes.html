Key Notes

1. Angle Sum Property of a Triangle

★ Key Fact
The sum of all three interior angles of any triangle is always 180°.

∠A + ∠B + ∠C = 180°

2. Theorem — Remote Interior Angles

Theorem
Statement: The measure of an exterior angle of a triangle is equal to the sum of its two remote (non-adjacent) interior angles.

If ∠PRS is an exterior angle of △PQR, then:
∠PRS = ∠PQR + ∠QPR
Proof (Step-by-Step)
1. In △PQR:   ∠PQR + ∠QPR + ∠PRQ = 180°  …(I) [angle sum]
2. ∠PRQ + ∠PRS = 180°  …(II) [linear pair]
3. From (I) and (II):   ∠PQR + ∠QPR + ∠PRQ = ∠PRQ + ∠PRS
4. Cancel ∠PRQ from both sides:   ∠PQR + ∠QPR = ∠PRS  ✓

3. Property of an Exterior Angle

★ Key Property
Since ∠PRS = ∠PQR + ∠QPR, and both remote interior angles are positive:

∠PRS > ∠P     and     ∠PRS > ∠Q

∴ An exterior angle of a triangle is always greater than either of its remote interior angles.

4. Sum of Exterior Angles of a Triangle = 360°

Theorem
The sum of the three exterior angles of a triangle (each formed by extending sides in the same direction) is 360°.
Proof — Method I (using remote interior angle theorem)
1. ∠PAB = ∠ABC + ∠ACB  …(I)
2. ∠ACR = ∠ABC + ∠BAC  …(II)
3. ∠CBQ = ∠BAC + ∠ACB  …(III)
4. Adding (I)+(II)+(III):   = 2(∠ABC + ∠ACB + ∠BAC) = 2 × 180° = 360°
Proof — Method II (using linear pairs)
• Each interior angle + its exterior angle = 180° (linear pair)
• ∠c + ∠f = 180°,   ∠a + ∠d = 180°,   ∠b + ∠e = 180°
• Sum all:   (∠a+∠b+∠c) + (∠d+∠e+∠f) = 540°
• 180° + (∠d+∠e+∠f) = 540°
∴ ∠d + ∠e + ∠f = 360°  ✓

5. Angle Bisectors Meet at Incenter

★ Key Result
If bisectors of ∠B and ∠C of △ABC intersect at point P, then:

∠BPC = 90° + ½ ∠BAC

Logic:   ∠PBC + ∠PCB = 90° − ½∠BAC, and by angle sum in △BPC, ∠BPC = 180° − (90° − ½∠BAC) = 90° + ½∠BAC

Solved Examples

Ex 1 Angles of a triangle are in ratio 5 : 6 : 7. Find the measures.
Solution:
  • Let the angles be 5x, 6x, 7x
  • 5x + 6x + 7x = 180°
  • 18x = 180°  ⟹  x = 10°
  • 5x = 50°,   6x = 60°,   7x = 70°
Answer
The three angles are 50°, 60°, and 70°.
Ex 2 Find ∠PRS and ∠RTS from figure 3.4 (given ∠QPR = 30°, ∠PQR = 40°, ∠TSR = 20°).
Solution:
  • ∠PRS is an exterior angle of △PQR
  • By remote interior angle theorem:   ∠PRS = ∠PQR + ∠QPR = 40° + 30° = 70°
  • In △RTS:   ∠TRS + ∠RTS + ∠TSR = 180°
  • Note: ∠TRS = ∠PRS = 70° (same angle), ∠TSR = 20°
  • 70° + ∠RTS + 20° = 180°
  • ∠RTS + 90° = 180°
  • ∠RTS = 90°
Answer
∠PRS = 70°  &  ∠RTS = 90°
Ex 3 Prove: Sum of exterior angles of a triangle = 360°
Given:  ∠PAB, ∠QBC, ∠ACR are exterior angles of △ABC.
To Prove:  ∠PAB + ∠QBC + ∠ACR = 360°

Proof (Method I):
  • ∠PAB = ∠ABC + ∠ACB  …(I) [remote int. angles]
  • ∠ACR = ∠ABC + ∠BAC  …(II)
  • ∠CBQ = ∠BAC + ∠ACB  …(III)
  • Adding: = 2∠ABC + 2∠ACB + 2∠BAC = 2(180°) = 360°  ✓
Ex 4 Bisectors of ∠B and ∠C of △ABC meet at P. Prove: ∠BPC = 90° + ½∠BAC
Proof:
  • In △ABC:  ∠BAC + ∠ABC + ∠ACB = 180°
  • Divide by 2:  ½∠BAC + ½∠ABC + ½∠ACB = 90°
  • Since BP bisects ∠B:  ∠PBC = ½∠ABC; since CP bisects ∠C:  ∠PCB = ½∠ACB
  • So:  ½∠BAC + ∠PBC + ∠PCB = 90°
  • ⟹  ∠PBC + ∠PCB = 90° − ½∠BAC  …(I)
  • In △BPC:  ∠BPC + ∠PBC + ∠PCB = 180°
  • Using (I):  ∠BPC + (90° − ½∠BAC) = 180°
  • ∠BPC = 90° + ½∠BAC  ✓
Hence Proved
∠BPC = 90° + ½∠BAC

Practice Set 3.1 — Solutions

Q1. In figure 3.8, ∠ACD is an exterior angle of △ABC. ∠B = 40°, ∠A = 70°. Find ∠ACD.
Solution:
  • ∠ACD is an exterior angle of △ABC.
  • By remote interior angle theorem:  ∠ACD = ∠A + ∠B
  • ∠ACD = 70° + 40°
Answer
∠ACD = 110°
Q2. In △PQR, ∠P = 70°, ∠Q = 65°. Find ∠R.
Solution:
  • Angle sum property:  ∠P + ∠Q + ∠R = 180°
  • 70° + 65° + ∠R = 180°
  • ∠R = 180° − 135°
Answer
∠R = 45°
Q3. Angles of a triangle are x°, (x−20)°, (x−40)°. Find each angle.
Solution:
  • x + (x−20) + (x−40) = 180°
  • 3x − 60 = 180°
  • 3x = 240°  ⟹  x = 80°
  • Angles: x = 80°,  x−20 = 60°,  x−40 = 40°
Answer
The three angles are 80°, 60°, and 40°.
Verification: 80 + 60 + 40 = 180° ✓
Q4. One angle is twice the smallest; another is thrice the smallest. Find all three angles.
Solution:
  • Let the smallest angle = x
  • Second angle = 2x,   Third angle = 3x
  • x + 2x + 3x = 180°
  • 6x = 180°  ⟹  x = 30°
  • Angles: 30°, 60°, 90°
Answer
The three angles are 30°, 60°, and 90°.
Note: This is a right-angled triangle! Verification: 30 + 60 + 90 = 180° ✓

Memory Tips

★ Quick Tricks to Remember
  • Ext. angle = Sum of 2 remote interior angles — think of it as "the outside angle collects the two angles far away."
  • Exterior > each remote interior — since it equals their sum, it must be bigger than each one alone.
  • 3 exterior angles = 360° — same as one full rotation around a point.
  • For ratio problems — always set angles as kx, mx, nx and use sum = 180°.
  • For bisector problems — divide the whole angle equation by 2 first, then use triangle angle sum.
