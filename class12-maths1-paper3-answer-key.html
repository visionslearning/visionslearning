Q.2 (xi)
Check the differentiability of f(x) = |x| at x = 0.
LHD LHD = lim(h→0⁺)[f(0−h)−f(0)]/−h = lim(h→0⁺)[h−0]/(−h) = −1
RHD RHD = lim(h→0⁺)[f(0+h)−f(0)]/h = lim(h→0⁺)[h−0]/h = +1
Conclusion
LHD ≠ RHD → f(x) = |x| is NOT differentiable at x = 0

Q.3 (ii)
Show that f: ℝ→ℝ defined by f(x) = (x−1)/(x+1) is one-one but not onto.
One-One Let f(x₁) = f(x₂): (x₁−1)/(x₁+1) = (x₂−1)/(x₂+1) (x₁−1)(x₂+1) = (x₂−1)(x₁+1) → x₁x₂+x₁−x₂−1 = x₁x₂−x₁+x₂−1 2x₁ = 2x₂ → x₁ = x₂ → f is one-one ✓
Not Onto Let f(x) = y: (x−1)/(x+1) = y → x−1 = yx+y → x(1−y) = y+1 → x = (y+1)/(1−y) For y = 1: x is not defined (division by zero) → y = 1 ∉ range Range = ℝ \ {1} ≠ ℝ → f is NOT onto ✓

Evaluate ∫₀^(π/4) log(1 + tan x) dx.
Method Let I = ∫₀^(π/4) log(1 + tan x) dx Using property: ∫₀^a f(x)dx = ∫₀^a f(a−x)dx Replace x with (π/4 − x): I = ∫₀^(π/4) log(1 + tan(π/4−x)) dx = ∫₀^(π/4) log(2/(1+tanx)) dx = ∫₀^(π/4) [log 2 − log(1+tan x)] dx = (π/4)log 2 − I 2I = (π/4)log 2 → I = (π/8)log 2

Q.4 (viii)
Show that f(x) = 3x⁴ + 4x³ − 12x² + 12 has maxima at x=0 and minima at x=1 and x=−2.
f'(x) f'(x) = 12x³ + 12x² − 24x = 12x(x² + x − 2) = 12x(x+2)(x−1) Critical points: x = 0, x = −2, x = 1
f''(x) Test f''(x) = 36x² + 24x − 24 f''(0) = −24 < 0 → local maximum at x = 0. f(0) = 12 f''(1) = 36+24−24 = 36 > 0 → local minimum at x = 1. f(1) = 3+4−12+12 = 7 f''(−2) = 144−48−24 = 72 > 0 → local minimum at x = −2. f(−2) = 48−32−48+12 = −20
