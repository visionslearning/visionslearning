SECTION A — MCQ Answers 8 × 1 = 8
(i) P(A∩B) when P(A)=1/4, P(B)=1/3, independent
Answer: (B) 1/12
For independent events: P(A∩B) = P(A) × P(B) 1/4 × 1/3 = 1/12 1/12
(ii) Variance of Binomial distribution B(n,p)
Answer: (C) npq
For B(n,p): Mean = np, Variance = npq where q = 1−p Variance = npq
(iii) byx when y = 2x + 5
Answer: (A) 2
In regression line y = byx·x + a, the coefficient of x is byx Here y = 2x + 5 → byx = 2
(iv) Optimal solution of L.P.P.
Answer: (B) Corner point of feasible region
By the Corner Point Theorem (Fundamental Theorem of L.P.P.), the optimal value of the objective function occurs at one of the corner (vertex) points of the feasible region.
(v) Mode formula for moderately skewed
Answer: (D) 3 Median − 2 Mean
Empirical relation: Mode = 3 Median − 2 Mean This is valid for moderately skewed (asymmetric) distributions.
(vi) byx when r = 0.6, bxy = 0.3
Answer: (B) 1.2
r² = byx × bxy byx = r²/bxy = (0.6)²/0.3 = 0.36/0.3 byx = 1.2
(vii) Poisson: mean=4, P(X=0)
Answer: (C) e⁻⁴
P(X=x) = e⁻λ·λˣ/x! P(X=0) = e⁻⁴·4⁰/0! = e⁻⁴ × 1 / 1 = e⁻⁴

Laspeyre's Index = (Σp₁q₀/Σp₀q₀) × 100 It uses base year quantities (q₀) as weights.

(ii) X: 0,1,2,3; P(X): k,2k,3k,k — find k, E(X), Var(X)
Sum of probabilities = 1: k + 2k + 3k + k = 7k = 1 → k = 1/7 E(X) = Σ x·P(X) = 0×(1/7) + 1×(2/7) + 2×(3/7) + 3×(1/7) 0 + 2/7 + 6/7 + 3/7 = 11/7 E(X) = 11/7 ≈ 1.57 E(X²) = 0 + 1×(2/7) + 4×(3/7) + 9×(1/7) = 2/7+12/7+9/7 = 23/7 Var(X) = E(X²) − [E(X)]² = 23/7 − (11/7)² = 23/7 − 121/49 161/49 − 121/49 = 40/49 Var(X) = 40/49 ≈ 0.816

(i) Addition theorem of probability + Numerical
Statement: For any two events A and B: P(A∪B) = P(A) + P(B) − P(A∩B) Proof: A∪B = A ∪ (B−A), these are mutually exclusive P(A∪B) = P(A) + P(B−A) = P(A) + P(B) − P(A∩B) Numerical: Die thrown twice, n(S) = 36 (1) Sum = 8: {(2,6),(3,5),(4,4),(5,3),(6,2)} → 5 outcomes → P = 5/36 (2) Sum divisible by 3: 3,6,9,12 → count: 3→(1,2),(2,1); 6→(1,5),(2,4),(3,3),(4,2),(5,1); 9→(3,6),(4,5),(5,4),(6,3); 12→(6,6) → 12 outcomes P(sum div by 3) = 12/36 = 1/3

Find corner points: From 6x+4y=24: y=0 → x=4 → point B(4,0) From x+2y=6: x=0 → y=3 → point D(0,3) Intersection: 6x+4y=24 and x+2y=6 → from 2nd: x=6−2y; sub: 6(6−2y)+4y=24 → 36−12y+4y=24 → −8y=−12 → y=3/2; x=3 → C(3, 3/2) A(0,0): Z=0  |  B(4,0): Z=20  |  C(3,1.5): Z=15+6=21  |  D(0,3): Z=12 Maximum Z = 21 at (3, 3/2)
(iv) Normal distribution — mean and SD (30.85% under 45, 69.15% under 64)
P(X < 45) = 30.85% = 0.3085 P(X < 64) = 69.15% = 0.6915 P(X < 45) = 0.3085 → area to left of Z₁ = 0.3085 Since area < 0.5, Z₁ is negative: P(Z < −0.5) ≈ 0.3085 So (45 − μ)/σ = −0.5 → μ − 0.5σ = 45 ...(1) P(X < 64) = 0.6915 → P(Z < 0.5) = 0.6915 So (64 − μ)/σ = 0.5 → μ + 0.5σ = 64 ...(2) Adding (1)+(2): 2μ = 109 → μ = 54.5 From (2): 54.5 + 0.5σ = 64 → σ = 19 Mean = 54.5, SD = 19
(vii) Regression coefficients byx and bxy; find r
n=10, Σx=60, Σy=80, Σx²=450, Σy²=720, Σxy=500 x̄ = 60/10 = 6, ȳ = 80/10 = 8 Σx² − nx̄² = 450 − 10(36) = 450 − 360 = 90 Σy² − nȳ² = 720 − 10(64) = 720 − 640 = 80 Σxy − nx̄ȳ = 500 − 10(6)(8) = 500 − 480 = 20 byx = (Σxy − nx̄ȳ)/(Σx² − nx̄²) = 20/90 = 2/9 bxy = (Σxy − nx̄ȳ)/(Σy² − nȳ²) = 20/80 = 1/4 r = √(byx × bxy) = √(2/9 × 1/4) = √(2/36) = √(1/18) = 1/(3√2) r = 1/(3√2) ≈ 0.236
