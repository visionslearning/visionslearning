⚡ 3 Fundamental Identities
1. sin²θ + cos²θ = 1 → sin²θ = 1 − cos²θ | cos²θ = 1 − sin²θ
2. 1 + tan²θ = sec²θ → tan²θ = sec²θ − 1 | sec²θ − tan²θ = 1
3. 1 + cot²θ = cosec²θ → cot²θ = cosec²θ − 1 | cosec²θ − cot²θ = 1

= cotθ/(cosecθ−1) Multiply top and bottom by (cosecθ+1): = cotθ(cosecθ+1) / [(cosecθ−1)(cosecθ+1)] = cotθ(cosecθ+1) / (cosec²θ−1) cosec²θ−1 = cot²θ  [from identity 3] = cotθ(cosecθ+1) / cot²θ = (cosecθ+1) / cotθ
Proved
= (cosecθ+1)/cotθ = RHS ✓
Q15 (x)Prove: (secA+cosA)(secA−cosA) = tan²A + sin²A
LHS
= (secA+cosA)(secA−cosA) = sec²A − cos²A   [(a+b)(a−b) = a²−b²] sec²A = 1 + tan²A cos²A = 1 − sin²A = (1 + tan²A) − (1 − sin²A) = 1 + tan²A − 1 + sin²A = tan²A + sin²A
Proved
= tan²A + sin²A = RHS ✓
Q15 (xi)Prove: 1 + 3cosec²θ·cot²θ + cot⁶θ = cosec⁶θ
Start from RHS
cosec⁶θ = (cosec²θ)³ cosec²θ = 1 + cot²θ = (1 + cot²θ)³ Using (a+b)³ = a³ + 3a²b + 3ab² + b³: = 1 + 3×1²×cot²θ + 3×1×cot⁴θ + cot⁶θ = 1 + 3cot²θ + 3cot⁴θ + cot⁶θ = 1 + 3cot²θ(1 + cot²θ) + cot⁶θ = 1 + 3cot²θ · cosec²θ + cot⁶θ
Proved
= LHS ✓
Q15 (xii)Prove: (1−secθ+tanθ)/(1+secθ−tanθ) = (secθ+tanθ−1)/(secθ+tanθ+1)
Numerator of LHS
Multiply (1−secθ+tanθ) by (secθ+tanθ+1): = (1+tanθ−secθ)(1+tanθ+secθ) = (1+tanθ)² − sec²θ = 1 + 2tanθ + tan²θ − sec²θ tan²θ − sec²θ = −1  [identity 2] = 1 + 2tanθ − 1 = 2tanθ
Denominator of LHS
Multiply (1+secθ−tanθ) by (secθ+tanθ+1): = (1+secθ−tanθ)(1+secθ+tanθ) = (1+secθ)² − tan²θ = 1 + 2secθ + sec²θ − tan²θ sec²θ − tan²θ = 1  [identity 2] = 1 + 2secθ + 1 = 2 + 2secθ = 2(1+secθ)
Divide
LHS = 2tanθ / 2(1+secθ) = tanθ/(1+secθ) RHS = (secθ+tanθ−1)/(secθ+tanθ+1) Both simplify to tanθ/(1+secθ)
Proved
LHS = RHS ✓
