🔗 Reciprocal & Quotient Relations
sin θ × cosec θ = 1  |  cos θ × sec θ = 1  |  tan θ × cot θ = 1
tan θ = sin θ / cos θ  |  cot θ = cos θ / sin θ
sin θ = tan θ × cos θ  |  cos θ = sin θ / tan θ
⚡ 2.2 Fundamental Identities
Identity 1: sin²θ + cos²θ = 1
→ sin²θ = 1 − cos²θ    cos²θ = 1 − sin²θ

Identity 2: 1 + tan²θ = sec²θ   (θ ≠ π/2)
→ sec²θ − tan²θ = 1    tan²θ = sec²θ − 1

Identity 3: 1 + cot²θ = cosec²θ   (θ ≠ 0)
→ cosec²θ − cot²θ = 1    cot²θ = cosec²θ − 1
★ Derived from Identity 1
(secθ + tanθ)(secθ − tanθ) = 1  |  (cosecθ + cotθ)(cosecθ − cotθ) = 1
cos⁶θ + sin⁶θ = 1 − 3sin²θcos²θ  (using a³+b³ = (a+b)³ − 3ab(a+b))

★ Periodicity Key Points
  • A function f is periodic if f(x + p) = f(x) for all x. The smallest positive p is the fundamental period.
  • sin, cos, cosec, sec have period 2π.  tan, cot have period π.
  • To evaluate: sin(41π/4) = sin(10π + π/4) = sin(π/4) = 1/√2
  • cos(765°) = cos(720° + 45°) = cos(45°) = 1/√2
🗺️ Polar Co-ordinate System
★ Key Formulas
If P has Cartesian coordinates (x, y) and polar coordinates (r, θ):

Cartesian → Polar:   r = √(x² + y²),   tan θ = y/x
Polar → Cartesian:   x = r cos θ,   y = r sin θ

O = pole (origin), OX = polar axis (X-axis)
✅ Exercise 2.1 — Complete Solutions
Ex.5If sec x = 13/5, x lies in the fourth quadrant. Find the values of other trigonometric functions.
Solution: sec x = 13/5  ∴ cos x = 5/13
tan²x = sec²x − 1 = (13/5)² − 1 = 169/25 − 1 = 144/25
Since x is in IV quadrant: tan x = −12/5, cot x = −5/12
sin x = tan x × cos x = (−12/5) × (5/13) = −12/13
cosec x = 1/sin x = −13/12
Ex.6If tan A = 4/3, find the value of (2 sin A − 3 cos A) / (2 sin A + 3 cos A)
Solution: Divide numerator and denominator by cos A:
= (2 tan A − 3) / (2 tan A + 3) = (2×4/3 − 3) / (2×4/3 + 3)
= (8/3 − 3) / (8/3 + 3) = (8/3 − 9/3) / (8/3 + 9/3)
= (−1/3) / (17/3) = −1/17
Ex.8If sin θ = −3/5 and 180° < θ < 270°, find all trigonometric functions of θ.
Solution: θ lies in the third quadrant (180° to 270°) → sin and cos both negative, tan positive.
sin θ = −3/5  ∴ cosec θ = −5/3
cos²θ = 1 − sin²θ = 1 − 9/25 = 16/25
cos θ = −4/5 (negative in Q3)  ∴ sec θ = −5/4
tan θ = sin θ / cos θ = (−3/5)/(−4/5) = 3/4
cot θ = 4/3

Q6Find all trigonometric functions of angle in standard position whose terminal arm passes through point (3, −4).
Solution: x = 3, y = −4
r = √(x² + y²) = √(9 + 16) = √25 = 5
The point (3, −4) is in the fourth quadrant.

sin θ = y/r = −4/5    cos θ = x/r = 3/5    tan θ = y/x = −4/3
cosec θ = −5/4    sec θ = 5/3    cot θ = −3/4
Q7If cos θ = 12/13, 0 < θ < π/2, find (sin²θ − cos²θ)/(2 sin θ cos θ) and 1/tan²θ
Solution: cos θ = 12/13  →  sin²θ = 1 − 144/169 = 25/169  →  sin θ = 5/13 (Q1, positive)
tan θ = sin θ / cos θ = (5/13)/(12/13) = 5/12

(sin²θ − cos²θ)/(2 sin θ cos θ):
= (25/169 − 144/169) / (2 × 5/13 × 12/13)
= (−119/169) / (120/169) = −119/120

1/tan²θ = cot²θ = (12/5)² = 144/25
Q8Using tables evaluate: (i) 4cot45° − sec²60° + sin30°   (ii) cos²0 + cos²(π/6) + cos²(π/3) + cos²(π/2)
Solution: (i) 4cot45° − sec²60° + sin30°
= 4(1) − (2)² + (1/2)
= 4 − 4 + 1/2 = 1/2

(ii) cos²0° + cos²(π/6) + cos²(π/3) + cos²(π/2)
= (1)² + (√3/2)² + (1/2)² + (0)²
= 1 + 3/4 + 1/4 + 0 = 2
Q9Find other trigonometric functions: (i) cos θ = −3/5, 180° < θ < 270°
Solution (i): θ in III quadrant → sin and cos both negative, tan positive.
cos θ = −3/5  ∴ sec θ = −5/3
sin²θ = 1 − 9/25 = 16/25  → sin θ = −4/5 (Q3)  ∴ cosec θ = −5/4
tan θ = (−4/5)/(−3/5) = 4/3    cot θ = 3/4
Q9(ii) sec A = −25/7, A lies in the second quadrant
Solution (ii): sec A = −25/7  ∴ cos A = −7/25
sin²A = 1 − 49/625 = 576/625  → sin A = 24/25 (positive in Q2)
cosec A = 25/24
tan A = sin A / cos A = (24/25)/(−7/25) = −24/7
cot A = −7/24
Q9(iii) cot x = 3/4, x lies in the third quadrant
Solution (iii): cot x = 3/4  ∴ tan x = 4/3 (positive in Q3 ✓)
cosec²x = 1 + cot²x = 1 + 9/16 = 25/16  → cosec x = −5/4 (negative in Q3)
sin x = −4/5
cos x = cot x × sin x = (3/4)(−4/5) = −3/5
sec x = −5/3
Q9(iv) tan x = −5/12, x lies in the fourth quadrant
Solution (iv): tan x = −5/12  (negative in Q4 ✓)  → cot x = −12/5
sec²x = 1 + tan²x = 1 + 25/144 = 169/144  → sec x = 13/12 (positive in Q4)
cos x = 12/13
sin x = tan x × cos x = (−5/12)(12/13) = −5/13
cosec x = −13/5
✅ Exercise 2.2 — Complete Solutions
Ex.1If tan θ + 1/tan θ = 2, find the value of tan²θ + 1/tan²θ
Solution: Given: tan θ + 1/tan θ = 2
Squaring both sides: tan²θ + 2(tan θ)(1/tan θ) + 1/tan²θ = 4
tan²θ + 2 + 1/tan²θ = 4
∴ tan²θ + 1/tan²θ = 2
Ex.3If 5 tan A = √2 (π < A < 3π/2) and sec B = √11 (3π/2 < B < 2π), find cosec A − tan B
Solution: tan A = √2/5  &  cot A = 5/√2
cosec²A = 1 + cot²A = 1 + 25/2 = 27/2
A is in Q3 → cosec A = −√(27/2) = −√27/√2

sec B = √11  → tan²B = sec²B − 1 = 11 − 1 = 10
B is in Q4 → tan B = −√10

cosec A − tan B = −√27/√2 − (−√10) = (√20 − √27)/√2
Ex.4If tan θ = 1/√7, evaluate (cosec²θ − sec²θ)/(cosec²θ + sec²θ)
Solution: tan θ = 1/√7  → cot θ = √7
cosec²θ − sec²θ = cot²θ − tan²θ = 7 − 1/7 = 48/7
cosec²θ + sec²θ = cot²θ + tan²θ + 2 = 7 + 1/7 + 2 = 64/7
Result = (48/7)/(64/7) = 48/64 = 3/4
Ex.5Prove: cos⁶θ + sin⁶θ = 1 − 3sin²θ cos²θ
Solution: Using a³ + b³ = (a + b)³ − 3ab(a + b):
LHS = (cos²θ)³ + (sin²θ)³
= (cos²θ + sin²θ)³ − 3cos²θ sin²θ (cos²θ + sin²θ)
= (1)³ − 3sin²θ cos²θ (1)   [∵ sin²θ + cos²θ = 1]
= 1 − 3sin²θ cos²θ = RHS ✓
Ex.6Eliminate θ from: (i) x = a cosθ, y = b sinθ   (ii) x = a cos³θ, y = b sin³θ   (iii) x = 2+3cosθ, y = 5+3sinθ
Solution (i): cos θ = x/a, sin θ = y/b. Squaring and adding: x²/a² + y²/b² = 1  → x²/a² + y²/b² = 1 (ellipse)

Solution (ii): cos³θ = x/a, sin³θ = y/b  → cosθ = (x/a)^(1/3), sinθ = (y/b)^(1/3)
Squaring and adding: (x/a)^(2/3) + (y/b)^(2/3) = 1

Solution (iii): cosθ = (x−2)/3, sinθ = (y−5)/3
cos²θ + sin²θ = 1  → (x−2)²/9 + (y−5)²/9 = 1
∴ (x−2)² + (y−5)² = 9 (circle with centre (2,5) and radius 3)
Ex.7If 2sin²θ + 7cosθ = 5, find permissible values of cosθ.
Solution: sin²θ = 1 − cos²θ. Substitute:
2(1 − cos²θ) + 7cosθ = 5
2 − 2cos²θ + 7cosθ − 5 = 0
2cos²θ − 7cosθ + 3 = 0
(2cosθ − 1)(cosθ − 3) = 0
cosθ = 3 or cosθ = 1/2
Since −1 ≤ cosθ ≤ 1, cosθ = 3 is not valid.
∴ Permissible value: cos θ = 1/2
Ex.9If tan θ + sec θ = 1.5, find tan θ, sin θ and sec θ.
Solution: tan θ + sec θ = 3/2  ...(1)
sec²θ − tan²θ = 1  → (secθ + tanθ)(secθ − tanθ) = 1
(3/2)(secθ − tanθ) = 1  → secθ − tanθ = 2/3  ...(2)
Adding (1) and (2): 2 secθ = 3/2 + 2/3 = 13/6  → sec θ = 13/12, cos θ = 12/13
Subtracting: 2 tanθ = 3/2 − 2/3 = 5/6  → tan θ = 5/12
sin θ = tan θ × cos θ = (5/12)(12/13) = 5/13
✅ Exercise 2.2 — Important Questions
Q1If 2sinA = 1 = √2 cosB, π/2 < A < π, 3π/2 < B < 2π, find (tan A + tan B)/(cos A − cos B)
Solution: 2 sin A = 1 → sin A = 1/2 → A = 5π/6 (Q2, sin positive ✓)
cos A = −√3/2 (Q2), tan A = sin A/cos A = (1/2)/(−√3/2) = −1/√3
√2 cos B = 1 → cos B = 1/√2 → B lies in Q4 (3π/2 to 2π), cos positive ✓
sin B = −1/√2 (Q4), tan B = (−1/√2)/(1/√2) = −1
(tan A + tan B)/(cos A − cos B) = (−1/√3 + (−1))/(−√3/2 − 1/√2)
= (−1/√3 − 1)/(−√3/2 − 1/√2) = √2/√3 (simplify by rationalising)
Q3If tan θ = 1/2, evaluate (2sinθ + 3cosθ)/(4cosθ + 3sinθ)
Solution: Divide numerator and denominator by cosθ:
= (2tanθ + 3)/(4 + 3tanθ) = (2×1/2 + 3)/(4 + 3×1/2)
= (1 + 3)/(4 + 3/2) = 4/(11/2) = 8/11
Q4Eliminate θ: (i) x = 3secθ, y = 4tanθ  (ii) x = 6cosecθ, y = 8cotθ  (iii) x = 4cosθ−5sinθ, y = 4sinθ+5cosθ
Solution (i): secθ = x/3, tanθ = y/4. Using sec²θ − tan²θ = 1: x²/9 − y²/16 = 1  → x²/9 − y²/16 = 1 (hyperbola)

Solution (ii): cosecθ = x/6, cotθ = y/8. Using cosec²θ − cot²θ = 1: x²/36 − y²/64 = 1  → x²/36 − y²/64 = 1

Solution (iii): x = 4cosθ − 5sinθ  &  y = 4sinθ + 5cosθ
x² = 16cos²θ − 40cosθsinθ + 25sin²θ
y² = 16sin²θ + 40sinθcosθ + 25cos²θ
x² + y² = 16(cos²θ+sin²θ) + 25(sin²θ+cos²θ) = 16 + 25
∴ x² + y² = 41
Q5If 2sin²θ + 3sinθ = 0, find permissible values of cosθ.
Solution: sinθ(2sinθ + 3) = 0
sinθ = 0 or sinθ = −3/2
Since −1 ≤ sinθ ≤ 1, sinθ = −3/2 is not valid.
sinθ = 0 → cosθ = ±√(1−0) = ±1
∴ Permissible values: cos θ = ±1
Q7Find the acute angle θ such that 2cos²θ = 3sinθ
Solution: 2(1 − sin²θ) = 3sinθ
2 − 2sin²θ − 3sinθ = 0
2sin²θ + 3sinθ − 2 = 0
(2sinθ − 1)(sinθ + 2) = 0
sinθ = 1/2 or sinθ = −2 (rejected)
∴ θ = 30°
Q8Find the acute angle θ such that 5tan²θ + 3 = 9secθ
Solution: 5(sec²θ − 1) + 3 = 9secθ
5sec²θ − 9secθ − 2 = 0
(5secθ + 1)(secθ − 2) = 0
secθ = −1/5 (rejected, |secθ| ≥ 1) or secθ = 2
secθ = 2 → cosθ = 1/2 → θ = 60°
Q9Find sinθ such that 3cosθ + 4sinθ = 4
Solution: 3cosθ = 4 − 4sinθ → 9cos²θ = (4 − 4sinθ)²
9(1 − sin²θ) = 16 − 32sinθ + 16sin²θ
9 − 9sin²θ = 16 − 32sinθ + 16sin²θ
25sin²θ − 32sinθ + 7 = 0
(25sinθ − 7)(sinθ − 1) = 0
sinθ = 7/25 or sinθ = 1  → both valid
∴ sin θ = 7/25 or sin θ = 1
Q10If cosecθ + cotθ = 5, evaluate secθ.
Solution: cosecθ + cotθ = 5  ...(1)
cosec²θ − cot²θ = 1 → (cosecθ + cotθ)(cosecθ − cotθ) = 1
5(cosecθ − cotθ) = 1 → cosecθ − cotθ = 1/5  ...(2)
Adding: 2cosecθ = 5 + 1/5 = 26/5 → cosecθ = 13/5 → sinθ = 5/13
cosθ = √(1 − 25/169) = 12/13
∴ sec θ = 13/12
Q11If cotθ = 3/4 and π < θ < 3π/4, find 4cosecθ + 5cosθ.
Solution: Wait — π < θ < 3π/4 is invalid (3π/4 < π). The correct range is π < θ < 3π/2 (Q3).
cotθ = 3/4, θ in Q3 → sinθ and cosθ both negative, tanθ positive.
cosec²θ = 1 + cot²θ = 1 + 9/16 = 25/16 → cosecθ = −5/4 (Q3)
sinθ = −4/5, cosθ = cotθ × sinθ = (3/4)(−4/5) = −3/5
4cosecθ + 5cosθ = 4(−5/4) + 5(−3/5) = −5 + (−3) = −8
Q12Find Cartesian co-ordinates from polar: (i) (3, 90°)   (ii) (1, 180°)
Solution (i): r = 3, θ = 90° → x = 3cos90° = 0, y = 3sin90° = 3 → (0, 3)
Solution (ii): r = 1, θ = 180° → x = 1cos180° = −1, y = 1sin180° = 0 → (−1, 0)
Q13Find polar co-ordinates from Cartesian: (i)(5,5) (ii)(1,√3) (iii)(−1,−1) (iv)(−√3,1)

Solution (iii): r = √(1+1) = √2, tanθ = 1, Q3 → θ = 225° → (√2, 225°)
Solution (iv): r = √(3+1) = 2, tanθ = 1/(−√3) = −1/√3, Q2 → θ = 150° → (2, 150°)
Q14Find the value of: (i) sin(19π/3)   (ii) cos1140°   (iii) cot(25π/3)

🔷 Exercise 2.2 Q15 — Prove the Following Identities
(ii)Prove: (cos²A − 1)(cot²A + 1) = −1
LHS = (cos²A − 1)(cot²A + 1)
= (−sin²A)(cosec²A)   [∵ cos²A−1 = −sin²A and 1+cot²A = cosec²A]
= −sin²A × 1/sin²A = −1 = RHS ✓
(iii)Prove: (sinθ + secθ)² + (cosθ + cosecθ)² = (1 + cosecθ secθ)²
LHS = sin²θ + 2sinθsecθ + sec²θ + cos²θ + 2cosθcosecθ + cosec²θ
= (sin²θ + cos²θ) + (sec²θ + cosec²θ) + 2(sinθ/cosθ + cosθ/sinθ)
= 1 + sec²θ + cosec²θ + 2(sin²θ + cos²θ)/(sinθcosθ)
= 1 + sec²θ + cosec²θ + 2/sinθcosθ
RHS = 1 + 2cosecθsecθ + cosec²θsec²θ
Note: sec²θ + cosec²θ = 1/cos²θ + 1/sin²θ = (sin²θ+cos²θ)/(sin²θcos²θ) = cosec²θsec²θ
Also 2/sinθcosθ = 2cosecθsecθ. So LHS = RHS ✓
(iv)Prove: (1 + cotθ − cosecθ)(1 + tanθ + secθ) = 2
LHS = (1 + cosθ/sinθ − 1/sinθ)(1 + sinθ/cosθ + 1/cosθ)
= [(sinθ + cosθ − 1)/sinθ] × [(cosθ + sinθ + 1)/cosθ]
= [(sinθ + cosθ − 1)(sinθ + cosθ + 1)] / (sinθcosθ)
= [(sinθ + cosθ)² − 1] / (sinθcosθ)
= [sin²θ + 2sinθcosθ + cos²θ − 1] / (sinθcosθ)
= [1 + 2sinθcosθ − 1] / (sinθcosθ) = 2sinθcosθ / sinθcosθ = 2 = RHS ✓
(x)Prove: (secA + cosA)(secA − cosA) = tan²A + sin²A
LHS = sec²A − cos²A
= (1 + tan²A) − (1 − sin²A)
= 1 + tan²A − 1 + sin²A
= tan²A + sin²A = RHS ✓
(vii)Prove: sinθ/(1+cosθ) + (1+cosθ)/sinθ = 2cosecθ
LHS = [sin²θ + (1+cosθ)²] / [sinθ(1+cosθ)]
= [sin²θ + 1 + 2cosθ + cos²θ] / [sinθ(1+cosθ)]
= [1 + 1 + 2cosθ] / [sinθ(1+cosθ)]
= [2 + 2cosθ] / [sinθ(1+cosθ)] = 2(1+cosθ) / [sinθ(1+cosθ)]
= 2/sinθ = 2cosecθ = RHS ✓
(viii)Prove: tanθ/(secθ−1) = (secθ+1)/tanθ
LHS = tanθ/(secθ−1) × (secθ+1)/(secθ+1) = tanθ(secθ+1)/(sec²θ−1)
= tanθ(secθ+1)/tan²θ = (secθ+1)/tanθ = RHS ✓
(xi)Prove: 1 + 3cosec²θ·cot²θ + cot⁶θ = cosec⁶θ
RHS = cosec⁶θ = (cosec²θ)³ = (1 + cot²θ)³
= 1 + 3cot²θ + 3cot⁴θ + cot⁶θ
= 1 + 3cot²θ(1 + cot²θ) + cot⁶θ
= 1 + 3cot²θ·cosec²θ + cot⁶θ = LHS ✓
