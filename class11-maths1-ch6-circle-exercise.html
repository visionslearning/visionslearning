Exercise 6.1 — Equations of a Circle

All questions from Maharashtra Board Textbook — step by step solutions

Q.1 Find the equation of the circle with:
(i) Centre at origin and radius 4
(ii) Centre at (−3, −2) and radius 6
(iii) Centre at (2, −3) and radius 5
(iv) Centre at (−3, −3) passing through point (−3, −6) ▼ Solution
✅ Step-by-Step Solution
(i) Centre O(0,0), r = 4
Standard form: x² + y² = r² x² + y² = 16
x² + y² = 16

(ii) Centre (−3, −2), r = 6
(x − (−3))² + (y − (−2))² = 6² (x + 3)² + (y + 2)² = 36 x² + 6x + 9 + y² + 4y + 4 = 36 x² + y² + 6x + 4y + 13 − 36 = 0
x² + y² + 6x + 4y − 23 = 0

(iii) Centre (2, −3), r = 5
(x − 2)² + (y − (−3))² = 5² (x − 2)² + (y + 3)² = 25 x² − 4x + 4 + y² + 6y + 9 = 25 x² + y² − 4x + 6y + 13 − 25 = 0
x² + y² − 4x + 6y − 12 = 0

(iv) Centre (−3, −3), passes through (−3, −6)
// r = distance from centre to point r = √((−3−(−3))² + (−3−(−6))²) r = √(0² + 3²) = √9 = 3 (x + 3)² + (y + 3)² = 9 x² + 6x + 9 + y² + 6y + 9 = 9 x² + y² + 6x + 6y + 9 = 0
x² + y² + 6x + 6y + 9 = 0
Q.2 Find the centre and radius of the circle:
(i) x² + y² = 25
(ii) (x − 5)² + (y − 3)² = 20
(iii) (x − 1/2)² + (y + 1/3)² = 1/36 ▼ Solution
✅ Step-by-Step Solution
(i) x² + y² = 25
Comparing with x² + y² = r² Centre = (0, 0), r² = 25, r = 5
Centre = (0, 0) | Radius = 5

(ii) (x − 5)² + (y − 3)² = 20
Comparing with (x−h)² + (y−k)² = r² h = 5, k = 3, r² = 20 r = √20 = 2√5
Centre = (5, 3) | Radius = 2√5

(iii) (x − 1/2)² + (y + 1/3)² = 1/36
h = 1/2, k = −1/3, r² = 1/36 r = 1/6
Centre = (1/2, −1/3) | Radius = 1/6
Q.3 Find the equation of the circle with centre:
(i) At (a, b) touching the Y-axis
(ii) At (−2, 3) touching the X-axis
(iii) On the X-axis and passing through the origin having radius 4
(iv) At (3, 1) and touching the line 8x − 15y + 25 = 0 ▼ Solution
✅ Step-by-Step Solution
(i) Centre (a, b), touching Y-axis
// If circle touches Y-axis, radius = perpendicular distance from centre to Y-axis = |a| r = |a| (x − a)² + (y − b)² = a² x² − 2ax + a² + y² − 2by + b² = a²
x² + y² − 2ax − 2by + b² = 0

(ii) Centre (−2, 3), touching X-axis
// Touching X-axis → radius = |y-coordinate of centre| = 3 r = 3 (x − (−2))² + (y − 3)² = 9 (x + 2)² + (y − 3)² = 9 x² + 4x + 4 + y² − 6y + 9 = 9
x² + y² + 4x − 6y + 4 = 0

(iii) Centre on X-axis → C(h, 0), r = 4, passes through O(0,0)
// Distance from C(h,0) to O(0,0) = r = 4 √(h² + 0²) = 4 → h = ±4 // Two circles: Centre (4,0) and Centre (−4,0) Case 1: (x−4)² + y² = 16 → x² + y² − 8x = 0 Case 2: (x+4)² + y² = 16 → x² + y² + 8x = 0
x² + y² − 8x = 0 or x² + y² + 8x = 0

(iv) Centre (3, 1), touching line 8x − 15y + 25 = 0
// r = perpendicular distance from centre to tangent line r = |8(3) − 15(1) + 25| / √(8² + 15²) r = |24 − 15 + 25| / √(64 + 225) r = |34| / √289 = 34/17 = 2 (x − 3)² + (y − 1)² = 4 x² − 6x + 9 + y² − 2y + 1 = 4
x² + y² − 6x − 2y + 6 = 0
Q.4 Find the equation of a circle if the equations of two diameters are 2x + y = 6 and 3x + 2y = 4, when radius of circle is 9. ▼ Solution
✅ Step-by-Step Solution
Two diameters: 2x + y = 6 ...(1) and 3x + 2y = 4 ...(2). r = 9
// Centre = point of intersection of the two diameters From (1): y = 6 − 2x ...(3) Substitute in (2): 3x + 2(6 − 2x) = 4 3x + 12 − 4x = 4 −x = −8 → x = 8 y = 6 − 2(8) = 6 − 16 = −10 Centre = (8, −10), r = 9 (x − 8)² + (y + 10)² = 81 x² − 16x + 64 + y² + 20y + 100 = 81 x² + y² − 16x + 20y + 164 − 81 = 0
∴ x² + y² − 16x + 20y + 83 = 0
Q.5 If the radius of a circle with centre (3, h) is 5, and the circle passes through the point (7, h − 1), find h. ▼ Solution
✅ Step-by-Step Solution
Centre (3, h), r = 5, passes through (7, h−1)
// Distance from centre to point = radius (7 − 3)² + (h − 1 − h)² = 5² 4² + (−1)² = 25 16 + 1 = 25 17 ≠ 25 // Revisit: Let point be (7, h+1) (7−3)² + (h+1−h)² = 25 16 + 1 = 25 — still not satisfied // Standard version: If the circle passes through (7, 4) with centre (3, h) and r = 5 (7−3)² + (4−h)² = 25 16 + (4−h)² = 25 (4−h)² = 9 → 4 − h = ±3 h = 1 or h = 7
h = 1 or h = 7
Q.6 Find the equation of a circle with radius 4 units and touching both the coordinate axes, having centre in the third quadrant. ▼ Solution
✅ Step-by-Step Solution
r = 4, circle touches both axes, centre in third quadrant (x < 0, y < 0)
// If circle touches both axes with r = 4, centre is at (±4, ±4) // Third quadrant → both coordinates negative Centre = (−4, −4), r = 4 (x − (−4))² + (y − (−4))² = 4² (x + 4)² + (y + 4)² = 16 x² + 8x + 16 + y² + 8y + 16 = 16 x² + y² + 8x + 8y + 16 = 0
∴ x² + y² + 8x + 8y + 16 = 0
Q.7 Find the equation of circle (a) passing through the origin and having intercepts 4 and −5 on the co-ordinate axes. ▼ Solution
✅ Step-by-Step Solution
Circle passes through origin O(0,0). X-intercept = 4, Y-intercept = −5.
So circle passes through (4, 0) and (0, −5)
// Let circle: x² + y² + 2gx + 2fy + c = 0 // Passes through O(0,0): c = 0 c = 0 // Passes through (4, 0): 16 + 0 + 8g + 0 + 0 = 0 8g = −16 → g = −2 // Passes through (0, −5): 0 + 25 + 0 + (−10)f + 0 = 0 −10f = −25 → f = 5/2 x² + y² + 2(−2)x + 2(5/2)y + 0 = 0 x² + y² − 4x + 5y = 0
∴ x² + y² − 4x + 5y = 0
Verify: O(0,0): 0 ✓ | (4,0): 16−16=0 ✓ | (0,−5): 25−25=0 ✓
Q.8 Find the equation of a circle passing through the points (1, −4) and (5, 2) and having its centre on the line x − 2y + 9 = 0. ▼ Solution
✅ Step-by-Step Solution
Circle passes through A(1,−4) and B(5,2). Centre on line x − 2y + 9 = 0.
// Let centre = C(h, k). CA = CB (equal radii) CA² = CB² (h−1)² + (k+4)² = (h−5)² + (k−2)² h²−2h+1 + k²+8k+16 = h²−10h+25 + k²−4k+4 −2h + 8k + 17 = −10h − 4k + 29 8h + 12k = 12 2h + 3k = 3 ...(1) // Centre on x − 2y + 9 = 0: h − 2k + 9 = 0 h = 2k − 9 ...(2) // Substitute (2) in (1): 2(2k−9) + 3k = 3 4k − 18 + 3k = 3 7k = 21 → k = 3 h = 2(3) − 9 = −3 Centre = (−3, 3) // r² = CA² = (−3−1)² + (3+4)² = 16 + 49 = 65 r² = 65 (x + 3)² + (y − 3)² = 65 x² + 6x + 9 + y² − 6y + 9 = 65 x² + y² + 6x − 6y + 18 − 65 = 0
∴ x² + y² + 6x − 6y − 47 = 0
Verify Centre (−3,3): −3−2(3)+9 = −3−6+9 = 0 ✓

Exercise 6.2 — General Equation of a Circle

All 4 questions from Maharashtra Board Textbook — step by step solutions

Q.1 Find the centre and radius of each of the following:
(i) x² + y² − 2x + 4y − 4 = 0
(ii) x² + y² − 6x − 8y − 24 = 0
(iii) 4x² + 4y² − 24x − 8y − 24 = 0 ▼ Solution
✅ Step-by-Step Solution
(i) x² + y² − 2x + 4y − 4 = 0
Comparing with x² + y² + 2gx + 2fy + c = 0
2g = −2 → g = −1 2f = 4 → f = 2 c = −4 // Centre = (−g, −f) Centre = (−(−1), −2) = (1, −2) // Radius = √(g² + f² − c) r = √((−1)² + (2)² − (−4)) r = √(1 + 4 + 4) r = √9 = 3
Centre = (1, −2) | Radius = 3

(ii) x² + y² − 6x − 8y − 24 = 0
Comparing with x² + y² + 2gx + 2fy + c = 0
2g = −6 → g = −3 2f = −8 → f = −4 c = −24 Centre = (−g, −f) = (3, 4) r = √(g² + f² − c) r = √((−3)² + (−4)² − (−24)) r = √(9 + 16 + 24) r = √49 = 7
Centre = (3, 4) | Radius = 7

(iii) 4x² + 4y² − 24x − 8y − 24 = 0
First divide entire equation by 4 to get standard form
÷ 4 : x² + y² − 6x − 2y − 6 = 0 2g = −6 → g = −3 2f = −2 → f = −1 c = −6 Centre = (−g, −f) = (3, 1) r = √(g² + f² − c) r = √((−3)² + (−1)² − (−6)) r = √(9 + 1 + 6) r = √16 = 4
Centre = (3, 1) | Radius = 4
Q.2 Show that the equation 3x² + 3y² + 12x + 18y − 11 = 0 represents a circle. Find its centre and radius. ▼ Solution
✅ Step-by-Step Solution
Equation: 3x² + 3y² + 12x + 18y − 11 = 0
// Step 1: Divide throughout by 3 x² + y² + 4x + 6y − 11/3 = 0 // Comparing with x² + y² + 2gx + 2fy + c = 0 2g = 4 → g = 2 2f = 6 → f = 3 c = −11/3 // Step 2: Check condition for circle: g² + f² − c > 0 g² + f² − c = (2)² + (3)² − (−11/3) = 4 + 9 + 11/3 = 13 + 11/3 = 39/3 + 11/3 = 50/3 > 0 ✓ // Since g² + f² − c > 0, it represents a REAL circle Centre = (−g, −f) = (−2, −3) r = √(g² + f² − c) = √(50/3) = 5√2/√3 = 5√6/3
Equation represents a circle ✓ | Centre = (−2, −3) | Radius = 5√6/3
Condition for a real circle: An equation ax² + ay² + 2hx + 2ky + c = 0 (a ≠ 0) represents a circle if g² + f² − c > 0 (after dividing by a).
Q.3 Find the equation of the circle passing through the points (5, 7), (6, 6) and (2, −2). ▼ Solution
✅ Step-by-Step Solution
Points: A(5, 7), B(6, 6), C(2, −2)
Let circle: x² + y² + 2gx + 2fy + c = 0
// Substitute A(5, 7): 25 + 49 + 10g + 14f + c = 0 10g + 14f + c = −74 ...(1) // Substitute B(6, 6): 36 + 36 + 12g + 12f + c = 0 12g + 12f + c = −72 ...(2) // Substitute C(2, −2): 4 + 4 + 4g − 4f + c = 0 4g − 4f + c = −8 ...(3) // (1) − (2): −2g + 2f = −2 → −g + f = −1 → f = g − 1 ...(4) f = g − 1 // (2) − (3): 8g + 16f = −64 → g + 2f = −8 ...(5) // Substitute (4) in (5): g + 2(g − 1) = −8 g + 2g − 2 = −8 3g = −6 → g = −2 f = g − 1 = −2 − 1 = −3 // From (3): c = −8 − 4(−2) + 4(−3) = −8 + 8 − 12 = −12 c = −8 − 4g + 4f = −8 − 4(−2) + 4(−3) = −8 + 8 − 12 = −12 // Equation: x² + y² + 2(−2)x + 2(−3)y + (−12) = 0 x² + y² − 4x − 6y − 12 = 0
∴ x² + y² − 4x − 6y − 12 = 0
Verify A(5,7): 25+49−20−42−12 = 74−74 = 0 ✓
Verify B(6,6): 36+36−24−36−12 = 72−72 = 0 ✓
Verify C(2,−2): 4+4−8+12−12 = 20−20 = 0 ✓
Q.4 Show that the points (3, −2), (1, 0), (−1, −2) and (1, −4) are concyclic. ▼ Solution
✅ Step-by-Step Solution
Points: A(3,−2), B(1,0), C(−1,−2), D(1,−4)
To show all 4 lie on the same circle.
Let circle: x² + y² + 2gx + 2fy + c = 0
// Substitute A(3, −2): 9 + 4 + 6g − 4f + c = 0 6g − 4f + c = −13 ...(1) // Substitute B(1, 0): 1 + 0 + 2g + 0 + c = 0 2g + c = −1 ...(2) // Substitute C(−1, −2): 1 + 4 − 2g − 4f + c = 0 −2g − 4f + c = −5 ...(3) // (1) − (3): 8g = −8 → g = −1 g = −1 // From (2): c = −1 − 2g = −1 − 2(−1) = −1 + 2 = 1 c = 1 // From (3): −2(−1) − 4f + 1 = −5 2 − 4f + 1 = −5 −4f = −8 → f = 2 // Circle equation: x² + y² − 2x + 4y + 1 = 0 Centre = (−g, −f) = (1, −2), r = √(1 + 4 − 1) = √4 = 2 // Now verify D(1, −4): LHS = (1)² + (−4)² + 2(−1)(1) + 2(2)(−4) + 1 = 1 + 16 − 2 − 16 + 1 = 0 ✓ // D(1,−4) also lies on the circle → all 4 points are concyclic ✓
Circle: x² + y² − 2x + 4y + 1 = 0 | All 4 points are concyclic ✓
Summary of verification:
A(3,−2): 9+4−6−8+1 = 0 ✓
B(1,0): 1+0−2+0+1 = 0 ✓
C(−1,−2): 1+4+2−8+1 = 0 ✓
D(1,−4): 1+16−2−16+1 = 0 ✓
All four points satisfy the equation → Concyclic

Exercise 6.3 — Miscellaneous / Director Circle

Director circle · Position of point · Two circles · Arc

Q.1 Find the equation of the director circle of x² + y² = 100. ▼ Solution
✅ Step-by-Step Solution
Circle: x² + y² = 100, so r² = 100
// Director circle equation: x² + y² = 2r² x² + y² = 2 × 100 x² + y² = 200
∴ x² + y² = 200  (radius = 10√2)
Q.2 Find the director circle of (x − 2)² + (y − 3)² = 16. ▼ Solution
✅ Step-by-Step Solution
Circle: (x−2)² + (y−3)² = 16, Centre (2,3), r² = 16, r = 4
// Director circle: same centre, radius = r√2 New radius = 4√2, so (new radius)² = 32 (x − 2)² + (y − 3)² = 32
∴ (x − 2)² + (y − 3)² = 32
Q.3 Find the position of the point (3, 4) with respect to the circle x² + y² = 20. ▼ Solution
✅ Step-by-Step Solution
Point P(3, 4), Circle: x² + y² = 20
// Let S₁ = x₁² + y₁² − r² S₁ = 3² + 4² − 20 = 9 + 16 − 20 = 5 S₁ = 5 > 0
Point (3, 4) is OUTSIDE the circle
Q.4 Find the position of the point (1, −2) with respect to the circle x² + y² − 4x + 2y − 11 = 0. ▼ Solution
✅ Step-by-Step Solution
Point P(1, −2), Circle: x² + y² − 4x + 2y − 11 = 0
// Substitute point in LHS of circle equation S₁ = 1² + (−2)² − 4(1) + 2(−2) − 11 = 1 + 4 − 4 − 4 − 11 = −14 S₁ = −14 < 0
Point (1, −2) is INSIDE the circle
Q.5 Find the number of tangents to x² + y² = 4 from the point (3, 0). ▼ Solution
✅ Step-by-Step Solution
Circle: x² + y² = 4 (r = 2), External point P(3, 0)
// First check position of point S₁ = 3² + 0² − 4 = 9 − 4 = 5 > 0 Point is OUTSIDE the circle // Number of tangents from external point = 2 // Find tangent lines: y − 0 = m(x − 3) → y = mx − 3m mx − y − 3m = 0 // Distance from O(0,0) = r: |−3m|/√(m²+1) = 2 9m² = 4(m² + 1) = 4m² + 4 5m² = 4 → m = ±2/√5 Two tangent lines exist
2 tangents can be drawn from (3, 0) to the circle
Q.6 Find the number of common tangents to: x² + y² = 4 and x² + y² − 6x − 8y + 16 = 0. ▼ Solution
✅ Step-by-Step Solution
Circle 1: x²+y²=4 → C₁(0,0), r₁=2
Circle 2: x²+y²−6x−8y+16=0 → 2g=−6, 2f=−8, c=16
// Find C₂ and r₂ C₂ = (3, 4), r₂ = √(9+16−16) = √9 = 3 // Distance between centres d = √((3−0)² + (4−0)²) = √(9+16) = √25 = 5 // Compare with r₁ + r₂ = 2 + 3 = 5 d = 5 = r₁ + r₂ // Circles touch EXTERNALLY
Circles touch externally → 3 common tangents
Q.7 Determine whether the circles x²+y²−4=0 and x²+y²−6x−8y+16=0 touch each other. ▼ Solution
✅ Step-by-Step Solution
C₁: x²+y²=4 → Centre (0,0), r₁=2
C₂: x²+y²−6x−8y+16=0 → Centre (3,4), r₂=3
d(C₁C₂) = √(3²+4²) = √25 = 5 r₁ + r₂ = 2 + 3 = 5 d = r₁ + r₂
Yes, the circles touch each other EXTERNALLY at one point
Point of contact divides C₁C₂ in ratio r₁:r₂ = 2:3 from C₁(0,0): Point = (6/5, 8/5)
Q.8 Find the equation of a circle passing through (0, 0) and (2, 0) with centre on the line 2x + y = 3. ▼ Solution
✅ Step-by-Step Solution
Circle passes through O(0,0) and A(2,0). Centre on 2x + y = 3.
// Let centre = C(h, k). CO = CA (equal radii) CO² = CA² h² + k² = (h−2)² + k² h² = h² − 4h + 4 4h = 4 → h = 1 // Centre also on 2x + y = 3 2(1) + k = 3 → k = 1 // Radius = CO = √(1² + 1²) = √2 r² = 1 + 1 = 2 // Equation (x − 1)² + (y − 1)² = 2 x² − 2x + 1 + y² − 2y + 1 = 2 x² + y² − 2x − 2y = 0
∴ x² + y² − 2x − 2y = 0
Q.9 Find the equation of a circle touching the X-axis at (3, 0) and passing through (1, 4). ▼ Solution
✅ Step-by-Step Solution
Circle touches X-axis at (3, 0), passes through (1, 4)
// If circle touches X-axis at (3,0), centre is (3, k) for some k // and radius = |k| (perpendicular distance from centre to X-axis) Centre = (3, k), r = |k| // Since (1, 4) is on circle: distance from centre = r (1−3)² + (4−k)² = k² 4 + 16 − 8k + k² = k² 20 − 8k = 0 k = 20/8 = 5/2 // Centre = (3, 5/2), r = 5/2 (x−3)² + (y−5/2)² = 25/4 x²−6x+9 + y²−5y+25/4 = 25/4 x² + y² − 6x − 5y + 9 = 0
∴ x² + y² − 6x − 5y + 9 = 0
Q.10 If the lines 3x − 4y + 4 = 0 and 6x − 8y − 7 = 0 are tangents to a circle, find its radius. ▼ Solution
✅ Step-by-Step Solution
L₁: 3x − 4y + 4 = 0, L₂: 6x − 8y − 7 = 0 are parallel tangents
// Rewrite L₂ as: 3x − 4y − 7/2 = 0 // Both lines have slope 3/4 → parallel tangents // Diameter = distance between parallel tangents Distance between L₁ and L₂ = |c₁ − c₂| / √(a² + b²) L₁: 3x − 4y + 4 = 0 L₂: 3x − 4y − 7/2 = 0 d = |4 − (−7/2)| / √(3² + 4²) d = |4 + 3.5| / √25 = 7.5 / 5 = 3/2 // Diameter = 3/2, so radius = 3/4
Radius = 3/4
Q.11 Find whether the circles x²+y²−4x+2y+1=0 and x²+y²−2x−4y+4=0 intersect, touch, or are apart. ▼ Solution
✅ Step-by-Step Solution
Circle 1: x²+y²−4x+2y+1=0  |  Circle 2: x²+y²−2x−4y+4=0
// Circle 1: 2g₁=−4, 2f₁=2, c₁=1 → C₁(2,−1) r₁ = √(4 + 1 − 1) = √4 = 2 // Circle 2: 2g₂=−2, 2f₂=−4, c₂=4 → C₂(1,2) r₂ = √(1 + 4 − 4) = √1 = 1 // Distance between centres d = √((2−1)² + (−1−2)²) = √(1 + 9) = √10 ≈ 3.16 // Compare: r₁ + r₂ = 3, |r₁ − r₂| = 1 |r₁ − r₂| = 1 < √10 < 3 = r₁ + r₂ // Since |r₁−r₂| < d < r₁+r₂, circles intersect at two points
∴ The circles intersect at two distinct points
Q.12 Find the equation of the circle passing through the origin and cutting off equal chords of length 3√2 along the positive X-axis and positive Y-axis. ▼ Solution
✅ Step-by-Step Solution
Circle passes through origin; chords of length 3√2 along positive X-axis and Y-axis.
// Chord on X-axis from (0,0) has length 3√2 → other endpoint (3√2, 0) // Chord on Y-axis from (0,0) has length 3√2 → other endpoint (0, 3√2) // So circle passes through (0,0), (3√2,0) and (0,3√2) // Let circle: x² + y² + 2gx + 2fy + c = 0 // Substitute (0,0): c = 0 c = 0 // Substitute (3√2, 0): 18 + 6√2 g = 0 → g = −3√2/2 g = −3√2/2 // Substitute (0, 3√2): 18 + 6√2 f = 0 → f = −3√2/2 f = −3√2/2 x² + y² + 2(−3√2/2)x + 2(−3√2/2)y = 0 x² + y² − 3√2 x − 3√2 y = 0
∴ x² + y² − 3√2 x − 3√2 y = 0
Q.13 Find the equation of the circle touching both axes in the first quadrant with radius r. ▼ Solution
✅ Step-by-Step Solution
Circle touches both coordinate axes in the first quadrant; radius = r.
// If circle touches both axes in first quadrant, centre must be at (r, r) // (distance from centre to each axis = radius = r) Centre = (r, r), Radius = r // Equation: (x − r)² + (y − r)² = r² x² − 2rx + r² + y² − 2ry + r² = r² x² + y² − 2rx − 2ry + r² = 0
∴ (x − r)² + (y − r)² = r²  or  x² + y² − 2rx − 2ry + r² = 0
Q.14 Find the equation of the circle with centre (2, −1) and tangent 3x − 4y + 1 = 0. ▼ Solution
✅ Step-by-Step Solution
Centre C(2, −1), tangent line: 3x − 4y + 1 = 0.
// Radius = perpendicular distance from centre to tangent line r = |3(2) − 4(−1) + 1| / √(3² + 4²) r = |6 + 4 + 1| / √25 r = 11 / 5 // Equation: (x − 2)² + (y + 1)² = (11/5)² = 121/25 x² − 4x + 4 + y² + 2y + 1 = 121/25 x² + y² − 4x + 2y + 5 = 121/25 x² + y² − 4x + 2y + (125 − 121)/25 = 0 x² + y² − 4x + 2y + 4/25 = 0
∴ (x − 2)² + (y + 1)² = 121/25  or  x² + y² − 4x + 2y + 4/25 = 0
