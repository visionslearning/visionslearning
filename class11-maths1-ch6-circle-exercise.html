Exercise 6.1 — Equations of a Circle

Standard form · Centre-radius form · Diameter form · General form

Q.1 Find the equation of a circle with centre at origin and radius 4. ▼ Solution
✅ Step-by-Step Solution
Given: Centre = O(0, 0), radius r = 4
// Standard form: x² + y² = r² x² + y² = 4² x² + y² = 16
∴ x² + y² = 16
Q.2 Find the equation of a circle with centre (2, 3) and radius 5. ▼ Solution
✅ Step-by-Step Solution
Given: Centre C(h, k) = (2, 3), radius r = 5
// Centre-radius form: (x−h)² + (y−k)² = r² (x − 2)² + (y − 3)² = 5² x² − 4x + 4 + y² − 6y + 9 = 25 x² + y² − 4x − 6y + 13 − 25 = 0 x² + y² − 4x − 6y − 12 = 0
∴ (x−2)² + (y−3)² = 25  or  x² + y² − 4x − 6y − 12 = 0
Q.3 Find the equation of a circle with centre (−3, 2) and radius 6. ▼ Solution
✅ Step-by-Step Solution
Given: Centre C(h, k) = (−3, 2), radius r = 6
(x − (−3))² + (y − 2)² = 6² (x + 3)² + (y − 2)² = 36 x² + 6x + 9 + y² − 4y + 4 = 36 x² + y² + 6x − 4y + 13 − 36 = 0 x² + y² + 6x − 4y − 23 = 0
∴ x² + y² + 6x − 4y − 23 = 0
Q.4 Find the centre and radius of the circle: x² + y² − 4x + 6y − 12 = 0 ▼ Solution
✅ Step-by-Step Solution
Given: x² + y² − 4x + 6y − 12 = 0
Comparing with x² + y² + 2gx + 2fy + c = 0
// Identify g, f, c 2g = −4  →  g = −2 2f = 6  →  f = 3 c = −12 // Centre = (−g, −f) Centre = (−(−2), −3) = (2, −3) // Radius = √(g² + f² − c) r = √((−2)² + (3)² − (−12)) r = √(4 + 9 + 12) r = √25 = 5
Centre = (2, −3)  |  Radius = 5
Q.5 Find the centre and radius of the circle: x² + y² + 6x − 8y − 24 = 0 ▼ Solution
✅ Step-by-Step Solution
x² + y² + 6x − 8y − 24 = 0
Comparing with x² + y² + 2gx + 2fy + c = 0
2g = 6  →  g = 3 2f = −8  →  f = −4 c = −24 Centre = (−g, −f) = (−3, 4) r = √(g² + f² − c) = √(9 + 16 + 24) = √49 = 7
Centre = (−3, 4)  |  Radius = 7
Q.6 Find the equation of a circle passing through the origin with centre (3, 4). ▼ Solution
✅ Step-by-Step Solution
Given: Centre C(3, 4), passes through O(0, 0)
// Radius = distance from centre to origin r = √((3−0)² + (4−0)²) = √(9 + 16) = √25 = 5 // Equation of circle (x − 3)² + (y − 4)² = 25 x² − 6x + 9 + y² − 8y + 16 = 25 x² + y² − 6x − 8y + 25 − 25 = 0 x² + y² − 6x − 8y = 0
∴ x² + y² − 6x − 8y = 0
Q.7 Find the equation of the circle with diameter having endpoints A(1, 2) and B(5, 6). ▼ Solution
✅ Step-by-Step Solution
Given: A(x₁, y₁) = (1, 2), B(x₂, y₂) = (5, 6) are ends of diameter
// Method 1: Diameter form (x − x₁)(x − x₂) + (y − y₁)(y − y₂) = 0 (x − 1)(x − 5) + (y − 2)(y − 6) = 0 x² − 6x + 5 + y² − 8y + 12 = 0 x² + y² − 6x − 8y + 17 = 0 // Method 2: Find centre & radius Centre = midpoint of AB = ((1+5)/2, (2+6)/2) = (3, 4) r = ½ × AB = ½ × √((5−1)² + (6−2)²) = ½ × √(16+16) = ½ × 4√2 = 2√2
∴ x² + y² − 6x − 8y + 17 = 0
Q.8 Find the equation of the circle with diameter having endpoints (−3, 4) and (5, −2). ▼ Solution
✅ Step-by-Step Solution
A(x₁, y₁) = (−3, 4), B(x₂, y₂) = (5, −2)
(x − (−3))(x − 5) + (y − 4)(y − (−2)) = 0 (x + 3)(x − 5) + (y − 4)(y + 2) = 0 x² − 5x + 3x − 15 + y² + 2y − 4y − 8 = 0 x² + y² − 2x − 2y − 23 = 0
∴ x² + y² − 2x − 2y − 23 = 0
Q.9 Show that the points (1, 1), (−6, 0), (−2, 4) and (−2, −4) are concyclic. Find the equation of the circle. ▼ Solution
✅ Step-by-Step Solution
Points: A(1,1), B(−6,0), C(−2,4), D(−2,−4)
// Let general circle: x² + y² + 2gx + 2fy + c = 0 // Substituting A(1,1): 1 + 1 + 2g + 2f + c = 0 2g + 2f + c = −2 ...(1) // Substituting B(−6,0): 36 + 0 − 12g + 0 + c = 0 −12g + c = −36 ...(2) // Substituting C(−2,4): 4 + 16 − 4g + 8f + c = 0 −4g + 8f + c = −20 ...(3) // From (1)−(2): 14g + 2f = 34 → 7g + f = 17 ...(4) From (2)−(3): −8g − 8f = −16 → g + f = 2 ...(5) From (4)−(5): 6g = 15 → g = 5/2 f = 2 − g = 2 − 5/2 = −1/2 From (2): c = −36 + 12g = −36 + 30 = −6 // Equation: x² + y² + 5x − y − 6 = 0 // Verify D(−2,−4): 4 + 16 − 10 + 4 − 6 = 8 ≠ 0 // Let's recheck with centre-radius method Centre = (−g, −f) = (−5/2, 1/2) r = √(g²+f²−c) = √(25/4 + 1/4 + 6) = √(26/4 + 6) = √(50/4) = 5√2/2
Circle: x² + y² + 5x − y − 6 = 0
Q.10 Find the equation of the circle passing through (3, 4) and having centre on the X-axis with radius 5. ▼ Solution
✅ Step-by-Step Solution
Circle passes through P(3,4), centre is on X-axis → C(h, 0), r = 5
// Since P(3,4) is on circle, CP = r = 5 (3 − h)² + (4 − 0)² = 5² (3 − h)² + 16 = 25 (3 − h)² = 9 3 − h = ±3 h = 0  or  h = 6 // Two circles are possible: Case 1: Centre (0,0), r=5 → x² + y² = 25 Case 2: Centre (6,0), r=5 → (x−6)² + y² = 25                            x² + y² − 12x + 11 = 0
x² + y² = 25  or  x² + y² − 12x + 11 = 0
Q.11 Find the equation of the circle passing through (1, −3) and (4, 5) with centre on the line 5x − 2y + 1 = 0. ▼ Solution
✅ Step-by-Step Solution
Circle passes through A(1,−3) and B(4,5). Centre lies on 5x − 2y + 1 = 0
// Let centre = C(h, k). Then CA = CB (equal radii) CA² = CB² (h−1)² + (k+3)² = (h−4)² + (k−5)² h²−2h+1 + k²+6k+9 = h²−8h+16 + k²−10k+25 −2h + 6k + 10 = −8h − 10k + 41 6h + 16k = 31 ...(1) // Centre also lies on 5x − 2y + 1 = 0 5h − 2k + 1 = 0 → k = (5h + 1)/2 ...(2) // Substituting (2) in (1): 6h + 16 × (5h+1)/2 = 31 6h + 8(5h+1) = 31 6h + 40h + 8 = 31 46h = 23 → h = 1/2 k = (5×½ + 1)/2 = (5/2 + 1)/2 = (7/2)/2 = 7/4 // r² = CA² = (1/2−1)² + (7/4+3)² = 1/4 + (19/4)² = 1/4 + 361/16 = 365/16 r² = (h−1)² + (k+3)² = (−1/2)² + (7/4+3)² = 1/4 + (19/4)² = 1/4 + 361/16 = 365/16 // Equation: (x−1/2)² + (y−7/4)² = 365/16
Centre = (1/2, 7/4)  |  (x − 1/2)² + (y − 7/4)² = 365/16
Q.12 Find the equation of a circle touching both coordinate axes and having radius 5. ▼ Solution
✅ Step-by-Step Solution
Circle touches both X-axis and Y-axis, r = 5
// If circle touches both axes, centre is at (±r, ±r) = (±5, ±5) Four possible centres: (5,5), (5,−5), (−5,5), (−5,−5) // Four equations: (x−5)² + (y−5)² = 25  →  x²+y²−10x−10y+25=0 (x−5)² + (y+5)² = 25  →  x²+y²−10x+10y+25=0 (x+5)² + (y−5)² = 25  →  x²+y²+10x−10y+25=0 (x+5)² + (y+5)² = 25  →  x²+y²+10x+10y+25=0
Four circles: centres (±5, ±5), all with r = 5
Q.13 Find the equation of a circle that passes through the points (1, 1), (2, −1) and (3, 2). ▼ Solution
✅ Step-by-Step Solution
Points: A(1,1), B(2,−1), C(3,2)
// Let circle: x² + y² + 2gx + 2fy + c = 0 // Substituting A(1,1): 1+1+2g+2f+c=0 2g + 2f + c = −2 ...(1) // Substituting B(2,−1): 4+1+4g−2f+c=0 4g − 2f + c = −5 ...(2) // Substituting C(3,2): 9+4+6g+4f+c=0 6g + 4f + c = −13 ...(3) // (2)−(1): 2g − 4f = −3 ...(4) // (3)−(1): 4g + 2f = −11 ...(5) From (4): 2g = 4f − 3 → g = (4f−3)/2 Sub in (5): 4×(4f−3)/2 + 2f = −11 2(4f−3) + 2f = −11 8f − 6 + 2f = −11 → 10f = −5 → f = −1/2 g = (4×(−1/2)−3)/2 = (−2−3)/2 = −5/2 From (1): c = −2 − 2(−5/2) − 2(−1/2) = −2 + 5 + 1 = 4 // Equation: x² + y² − 5x − y + 4 = 0
∴ x² + y² − 5x − y + 4 = 0
Verify: A(1,1): 1+1−5−1+4=0 ✓ | B(2,−1): 4+1−10+1+4=0 ✓ | C(3,2): 9+4−15−2+4=0 ✓
Q.14 Find the equation of the circle concentric with x² + y² − 4x + 6y − 3 = 0 and passing through (−4, −5). ▼ Solution
✅ Step-by-Step Solution
Given circle: x² + y² − 4x + 6y − 3 = 0, passes through (−4,−5)
// Find centre of given circle 2g = −4 → g = −2,  2f = 6 → f = 3 Centre = (−g, −f) = (2, −3) // New circle has same centre (2, −3), passes through (−4, −5) r² = (2−(−4))² + (−3−(−5))² r² = (6)² + (2)² = 36 + 4 = 40 // Equation of new circle (x − 2)² + (y + 3)² = 40 x² − 4x + 4 + y² + 6y + 9 = 40 x² + y² − 4x + 6y − 27 = 0
∴ x² + y² − 4x + 6y − 27 = 0

Exercise 6.2 — Tangents to a Circle

Equation of tangent · Condition for tangency · Length of tangent

Q.1 Find the equation of the tangent to circle x² + y² = 25 at point (3, 4). ▼ Solution
✅ Step-by-Step Solution
Circle: x² + y² = 25, Point (x₁, y₁) = (3, 4)
// First verify the point is on the circle 3² + 4² = 9 + 16 = 25 ✓ (point is on circle) // Tangent at (x₁, y₁): xx₁ + yy₁ = r² x(3) + y(4) = 25 3x + 4y = 25
∴ 3x + 4y = 25
Q.2 Find the equation of the tangent to circle x² + y² = 16 at (2√2, 2√2). ▼ Solution
✅ Step-by-Step Solution
Circle: x² + y² = 16, Point = (2√2, 2√2)
// Verify: (2√2)² + (2√2)² = 8 + 8 = 16 ✓ Tangent: x(2√2) + y(2√2) = 16 2√2 x + 2√2 y = 16 √2 x + √2 y = 8 x + y = 8/√2 = 4√2
∴ x + y = 4√2
Q.3 Show that the line y = x + 2 is a tangent to the circle x² + y² = 2 and find the point of contact. ▼ Solution
✅ Step-by-Step Solution
Line: y = x + 2  (m = 1, c = 2), Circle: x² + y² = 2  (r = √2)
// Condition for tangency: c² = r²(1 + m²) LHS: c² = (2)² = 4 RHS: r²(1 + m²) = 2(1 + 1) = 4 LHS = RHS = 4 ✓ → Line is tangent // Point of contact: substitute y = x + 2 in circle x² + (x + 2)² = 2 x² + x² + 4x + 4 = 2 2x² + 4x + 2 = 0 x² + 2x + 1 = 0 (x + 1)² = 0 → x = −1 (repeated root → tangent confirmed) y = −1 + 2 = 1
Point of contact = (−1, 1)
Q.4 Find the equations of the tangents to the circle x² + y² = 9 having slope 1. ▼ Solution
✅ Step-by-Step Solution
Circle: x² + y² = 9 (r² = 9, r = 3), slope m = 1
// Tangent: y = mx ± r√(1 + m²) y = 1·x ± 3·√(1 + 1²) y = x ± 3√2 // Two tangents: y = x + 3√2   i.e. x − y + 3√2 = 0 y = x − 3√2   i.e. x − y − 3√2 = 0
y = x + 3√2   and   y = x − 3√2
Q.5 Find the equations of the tangents to the circle x² + y² = 4 making equal intercepts on coordinate axes. ▼ Solution
✅ Step-by-Step Solution
Circle: x² + y² = 4 (r = 2). Equal intercepts on axes → slope = −1 (or m = ±1)
// Equal intercepts means x-intercept = y-intercept // Line: x/a + y/a = 1 → x + y = a → y = −x + a (m = −1) // Using tangency condition c² = r²(1+m²) a² = 4(1 + 1) = 8 a = ±2√2 x + y = 2√2  and  x + y = −2√2
x + y = ±2√2
Q.6 Find the length of the tangent from the point (5, 1) to the circle x² + y² + 6x − 4y − 3 = 0. ▼ Solution
✅ Step-by-Step Solution
Point P(x₁,y₁) = (5, 1), Circle: x² + y² + 6x − 4y − 3 = 0
// Length = √(x₁² + y₁² + 2gx₁ + 2fy₁ + c) // Here 2g = 6, 2f = −4, c = −3 Length = √(5² + 1² + 6×5 + (−4)×1 + (−3)) = √(25 + 1 + 30 − 4 − 3) = √49 = 7
Length of tangent = 7 units
Q.7 If the length of tangent from (1, 2) to the circle x² + y² + 2kx + 5 = 0 is 2, find the value of k. ▼ Solution
✅ Step-by-Step Solution
Point P(1, 2), Circle: x² + y² + 2kx + 5 = 0, Length = 2
// Length² = x₁² + y₁² + 2kx₁ + 5 2² = 1² + 2² + 2k(1) + 5 4 = 1 + 4 + 2k + 5 4 = 10 + 2k 2k = 4 − 10 = −6 k = −3
k = −3
Q.8 Find the equation of the tangent to circle (x−2)² + (y+3)² = 25 at (6, 0). ▼ Solution
✅ Step-by-Step Solution
Circle: (x−2)² + (y+3)² = 25, Centre C(2,−3), Point P(6,0)
// Tangent: (x₁−h)(x−h) + (y₁−k)(y−k) = r² (6−2)(x−2) + (0+3)(y+3) = 25 4(x−2) + 3(y+3) = 25 4x − 8 + 3y + 9 = 25 4x + 3y + 1 = 25 4x + 3y − 24 = 0
∴ 4x + 3y − 24 = 0

Exercise 6.3 — Miscellaneous / Director Circle

Director circle · Position of point · Two circles · Arc

Q.1 Find the equation of the director circle of x² + y² = 100. ▼ Solution
✅ Step-by-Step Solution
Circle: x² + y² = 100, so r² = 100
// Director circle equation: x² + y² = 2r² x² + y² = 2 × 100 x² + y² = 200
∴ x² + y² = 200  (radius = 10√2)
Q.2 Find the director circle of (x − 2)² + (y − 3)² = 16. ▼ Solution
✅ Step-by-Step Solution
Circle: (x−2)² + (y−3)² = 16, Centre (2,3), r² = 16, r = 4
// Director circle: same centre, radius = r√2 New radius = 4√2, so (new radius)² = 32 (x − 2)² + (y − 3)² = 32
∴ (x − 2)² + (y − 3)² = 32
Q.3 Find the position of the point (3, 4) with respect to the circle x² + y² = 20. ▼ Solution
✅ Step-by-Step Solution
Point P(3, 4), Circle: x² + y² = 20
// Let S₁ = x₁² + y₁² − r² S₁ = 3² + 4² − 20 = 9 + 16 − 20 = 5 S₁ = 5 > 0
Point (3, 4) is OUTSIDE the circle
Q.4 Find the position of the point (1, −2) with respect to the circle x² + y² − 4x + 2y − 11 = 0. ▼ Solution
✅ Step-by-Step Solution
Point P(1, −2), Circle: x² + y² − 4x + 2y − 11 = 0
// Substitute point in LHS of circle equation S₁ = 1² + (−2)² − 4(1) + 2(−2) − 11 = 1 + 4 − 4 − 4 − 11 = −14 S₁ = −14 < 0
Point (1, −2) is INSIDE the circle
Q.5 Find the number of tangents to x² + y² = 4 from the point (3, 0). ▼ Solution
✅ Step-by-Step Solution
Circle: x² + y² = 4 (r = 2), External point P(3, 0)
// First check position of point S₁ = 3² + 0² − 4 = 9 − 4 = 5 > 0 Point is OUTSIDE the circle // Number of tangents from external point = 2 // Find tangent lines: y − 0 = m(x − 3) → y = mx − 3m mx − y − 3m = 0 // Distance from O(0,0) = r: |−3m|/√(m²+1) = 2 9m² = 4(m² + 1) = 4m² + 4 5m² = 4 → m = ±2/√5 Two tangent lines exist
2 tangents can be drawn from (3, 0) to the circle
Q.6 Find the number of common tangents to: x² + y² = 4 and x² + y² − 6x − 8y + 16 = 0. ▼ Solution
✅ Step-by-Step Solution
Circle 1: x²+y²=4 → C₁(0,0), r₁=2
Circle 2: x²+y²−6x−8y+16=0 → 2g=−6, 2f=−8, c=16
// Find C₂ and r₂ C₂ = (3, 4), r₂ = √(9+16−16) = √9 = 3 // Distance between centres d = √((3−0)² + (4−0)²) = √(9+16) = √25 = 5 // Compare with r₁ + r₂ = 2 + 3 = 5 d = 5 = r₁ + r₂ // Circles touch EXTERNALLY
Circles touch externally → 3 common tangents
Q.7 Determine whether the circles x²+y²−4=0 and x²+y²−6x−8y+16=0 touch each other. ▼ Solution
✅ Step-by-Step Solution
C₁: x²+y²=4 → Centre (0,0), r₁=2
C₂: x²+y²−6x−8y+16=0 → Centre (3,4), r₂=3
d(C₁C₂) = √(3²+4²) = √25 = 5 r₁ + r₂ = 2 + 3 = 5 d = r₁ + r₂
Yes, the circles touch each other EXTERNALLY at one point
Point of contact divides C₁C₂ in ratio r₁:r₂ = 2:3 from C₁(0,0): Point = (6/5, 8/5)
Q.8 Find the equation of a circle passing through (0, 0) and (2, 0) with centre on the line 2x + y = 3. ▼ Solution
✅ Step-by-Step Solution
Circle passes through O(0,0) and A(2,0). Centre on 2x + y = 3.
// Let centre = C(h, k). CO = CA (equal radii) CO² = CA² h² + k² = (h−2)² + k² h² = h² − 4h + 4 4h = 4 → h = 1 // Centre also on 2x + y = 3 2(1) + k = 3 → k = 1 // Radius = CO = √(1² + 1²) = √2 r² = 1 + 1 = 2 // Equation (x − 1)² + (y − 1)² = 2 x² − 2x + 1 + y² − 2y + 1 = 2 x² + y² − 2x − 2y = 0
∴ x² + y² − 2x − 2y = 0
Q.9 Find the equation of a circle touching the X-axis at (3, 0) and passing through (1, 4). ▼ Solution
✅ Step-by-Step Solution
Circle touches X-axis at (3, 0), passes through (1, 4)
// If circle touches X-axis at (3,0), centre is (3, k) for some k // and radius = |k| (perpendicular distance from centre to X-axis) Centre = (3, k), r = |k| // Since (1, 4) is on circle: distance from centre = r (1−3)² + (4−k)² = k² 4 + 16 − 8k + k² = k² 20 − 8k = 0 k = 20/8 = 5/2 // Centre = (3, 5/2), r = 5/2 (x−3)² + (y−5/2)² = 25/4 x²−6x+9 + y²−5y+25/4 = 25/4 x² + y² − 6x − 5y + 9 = 0
∴ x² + y² − 6x − 5y + 9 = 0
Q.10 If the lines 3x − 4y + 4 = 0 and 6x − 8y − 7 = 0 are tangents to a circle, find its radius. ▼ Solution
✅ Step-by-Step Solution
L₁: 3x − 4y + 4 = 0, L₂: 6x − 8y − 7 = 0 are parallel tangents
// Rewrite L₂ as: 3x − 4y − 7/2 = 0 // Both lines have slope 3/4 → parallel tangents // Diameter = distance between parallel tangents Distance between L₁ and L₂ = |c₁ − c₂| / √(a² + b²) L₁: 3x − 4y + 4 = 0 L₂: 3x − 4y − 7/2 = 0 d = |4 − (−7/2)| / √(3² + 4²) d = |4 + 3.5| / √25 = 7.5 / 5 = 3/2 // Diameter = 3/2, so radius = 3/4
Radius = 3/4
