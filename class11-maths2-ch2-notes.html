⭐ All Key Formulas at a Glance

  • A.P. nth term: tₙ = a + (n−1)d  |  Sum: Sₙ = n/2[2a+(n−1)d]
  • G.P. nth term: tₙ = arⁿ⁻¹  |  Sum: Sₙ = a(rⁿ−1)/(r−1), r≠1
  • Infinite G.P.: S∞ = a/(1−r), only when |r| < 1
  • 3 numbers in G.P.: take a/r, a, ar → product = a³
  • 4 numbers in G.P.: take a/r³, a/r, ar, ar³ → product = a⁴
  • H.P. nth term: reciprocals in A.P. → tₙ(HP) = 1/[a+(n−1)d]
  • A.M. = (x+y)/2  |  G.M. = √(xy)  |  H.M. = 2xy/(x+y)
  • G² = AH  |  A ≥ G ≥ H (for positive numbers)
  • A.G.P. tₙ = [a+(n−1)d]rⁿ⁻¹  |  S∞ = a/(1−r) + dr/(1−r)²
  • Σr = n(n+1)/2  |  Σr² = n(n+1)(2n+1)/6  |  Σr³ = [n(n+1)/2]²

Geometric Progression (G.P.) — Theory
  • G.P.: tₙ₊₁/tₙ = r (constant common ratio) for all n
  • G.P. written as: a, ar, ar², ar³, ... where a = first term, r = common ratio
  • nth term: tₙ = arⁿ⁻¹
  • Property: If t₁,t₂,...,tₙ in G.P. then 1/t₁, 1/t₂,... also in G.P.
  • For 3 numbers in G.P.: take a/r, a, ar → product = a³
  • For 4 numbers in G.P.: take a/r³, a/r, ar, ar³ → product = a⁴
  • For 5 numbers in G.P.: take a/r², a/r, a, ar, ar² → product = a⁵

Exercise 2.1 — G.P. nth Term (Solved)
Q1
Check whether the following sequences are G.P. If so, write tₙ.
i) 2, 6, 18, 54, ...   ii) 1, −5, 25, −125, ...   iii) √5, 1/√5, 1/5√5, ...   iv) 3, 4, 5, 6, ...   v) 7, 14, 21, 28, ...
★★
Solution

Rule: Check if t₂/t₁ = t₃/t₂ = constant (r). If yes → G.P., find tₙ = arⁿ⁻¹

i) 2, 6, 18, 54, ...

t₂/t₁ = 6/2 = 3

t₃/t₂ = 18/6 = 3

t₄/t₃ = 54/18 = 3 → r = 3 (constant)

∴ YES, it is a G.P. with a = 2, r = 3

tₙ = 2 × 3ⁿ⁻¹

ii) 1, −5, 25, −125, ...

t₂/t₁ = −5/1 = −5

t₃/t₂ = 25/(−5) = −5 → r = −5 (constant)

∴ YES, it is a G.P. with a = 1, r = −5

tₙ = (−5)ⁿ⁻¹

iii) √5, 1/√5, 1/5√5, ...

t₂/t₁ = (1/√5)/√5 = 1/5

t₃/t₂ = (1/5√5)/(1/√5) = 1/5 → r = 1/5 (constant)

∴ YES, it is a G.P. with a = √5 = 5^(1/2), r = 1/5

tₙ = 5^((3−2n)/2)

iv) 3, 4, 5, 6, ...

t₂/t₁ = 4/3  |  t₃/t₂ = 5/4 → ratios NOT equal

∴ NOT a G.P. (this is an A.P. with d = 1)

v) 7, 14, 21, 28, ...

t₂/t₁ = 14/7 = 2  |  t₃/t₂ = 21/14 = 3/2 → NOT equal

∴ NOT a G.P. (this is an A.P. with d = 7)

Q2
For the G.P.:
i) r = 1/3, a = 9, find t₇   ii) a = 7/243, r = 3, find t₆
iii) r = −3, t₆ = 1701, find a   iv) a = 2/3, t₆ = 162, find r
★★
Solution

Formula: tₙ = arⁿ⁻¹

i) r = 1/3, a = 9, find t₇

t₇ = a × r⁶ = 9 × (1/3)⁶

= 9 × 1/729

= 9/729

t₇ = 1/81

ii) a = 7/243, r = 3, find t₆

t₆ = a × r⁵ = (7/243) × 3⁵

= (7/243) × 243

t₆ = 7

iii) r = −3, t₆ = 1701, find a

t₆ = a × r⁵ = a × (−3)⁵ = a × (−243) = 1701

a = 1701 ÷ (−243)

a = −7

iv) a = 2/3, t₆ = 162, find r

t₆ = (2/3) × r⁵ = 162

r⁵ = 162 × 3/2 = 243 = 3⁵

r = 3

Q3
Which term of the G.P. 5, 25, 125, 625, ... is 5¹⁰?
★★
Solution

Given: a = 5, r = 25/5 = 5, tₙ = 5¹⁰

tₙ = arⁿ⁻¹

5¹⁰ = 5 × 5ⁿ⁻¹

5¹⁰ = 5ⁿ

∴ n = 10

5¹⁰ is the 10th term

Q4
For what values of x are the terms 4/3, x, 4/27 in G.P.?
★★
Solution

For three terms a, b, c in G.P.: b² = ac

x² = (4/3) × (4/27)

x² = 16/81

x = ± √(16/81)

x = 4/9   or   x = −4/9

Q6
Find three numbers in G.P. such that their sum is 21 and sum of their squares is 189.
★★★
Solution

Let three numbers in G.P. be a/r, a, ar

Sum of squares: (a/r)² + a² + (ar)² = 189 ...(2)

Sum: a/r + a + ar = 21 ...(1)

Try a = 6, r = 2 (from sum condition):

Numbers: 3, 6, 12

Sum = 3 + 6 + 12 = 21 ✓

Sum of squares = 9 + 36 + 144 = 189 ✓

Numbers are 3, 6, 12

Q11
The number of bacteria doubles every hour. If there were 50 bacteria originally, how many will be there at end of 5th hour?
★★
Solution

This forms a G.P. with a = 50, r = 2

After 5 hours → t₆ = a × r⁵

= 50 × 2⁵

= 50 × 32

= 1600 bacteria

Q13
The numbers 3, x and x + 6 are in G.P. Find (i) x   (ii) 20th term   (iii) nth term
★★★
Solution

For G.P.: x² = 3(x + 6)

x² = 3x + 18

x² − 3x − 18 = 0

(x − 6)(x + 3) = 0

x = 6   or   x = −3

Taking x = 6: G.P. is 3, 6, 12 → a = 3, r = 2

t₂₀ = 3 × 2¹⁹ = 3 × 524288

t₂₀ = 1572864

tₙ = 3 × 2ⁿ⁻¹

Sum of G.P. — Formulas
  • Sₙ = a(rⁿ−1)/(r−1)   when r > 1
  • Sₙ = a(1−rⁿ)/(1−r)   when r < 1
  • Sₙ = a × n   when r = 1
  • tₙ = Sₙ − Sₙ₋₁

Exercise 2.2 — Sum of G.P. (Solved)
Q1
Find Sₙ for: i) 3, 6, 12, 24, ...   ii) 0.7, 0.07, 0.007, ...
★★
Solution

i) 3, 6, 12, 24, ... → a = 3, r = 2

Sₙ = a(rⁿ−1)/(r−1)

= 3(2ⁿ−1)/(2−1)

Sₙ = 3(2ⁿ−1)

ii) 0.7, 0.07, 0.007, ... → a = 0.7, r = 0.1

Sₙ = a(1−rⁿ)/(1−r)

= 0.7(1−0.1ⁿ)/(1−0.1)

= 0.7(1−0.1ⁿ)/0.9

Sₙ = 7/9 × (1 − (1/10)ⁿ)

Q3
i) a = 2, r = 3, Sₙ = 242, find n    ii) Sum of first 3 terms = 125, sum of next 3 terms = 27, find r
★★★
Solution

i) a = 2, r = 3, Sₙ = 242, find n

Sₙ = 2(3ⁿ−1)/(3−1) = (3ⁿ−1) = 242

3ⁿ = 243 = 3⁵

n = 5

ii) S₃ = 125, S₆ − S₃ = 27

S₆ = 125 + 27 = 152

S₆/S₃ = (1−r⁶)/(1−r³) = 152/125

(1 + r³) = 152/125

r³ = 152/125 − 1 = 27/125

r = 3/5

Q5
Find the sum to n terms: i) 3 + 33 + 333 + ...   ii) 8 + 88 + 888 + ...
★★★
Solution

i) 3 + 33 + 333 + ...

= 3(1 + 11 + 111 + ...)

= 3/9 × (9 + 99 + 999 + ...)

= 1/3 × [(10−1) + (100−1) + (1000−1) + ...]

= 1/3 × [(10 + 100 + ... n terms) − n]

= 1/3 × [10(10ⁿ−1)/9 − n]

Sₙ = (10/27)(10ⁿ−1) − n/3

ii) 8 + 88 + 888 + ...

= 8/9 × (9 + 99 + 999 + ...)

= 8/9 × [(10 + 100 + ... n terms) − n]

Sₙ = (80/81)(10ⁿ−1) − 8n/9

Q8
For a sequence, if Sₙ = 2(3ⁿ − 1), find the nth term and show it is a G.P.
★★★
Solution

Using tₙ = Sₙ − Sₙ₋₁:

Sₙ = 2(3ⁿ − 1)

Sₙ₋₁ = 2(3ⁿ⁻¹ − 1)

tₙ = 2(3ⁿ − 1) − 2(3ⁿ⁻¹ − 1)

= 2 × 3ⁿ − 2 × 3ⁿ⁻¹

= 2 × 3ⁿ⁻¹(3 − 1)

tₙ = 4 × 3ⁿ⁻¹

Verify G.P.:

tₙ₊₁/tₙ = (4 × 3ⁿ)/(4 × 3ⁿ⁻¹) = 3 = constant

∴ It is a G.P. with r = 3, first term t₁ = 4

Infinite G.P. & Recurring Decimals
  • S∞ = a/(1−r) only when |r| < 1
  • If |r| ≥ 1 → sum to infinity does NOT exist
  • Recurring decimal → write as G.P. → use S∞

Exercise 2.3 — Infinite G.P. (Solved)
Q1
Determine if sum to infinity exists. If yes, find it.
i) 1/2, 1/4, 1/8, ...   ii) 2, 4/3, 8/9, ...   iii) −3, 1, −1/3, 1/9, ...   iv) 1/5, −2/5, 4/5, ...   v) 9, 8.1, 7.29, ...
★★
Solution

Rule: S∞ exists only if |r| < 1. Then S∞ = a/(1−r)

i) 1/2, 1/4, 1/8, ... → a = 1/2, r = 1/2

|r| = 1/2 < 1 → S∞ exists

S∞ = (1/2)/(1 − 1/2) = (1/2)/(1/2)

S∞ = 1

ii) 2, 4/3, 8/9, ... → a = 2, r = 2/3

|r| = 2/3 < 1 → S∞ exists

S∞ = 2/(1 − 2/3) = 2/(1/3)

S∞ = 6

iii) −3, 1, −1/3, 1/9, ... → a = −3, r = −1/3

|r| = 1/3 < 1 → S∞ exists

S∞ = −3/(1 − (−1/3)) = −3/(4/3)

S∞ = −9/4

iv) 1/5, −2/5, 4/5, ... → a = 1/5, r = −2

|r| = 2 > 1 → S∞ does NOT exist

v) 9, 8.1, 7.29, ... → a = 9, r = 0.9

|r| = 0.9 < 1 → S∞ exists

S∞ = 9/(1 − 0.9) = 9/0.1

S∞ = 90

Q2
Express as rational numbers: i) 0.7̄   ii) 2.4̄   iii) 2.35̄   iv) 51.0̄2̄
★★★
Solution

Method: Write as G.P. with S∞ = a/(1−r)

i) 0.777... = 0.7 + 0.07 + 0.007 + ...

a = 0.7, r = 0.1

S∞ = 0.7/(1 − 0.1) = 0.7/0.9

= 7/9

ii) 2.444... = 2 + 0.4 + 0.04 + ...

= 2 + [a = 0.4, r = 0.1]

= 2 + 0.4/0.9 = 2 + 4/9

= 22/9

iii) 2.3555... = 2.3 + 0.05 + 0.005 + ...

= 23/10 + [a = 0.05, r = 0.1]

= 23/10 + 0.05/0.9 = 23/10 + 1/18

= 207/90 + 5/90

= 212/90 = 106/45

iv) 51.0202... = 51 + 0.02 + 0.0002 + ...

= 51 + [a = 0.02, r = 0.01]

= 51 + 0.02/0.99 = 51 + 2/99

= 5051/99

Q5
Sum of infinite G.P. is 5 and sum of squares of terms is 15. Find the G.P.
★★★
Solution

S∞ = a/(1−r) = 5 ...(1)

Squares form G.P. with first term a², ratio r²:

a²/(1−r²) = 15 ...(2)

Divide (2) by (1)²:

[a²/(1−r²)] ÷ [a²/(1−r)²] = 15/25

(1−r)²/(1−r²) = 3/5

(1−r)/(1+r) = 3/5

5 − 5r = 3 + 3r

8r = 2 → r = 1/4

From (1): a/(1 − 1/4) = 5 → a/(3/4) = 5

a = 15/4

G.P. = 15/4, 15/16, 15/64, ...

H.P. and Means (A.M., G.M., H.M.)
  • H.P.: 1/t₁, 1/t₂, ... are in A.P. → tₙ(HP) = 1/[a+(n−1)d]
  • A.M. = (x+y)/2  |  G.M. = √(xy)  |  H.M. = 2xy/(x+y)
  • G² = AH  |  A ≥ G ≥ H for positive x, y
  • If x = y then A = G = H

Exercise 2.4 — H.P. and Means (Solved)
Q2
Find nth term and 8th term of H.P.:
i) 1/2, 1/5, 1/8, 1/11, ...   ii) 1/4, 1/6, 1/8, 1/10, ...   iii) 1/5, 1/10, 1/15, 1/20, ...
★★★
Solution

Method: Write reciprocals → form A.P. → find nth term → take reciprocal back

i) Reciprocals: 2, 5, 8, 11, ... → a = 2, d = 3

tₙ of A.P. = 2 + (n−1) × 3 = 3n − 1

tₙ of H.P. = 1/(3n−1)

t₈ = 1/(3×8−1) = 1/23

ii) Reciprocals: 4, 6, 8, 10, ... → a = 4, d = 2

tₙ of A.P. = 4 + (n−1) × 2 = 2n + 2

tₙ of H.P. = 1/(2n+2) = 1/2(n+1)

t₈ = 1/18

iii) Reciprocals: 5, 10, 15, 20, ... → a = 5, d = 5

tₙ of A.P. = 5n

tₙ of H.P. = 1/(5n)

t₈ = 1/40

Q3
Find A.M. of two positive numbers whose G.M. = 4 and H.M. = 16/5
★★
Solution

Given: G = 4, H = 16/5

Using G² = AH:

4² = A × (16/5)

16 = A × 16/5

A = 16 × 5/16

A.M. = 5

Q5
Find G.M. of two positive numbers whose A.M. = 75 and H.M. = 48
★★
Solution

Given: A = 75, H = 48

Using G² = AH:

G² = 75 × 48 = 3600

G = √3600

G.M. = 60

  • A.G.P. tₙ = [a + (n−1)d] × rⁿ⁻¹
  • S∞ = a/(1−r) + dr/(1−r)² when |r| < 1

Exercise 2.5 — A.G.P. (Solved)
Q2i
Find sum to infinity of: 1, 2/4, 3/16, 4/64, ...
★★★
Solution

= 1×1, 2×(1/4), 3×(1/4)², 4×(1/4)³, ...

A.P. part: 1, 2, 3, 4 → a = 1, d = 1

G.P. part: 1, 1/4, (1/4)², ... → r = 1/4

Using S∞ = a/(1−r) + dr/(1−r)²:

= 1/(1−1/4) + 1×(1/4)/(1−1/4)²

= 1/(3/4) + (1/4)/(9/16)

= 4/3 + (1/4)×(16/9)

= 4/3 + 4/9

= 12/9 + 4/9

S∞ = 16/9

Summation (Σ) Formulas
  • Σr = n(n+1)/2 (sum of first n natural numbers)
  • Σr² = n(n+1)(2n+1)/6 (sum of squares)
  • Σr³ = [n(n+1)/2]² (sum of cubes)
  • Σ1 = n  |  Σk = kn

Exercise 2.6 — Summation (Solved)
Q1
Find the sum Σ(r+1)(2r−1) from r = 1 to n
★★★
Solution

Expand (r+1)(2r−1):

= 2r² + 2r − r − 1

= 2r² + r − 1

Σ(2r² + r − 1) = 2Σr² + Σr − Σ1

= 2 × n(n+1)(2n+1)/6 + n(n+1)/2 − n

= n(n+1)(2n+1)/3 + n(n+1)/2 − n

= n[((n+1)(2n+1)/3) + (n+1)/2 − 1]

= n[2(n+1)(2n+1) + 3(n+1) − 6] / 6

= n[4n² + 6n + 2 + 3n + 3 − 6] / 6

= n[4n² + 9n − 1] / 6

Sₙ = n(4n² + 9n − 1)/6

Q2
Find Σ(3r² − 2r + 1) from r = 1 to n
★★
Solution

= 3Σr² − 2Σr + Σ1

= 3 × n(n+1)(2n+1)/6 − 2 × n(n+1)/2 + n

= n(n+1)(2n+1)/2 − n(n+1) + n

= n[(n+1)(2n+1)/2 − (n+1) + 1]

= n[(2n²+3n+1)/2 − n]

= n[2n²+3n+1 − 2n] / 2

= n[2n² + n + 1] / 2

Sₙ = n(2n² + n + 1)/2

Q6
Find sum of 2² + 4² + 6² + 8² + ... upto n terms
★★
Solution

General term = (2r)² = 4r²

Sₙ = Σ 4r² = 4 Σr²

= 4 × n(n+1)(2n+1)/6

= 2n(n+1)(2n+1)/3

Sₙ = 2n(n+1)(2n+1)/3

Q5
Find the sum 5×7 + 9×11 + 13×15 + ... upto n terms
★★★
Solution

First factors: 5, 9, 13, ... → a = 5, d = 4 → rth term = 4r + 1

Second factors: 7, 11, 15, ... → a = 7, d = 4 → rth term = 4r + 3

tᵣ = (4r+1)(4r+3) = 16r² + 16r + 3

Sₙ = Σ(16r² + 16r + 3)

= 16Σr² + 16Σr + 3Σ1

= 16 × n(n+1)(2n+1)/6 + 16 × n(n+1)/2 + 3n

= 8n(n+1)(2n+1)/3 + 8n(n+1) + 3n

= n[8(n+1)(2n+1)/3 + 8(n+1) + 3]

Sₙ = n(16n² + 36n + 17)/3

Miscellaneous — Important Problems
M1
In a G.P., the 4th term is 48 and the 8th term is 768. Find the 10th term.
★★★
Solution

t₄ = ar³ = 48 ...(1)

t₈ = ar⁷ = 768 ...(2)

Divide (2) ÷ (1):

r⁴ = 768/48 = 16 = 2⁴

r = 2

From (1): a × 8 = 48 → a = 6

t₁₀ = ar⁹ = 6 × 2⁹ = 6 × 512

t₁₀ = 3072

M33
Find sum to infinity of: 1 + 4/5 + 7/25 + 10/125 + 13/625 + ...
★★★
Solution

A.G.P.: A.P. part: 1, 4, 7, 10, ... → a = 1, d = 3

G.P. part: 1, 1/5, (1/5)², ... → r = 1/5

S∞ = a/(1−r) + dr/(1−r)²

= 1/(1−1/5) + 3×(1/5)/(1−1/5)²

= 1/(4/5) + (3/5)/(16/25)

= 5/4 + (3/5)×(25/16)

= 5/4 + 15/16

= 20/16 + 15/16

S∞ = 35/16
