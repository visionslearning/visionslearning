Exercise 2.1 — G.P.: nᵗʰ Term
Q1
Check whether the following sequences are G.P. If so, write tₙ.
i) 2, 6, 18, 54, …   ii) 1, −5, 25, −125, …   iii) √5, 1/√5, 1/5√5, …   iv) 3, 4, 5, 6, …   v) 7, 14, 21, 28, …
Solution
i) 2, 6, 18, 54, …

t₂/t₁ = 6/2 = 3,   t₃/t₂ = 18/6 = 3,   t₄/t₃ = 54/18 = 3

∴ Common ratio r = 3 (constant)

∴ The sequence IS a G.P. with a = 2, r = 3.   tₙ = 2·(3)ⁿ⁻¹

ii) 1, −5, 25, −125, …

t₂/t₁ = −5/1 = −5,   t₃/t₂ = 25/(−5) = −5,   t₄/t₃ = −125/25 = −5

∴ r = −5 (constant)

∴ IS a G.P. with a = 1, r = −5.   tₙ = (−5)ⁿ⁻¹

iii) √5, 1/√5, 1/5√5, …

t₂/t₁ = (1/√5)/√5 = 1/5,   t₃/t₂ = (1/5√5)/(1/√5) = 1/5

∴ r = 1/5 (constant)

∴ IS a G.P. with a = √5, r = 1/5.   tₙ = √5·(1/5)ⁿ⁻¹ = 5^(3/2−n)

iv) 3, 4, 5, 6, …

t₂/t₁ = 4/3,   t₃/t₂ = 5/4 → ratios are NOT equal

∴ NOT a G.P. (it is an A.P. with d = 1)

v) 7, 14, 21, 28, …

t₂/t₁ = 14/7 = 2,   t₃/t₂ = 21/14 = 3/2 → ratios are NOT equal

∴ NOT a G.P. (it is an A.P. with d = 7)

Q2
For the G.P.: i) r = 1/3, a = 9, find t₇   ii) a = 7/243, r = 3, find t₆   iii) r = −3, t₆ = 1701, find a   iv) a = 2/3, t₆ = 162, find r
Solution   [Formula: tₙ = arⁿ⁻¹]
i) r = 1/3, a = 9, find t₇

t₇ = a·r⁶ = 9·(1/3)⁶

= 9 × 1/729

∴ t₇ = 1/81

ii) a = 7/243, r = 3, find t₆

t₆ = a·r⁵ = (7/243)·(3)⁵

= (7/243)·243

∴ t₆ = 7

iii) r = −3, t₆ = 1701, find a

t₆ = a·r⁵ = a·(−3)⁵ = −243a = 1701

∴ a = 1701/(−243)

∴ a = −7

iv) a = 2/3, t₆ = 162, find r

t₆ = a·r⁵ → 162 = (2/3)·r⁵

∴ r⁵ = 162 × 3/2 = 243 = 3⁵

∴ r = 3

Q3
Which term of the G.P. 5, 25, 125, 625, … is 5¹⁰?
Solution

Here a = 5, r = 5, tₙ = 5¹⁰

∴ arⁿ⁻¹ = 5¹⁰

∴ 5·5ⁿ⁻¹ = 5¹⁰

∴ 5ⁿ = 5¹⁰

∴ n = 10

∴ 5¹⁰ is the 10th term of the G.P.

Q4
For what values of x are the terms 4/3, x, 4/27 in G.P.?
Solution

If 4/3, x, 4/27 are in G.P., then x² = (4/3)·(4/27)

∴ x² = 16/81

∴ x = ±4/9

∴ x = 4/9   or   x = −4/9

Q5
If tₙ = 5ⁿ⁻³/2ⁿ⁻³, show the sequence is a G.P. Find first term and common ratio.
Solution

tₙ = 5ⁿ⁻³/2ⁿ⁻³ = (5/2)ⁿ⁻³

∴ tₙ₊₁ = (5/2)ⁿ⁻²

Consider tₙ₊₁/tₙ = (5/2)ⁿ⁻²/(5/2)ⁿ⁻³ = 5/2 = constant ∀ n ∈ ℕ

∴ The sequence is a G.P. with r = 5/2

t₁ = (5/2)¹⁻³ = (5/2)⁻² = (2/5)² = 4/25

∴ First term = 4/25, Common ratio = 5/2

Q6
Find three numbers in G.P. such that their sum is 21 and sum of their squares is 189.
Solution

Let the three numbers in G.P. be a/r, a, ar

Product = (a/r)·a·ar = a³

Sum of squares: a²/r² + a² + a²r² = 189   ...(2)

Sum: a/r + a + ar = 21   ...(1)

Dividing (2) by (1): a(1/r² + 1 + r²)/(1/r + 1 + r) = 9 → a = 9 when r = 2

Check with a = 3, r = 2: 3/2 + 3 + 6 = 10.5 ✗

Try numbers 3, 6, 12: sum = 21 ✓, sum of squares = 9+36+144 = 189 ✓

∴ a = 6, r = 2 (middle term)

∴ The three numbers are 3, 6, 12  (or 12, 6, 3)

Q7
Find four numbers in G.P. such that sum of middle two is 10/3 and product is 1.
Solution

Let the four numbers be a/r³, a/r, ar, ar³   (common ratio = r²)

Product: (a/r³)·(a/r)·(ar)·(ar³) = a⁴ = 1

∴ a = 1

Sum of middle two: a/r + ar = 10/3

∴ 1/r + r = 10/3

∴ 3r² − 10r + 3 = 0

∴ (3r − 1)(r − 3) = 0

∴ r = 1/3   or   r = 3

If r = 3: numbers = 1/27, 1/3, 3, 27

∴ The four numbers are 1/27, 1/3, 3, 27

Q8
Find five numbers in G.P. such that product = 1024 and fifth term = square of third term.
Solution

Let five numbers be a/r², a/r, a, ar, ar²

Product = a⁵ = 1024 = 4⁵

∴ a = 4

Condition: t₅ = (t₃)² → ar² = a²

∴ r² = a = 4

∴ r = 2

Numbers: 4/4, 4/2, 4, 8, 16 = 1, 2, 4, 8, 16

∴ The five numbers are 1, 2, 4, 8, 16

Q9
Fifth term = x, eighth term = y, eleventh term = z. Verify y² = xz.
Solution

t₅ = ar⁴ = x,   t₈ = ar⁷ = y,   t₁₁ = ar¹⁰ = z

y² = (ar⁷)² = a²r¹⁴

xz = (ar⁴)(ar¹⁰) = a²r¹⁴

∴ y² = xz   ✓

∴ Verified: y² = xz

Q10
If p, q, r, s are in G.P., show that p+q, q+r, r+s are also in G.P.
Solution

Since p, q, r, s are in G.P. with ratio k:

q = pk,   r = pk²,   s = pk³

∴ p+q = p(1+k),   q+r = pk(1+k),   r+s = pk²(1+k)

(q+r)/(p+q) = pk(1+k)/p(1+k) = k

(r+s)/(q+r) = pk²(1+k)/pk(1+k) = k

∴ Both ratios = k (constant)

∴ p+q, q+r, r+s are in G.P.   ✓

Q11
Bacteria doubles every hour. Initially 50. How many at end of 5th hour?
Solution

G.P. with a = 50, r = 2

After n hours: tₙ₊₁ = 50·2ⁿ

After 5th hour: 50·2⁵ = 50·32

∴ 1600 bacteria at end of 5th hour

Q12
Ball dropped from 80 ft, rebounds (3/4) of height fallen. Height on 6th bounce? nth bounce?
Solution

1st bounce = 80 × 3/4 = 60 ft

G.P. with a = 60, r = 3/4

Height on nth bounce: tₙ = 60·(3/4)ⁿ⁻¹

6th bounce: t₆ = 60·(3/4)⁵ = 60·243/1024 = 14580/1024

∴ Height on 6th bounce = 14580/1024 ft  |  nth bounce = 60·(3/4)ⁿ⁻¹

Q13
Numbers 3, x and x+6 form a G.P. Find (i) x (ii) 20th term (iii) nth term.
Solution

For G.P.: x² = 3(x+6)

∴ x² − 3x − 18 = 0

∴ (x−6)(x+3) = 0

∴ x = 6   or   x = −3

Taking x = 6: G.P. is 3, 6, 12 with r = 2

t₂₀ = 3·2¹⁹

∴ x = 6,   20th term = 3·2¹⁹,   tₙ = 3·2ⁿ⁻¹

Q14
Mosquitoes grow at 10% per year, initially 200. How many after (i) 3 years (ii) 10 years (iii) n years?
Solution

G.P. with a = 200, r = 1.1

After n years: 200·(1.1)ⁿ

∴ (i) 200·(1.1)³   (ii) 200·(1.1)¹⁰   (iii) 200·(1.1)ⁿ

Q15
Numbers x−6, 2x and x² are in G.P. Find (i) x (ii) 1st term (iii) nth term.
Solution

(2x)² = (x−6)(x²)

∴ 4x² = x²(x−6)

∴ 4 = x−6   (dividing by x², x≠0)

∴ x = 10

G.P.: 4, 20, 100   (r = 5)

∴ x = 10,   First term = 4,   tₙ = 4·5ⁿ⁻¹

Exercise 2.2 — Sum of G.P. (Sₙ)
Q1
For the following G.P.s find Sₙ:   i) 3, 6, 12, 24, …   ii) p, q, q²/p, …   iii) 0.7, 0.07, 0.007, …   iv) √5, −5, 5√5, −25, …
Solution   [Sₙ = a(rⁿ−1)/(r−1)]
i) a = 3, r = 2

Sₙ = 3(2ⁿ−1)/(2−1)

∴ Sₙ = 3(2ⁿ − 1)

ii) a = p, r = q/p

Sₙ = p·[(q/p)ⁿ − 1]/[(q/p) − 1]

= p·[qⁿ/pⁿ − 1]/[(q−p)/p]

∴ Sₙ = p(qⁿ − pⁿ)/[pⁿ⁻¹(q − p)]

iii) a = 0.7, r = 0.1

Sₙ = 0.7(1−0.1ⁿ)/(1−0.1) = 0.7(1−0.1ⁿ)/0.9

∴ Sₙ = (7/9)[1 − (0.1)ⁿ]

iv) a = √5, r = −5/√5 = −√5

Sₙ = √5·[(−√5)ⁿ − 1]/(−√5 − 1)

∴ Sₙ = √5·[(−√5)ⁿ − 1]/(−√5 − 1)

Q2
i) a = 2, r = −2/3, find S₆   ii) S₅ = 1023, r = 4, find a
Solution
i) a = 2, r = −2/3

S₆ = 2·[1−(−2/3)⁶]/[1−(−2/3)]

(−2/3)⁶ = 64/729

= 2·(1 − 64/729)/(5/3)

= 2·(665/729)·(3/5)

∴ S₆ = 266/243

ii) S₅ = 1023, r = 4, find a

Sₙ = a(rⁿ−1)/(r−1)

∴ 1023 = a(4⁵−1)/(4−1) = a·1023/3

∴ a = 1023·3/1023

∴ a = 3

Q3
i) a = 2, r = 3, Sₙ = 242, find n   ii) Sum of first 3 terms = 125, next 3 = 27, find r
Solution
i) a = 2, r = 3, Sₙ = 242

Sₙ = 2(3ⁿ−1)/(3−1) = 3ⁿ − 1 = 242

∴ 3ⁿ = 243 = 3⁵

∴ n = 5

ii) S₃ = 125, S₆ − S₃ = 27

S₆ − S₃ = S₃·r³

∴ 27 = 125·r³

∴ r³ = 27/125 = (3/5)³

∴ r = 3/5

Q4
i) t₃ = 20, t₆ = 160, find S₇   ii) t₄ = 16, t₉ = 512, find S₁₀
Solution
i) t₃ = 20, t₆ = 160

t₆/t₃ = r³ = 160/20 = 8

∴ r = 2

t₃ = ar² = 20 → a·4 = 20 → a = 5

S₇ = 5·(2⁷−1)/(2−1) = 5·127

∴ S₇ = 635

ii) t₄ = 16, t₉ = 512

t₉/t₄ = r⁵ = 512/16 = 32 = 2⁵

∴ r = 2

t₄ = ar³ = 16 → a·8 = 16 → a = 2

S₁₀ = 2·(2¹⁰−1)/(2−1) = 2·1023

∴ S₁₀ = 2046

Q5
Find sum to n terms: i) 3+33+333+…   ii) 8+88+888+…
Solution
i) 3+33+333+…

Sₙ = 3(1+11+111+…) = (3/9)(9+99+999+…)

= (1/3)[(10−1)+(100−1)+(1000−1)+…]

= (1/3)[10(10ⁿ−1)/9 − n]

∴ Sₙ = (1/27)[10(10ⁿ−1) − 9n]

ii) 8+88+888+…

= (8/9)(9+99+999+…) = (8/9)[(10−1)+(100−1)+…]

∴ Sₙ = (8/81)[10(10ⁿ−1) − 9n]

Q6
Find sum to n terms: i) 0.4+0.44+0.444+…   ii) 0.7+0.77+0.777+…
Solution
i) 0.4+0.44+0.444+…

= 4(0.1+0.11+0.111+…) = (4/9)(0.9+0.99+0.999+…)

= (4/9)[n − (1/9)(1−(0.1)ⁿ)]

∴ Sₙ = (4/9)[n − (1/9)(1−(0.1)ⁿ)]

ii) 0.7+0.77+0.777+…

∴ Sₙ = (7/9)[n − (1/9)(1−(0.1)ⁿ)]

Q7
Find sum to n terms: i) 0.5, 0.05, 0.005, …   ii) 0.2, 0.02, 0.002, …
Solution   [GP with r = 0.1]
i) a = 0.5, r = 0.1

Sₙ = 0.5·(1−0.1ⁿ)/(1−0.1) = 0.5(1−0.1ⁿ)/0.9

∴ Sₙ = (5/9)[1 − (0.1)ⁿ]

ii) a = 0.2, r = 0.1

∴ Sₙ = (2/9)[1 − (0.1)ⁿ]

Q8
If Sₙ = 2(3ⁿ−1), find nth term, show sequence is G.P.
Solution

tₙ = Sₙ − Sₙ₋₁ = 2(3ⁿ−1) − 2(3ⁿ⁻¹−1)

= 2·3ⁿ − 2·3ⁿ⁻¹

= 2·3ⁿ⁻¹(3−1)

= 4·3ⁿ⁻¹

tₙ₊₁/tₙ = 4·3ⁿ/4·3ⁿ⁻¹ = 3 = constant ∀ n ∈ ℕ

∴ tₙ = 4·3ⁿ⁻¹, the sequence is a G.P. with r = 3 ✓

Exercise 2.3 — Infinite G.P. (S∞)
Q1
Does S∞ exist? If yes, find it.
i) 1/2, 1/4, 1/8, …   ii) 2, 4/3, 8/9, …   iii) −3, 1, −1/3, 1/9, …   iv) 1/5, −2/5, 4/5, …   v) 9, 8.1, 7.29, …
Solution   [S∞ = a/(1−r) when |r| < 1]
i) a = 1/2, r = 1/2, |r| = 1/2 < 1 ✓

S∞ = (1/2)/(1−1/2) = (1/2)/(1/2)

∴ S∞ = 1

ii) a = 2, r = 2/3, |r| < 1 ✓

S∞ = 2/(1−2/3) = 2/(1/3)

∴ S∞ = 6

iii) a = −3, r = −1/3, |r| = 1/3 < 1 ✓

S∞ = −3/(1−(−1/3)) = −3/(4/3)

∴ S∞ = −9/4

iv) a = 1/5, r = −2, |r| = 2 > 1

∴ S∞ does not exist

v) a = 9, r = 0.9, |r| < 1 ✓

S∞ = 9/(1−0.9) = 9/0.1

∴ S∞ = 90

Q2
Express as rational numbers: i) 0.7̄   ii) 2.4̄   iii) 2.35̄   iv) 51.0̄2̄
Solution
i) 0.777… = 0.7 + 0.07 + 0.007 + … (a = 0.7, r = 0.1)

S = 0.7/(1−0.1) = 0.7/0.9

∴ 0.7̄ = 7/9

ii) 2.444… = 2 + 0.4/(1−0.1)

= 2 + 0.4/0.9 = 2 + 4/9

∴ 2.4̄ = 22/9

iii) 2.3555… = 2.3 + 0.05/(1−0.1)

= 2.3 + 0.05/0.9 = 23/10 + 1/18 = (207+5)/90

∴ 2.35̄ = 212/90 = 106/45

iv) 51.020202… = 51 + 0.02/(1−0.01)

= 51 + 0.02/0.99 = 51 + 2/99

∴ 51.0̄2̄ = 5051/99

Q3
r = 2/3, S∞ = 12. Find first term.
Solution

S∞ = a/(1−r) = a/(1−2/3) = a/(1/3) = 3a = 12

∴ a = 4

Q4
First term = 16, S∞ = 96. Find common ratio.
Solution

S∞ = a/(1−r) → 96 = 16/(1−r)

∴ 1−r = 16/96 = 1/6

∴ r = 1 − 1/6

∴ r = 5/6

Q5
Sum of infinite G.P. = 5, sum of squares of terms = 15. Find the G.P.
Solution

a/(1−r) = 5 → a = 5(1−r)   ...(1)

a²/(1−r²) = 15   ...(2)

From (1) and (2): [5(1−r)]²/[(1−r)(1+r)] = 15

∴ 25(1−r)/(1+r) = 15

∴ 5(1−r) = 3(1+r)

∴ 5 − 5r = 3 + 3r

∴ 8r = 2

∴ r = 1/4

a = 5(1−1/4) = 5 × 3/4 = 15/4

∴ G.P. is 15/4, 15/16, 15/64, … (a = 15/4, r = 1/4)

Q7
Midpoints of sides of square of side 1 joined repeatedly. Find sum of (i) all areas (ii) all perimeters.
Solution

(i) Areas: 1, 1/2, 1/4, …   G.P. with a=1, r=1/2

S∞ = 1/(1−1/2) = 2

∴ Sum of all areas = 2 sq units

(ii) Perimeters: 4, 4/√2, 4/2, …   G.P. with a=4, r=1/√2

S∞ = 4/(1−1/√2) = 4√2/(√2−1) = 4√2(√2+1)

∴ Sum of perimeters = (8+4√2) units

Q8
Ball dropped from 10 m, bounces to 6 m, 3.6 m, … Find total distance.
Solution

r = 6/10 = 0.6

Total = 10 + 2(6 + 3.6 + 2.16 + …)

S∞ of bounces = 6/(1−0.6) = 6/0.4 = 15

Total = 10 + 2×15 = 10 + 30

∴ Total distance = 40 m

Exercise 2.4 — H.P. and Means (A.M., G.M., H.M.)
Q1
Verify whether the following are H.P.: i) 1/3, 1/5, 1/7, 1/9, …   ii) 1/3, 1/6, 1/12, 1/24, …   iii) 5, 10/17, 10/32, 10/47, …
Solution   [HP if reciprocals are in AP]
i) Reciprocals: 3, 5, 7, 9, … → d = 2 (constant AP)

∴ YES, it is H.P.

ii) Reciprocals: 3, 6, 12, 24, … → ratio = 2 (GP, not AP)

∴ NOT H.P.

iii) Reciprocals: 1/5, 17/10, 32/10, 47/10, … → d = 3/2 (AP)

∴ YES, it is H.P.

Q2
Find nth term and 8th term: i) 1/2, 1/5, 1/8, 1/11, …   ii) 1/4, 1/6, 1/8, 1/10, …   iii) 1/5, 1/10, 1/15, 1/20, …
Solution
i) Reciprocals AP: 2, 5, 8, 11, … a=2, d=3

tₙ (AP) = 2 + (n−1)·3 = 3n−1

∴ tₙ (HP) = 1/(3n−1),   t₈ = 1/23

ii) Reciprocals AP: 4, 6, 8, 10, … a=4, d=2

tₙ (AP) = 4+(n−1)·2 = 2n+2 = 2(n+1)

∴ tₙ (HP) = 1/[2(n+1)],   t₈ = 1/18

iii) Reciprocals AP: 5, 10, 15, 20, … a=5, d=5

tₙ (AP) = 5n

∴ tₙ (HP) = 1/(5n),   t₈ = 1/40

Q3
Find A.M. of two positive numbers whose G.M. = 4 and H.M. = 16/5.
Solution   [G² = AH]

G² = AH → 16 = A × 16/5

∴ A = 16 × 5/16

∴ A.M. = 5

Q4
Find H.M. of two positive numbers whose A.M. = 15/2 and G.M. = 6.
Solution

G² = AH → 36 = (15/2)·H

∴ H = 36 × 2/15 = 72/15

∴ H.M. = 24/5

Q5
Find G.M. of two positive numbers whose A.M. = 75 and H.M. = 48.
Solution

G² = AH = 75 × 48 = 3600

∴ G = √3600

∴ G.M. = 60

Q6
Insert two numbers between 1/4 and 1/3 so the sequence is H.P.
Solution

Reciprocals: 4 and 3 must be in AP with 4 terms

a = 4, t₄ = 3 → 4 + 3d = 3

∴ d = −1/3

H₁ (AP) = 4 + (−1/3) = 11/3

H₂ (AP) = 4 + 2(−1/3) = 10/3

Numbers in HP = reciprocals: 3/11 and 3/10

∴ Insert 3/11 and 3/10 between 1/4 and 1/3

Q8
A.M. exceeds G.M. by 2 and H.M. by 18/5. Find the numbers.
Solution

A = G + 2 → G = A − 2   ...(1)

A = H + 18/5 → H = A − 18/5   ...(2)

G² = AH → (A−2)² = A(A−18/5)

∴ A² − 4A + 4 = A² − 18A/5

∴ −4A + 4 = −18A/5

∴ −20A + 20 = −18A

∴ −2A = −20

∴ A = 10

G = 10 − 2 = 8  |  x + y = 2A = 20  |  xy = G² = 64

t² − 20t + 64 = 0 → (t−16)(t−4) = 0

∴ The two numbers are 4 and 16

Q9
Find two numbers whose A.M. exceeds G.M. by 1/2 and H.M. by 25/26.
Solution

A = G + 1/2   ...(1)    H = A − 25/26   ...(2)

G² = AH → (A−1/2)² = A(A−25/26)

∴ A² − A + 1/4 = A² − 25A/26

∴ −A + 1/4 = −25A/26

∴ −26A + 6.5 = −25A

∴ A = 13/2

G = 13/2 − 1/2 = 6  |  x+y = 13  |  xy = 36

t² − 13t + 36 = 0 → (t−9)(t−4) = 0

∴ The two numbers are 4 and 9

Exercise 2.5 — A.G.P.
Q2
Find S∞ of AGP: i) 1, 2/4, 3/16, 4/64, …   ii) 3, 6/5, 9/25, 12/125, …   iii) 1, −4/3, 7/9, −10/27, …
Solution   [S∞ = a/(1−r) + dr/(1−r)²]
i) AP: 1,2,3,… (d=1); GP: 1,1/4,1/16,… (r=1/4)

S∞ = 1/(1−1/4) + 1·(1/4)/(1−1/4)²

= 1/(3/4) + (1/4)/(9/16)

= 4/3 + 4/9

∴ S∞ = 16/9

ii) AP: 3,6,9,… (d=3); GP: 1,1/5,1/25,… (r=1/5)

S∞ = 3/(1−1/5) + 3·(1/5)/(1−1/5)²

= 3/(4/5) + (3/5)/(16/25)

= 15/4 + 15/16

∴ S∞ = 75/16

iii) AP: 1,4,7,… (d=3); GP: 1,−1/3,1/9,… (r=−1/3)

S∞ = 1/(1+1/3) + 3·(−1/3)/(1+1/3)²

= 3/4 + (−1)/(16/9)

Exercise 2.6 — Special Series (Σr, Σr², Σr³)
Q1
Find Σ(r=1 to n) (r+1)(2r−1)
Solution

Expand: (r+1)(2r−1) = 2r² + r − 1

Σ(2r²+r−1) = 2Σr² + Σr − Σ1

= 2·n(n+1)(2n+1)/6 + n(n+1)/2 − n

= n(n+1)(2n+1)/3 + n(n+1)/2 − n

= n/6[2(n+1)(2n+1) + 3(n+1) − 6]

= n/6[4n²+6n+2+3n+3−6]

∴ = n(4n²+9n−1)/6

Q2
Find Σ(r=1 to n) (3r²−2r+1)
Solution

= 3Σr² − 2Σr + Σ1

= 3·n(n+1)(2n+1)/6 − 2·n(n+1)/2 + n

= n(n+1)(2n+1)/2 − n(n+1) + n

= n/2[(n+1)(2n+1) − 2(n+1) + 2]

= n/2[2n²+3n+1 − 2n − 2 + 2]

∴ = n(2n²+n+1)/2

Q3
Find Σ(r=1 to n) (1+2+3+…+r)/r
Solution

(1+2+…+r)/r = r(r+1)/(2r) = (r+1)/2

Σ(r+1)/2 = (1/2)[Σr + Σ1] = (1/2)[n(n+1)/2 + n]

= (1/2)·n(n+3)/2

∴ = n(n+3)/4

Q5
Find 5×7 + 9×11 + 13×15 + … upto n terms.
Solution

First factors: 5, 9, 13, … → rth = 4r+1

Second factors: 7, 11, 15, … → rth = 4r+3

Σ(4r+1)(4r+3) = Σ(16r²+16r+3)

= 16Σr² + 16Σr + 3n

= 16·n(n+1)(2n+1)/6 + 16·n(n+1)/2 + 3n

= n/3[8(n+1)(2n+1) + 24(n+1) + 9]

= n/3[16n²+24n+8+24n+24+9]

∴ Sₙ = n(16n²+48n+41)/3

Q6
Find 2²+4²+6²+8²+… upto n terms.
Solution

= Σ(2r)² = 4Σr² = 4·n(n+1)(2n+1)/6

∴ = 2n(n+1)(2n+1)/3

Q9
If [1×2+2×3+… upto n]/[1+2+3+… upto n] = 100/3, find n.
Solution

Numerator: Σr(r+1) = n(n+1)(n+2)/3

Denominator: Σr = n(n+1)/2

Ratio = [n(n+1)(n+2)/3] / [n(n+1)/2] = 2(n+2)/3 = 100/3

∴ 2(n+2) = 100

∴ n+2 = 50

∴ n = 48

M5
Find three numbers in G.P. with sum = 35 and product = 1000.
Solution

Let numbers be a/r, a, ar

Product = a³ = 1000

∴ a = 10

Sum: 10/r + 10 + 10r = 35 → 10/r + 10r = 25

∴ 10r² − 25r + 10 = 0

∴ 2r² − 5r + 2 = 0

∴ (2r−1)(r−2) = 0

∴ r = 1/2   or   r = 2

If r = 2: numbers = 5, 10, 20

∴ The three numbers are 5, 10, 20
