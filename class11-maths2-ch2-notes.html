Key Formulas & Theory

Arithmetic Progression (AP)

tₙ = a + (n−1)d  |  Sₙ = n/2 × [2a + (n−1)d]

Geometric Progression (GP)

tₙ = arⁿ⁻¹  |  Sₙ = a(rⁿ−1)/(r−1), r≠1  |  S∞ = a/(1−r), |r|<1

Harmonic Progression (HP)

tₙ of HP = 1/(tₙ of AP)

Means

A = (x+y)/2  |  G = √(xy)  |  H = 2xy/(x+y)  |  G² = AH  |  A ≥ G ≥ H

AGP Sum

S∞ = a/(1−r) + dr/(1−r)²

Summation Results

Σr = n(n+1)/2  |  Σr² = n(n+1)(2n+1)/6  |  Σr³ = [n(n+1)/2]²

Exercise 2.1 — GP: nth Term
Q1
Check whether the following sequences are G.P. If so, write tₙ.
i) 2, 6, 18, 54, …   ii) 1, −5, 25, −125, …   iii) √5, 1/√5, 1/5√5, 1/25√5, …   iv) 3, 4, 5, 6, …   v) 7, 14, 21, 28, …
Solution
i) 2, 6, 18, 54, …
1
Check ratio: t₂/t₁ = 6/2 = 3, t₃/t₂ = 18/6 = 3, t₄/t₃ = 54/18 = 3
2
Ratio is constant = 3, so it IS a GP with a = 2, r = 3
tₙ = arⁿ⁻¹ = 2·(3)ⁿ⁻¹
ii) 1, −5, 25, −125, …
1
t₂/t₁ = −5/1 = −5, t₃/t₂ = 25/(−5) = −5, t₄/t₃ = −125/25 = −5
2
Ratio is constant = −5, so it IS a GP with a = 1, r = −5
tₙ = 1·(−5)ⁿ⁻¹ = (−5)ⁿ⁻¹
iii) √5, 1/√5, 1/5√5, 1/25√5, …
1
t₂/t₁ = (1/√5)/√5 = 1/5, t₃/t₂ = (1/5√5)/(1/√5) = 1/5
2
Ratio = 1/5 (constant) → IS a GP with a = √5, r = 1/5
tₙ = √5·(1/5)ⁿ⁻¹ = 5^(1/2)·5^(-(n-1)) = 5^(1/2 - n + 1) = 5^(3/2 - n)
iv) 3, 4, 5, 6, …
1
t₂/t₁ = 4/3, t₃/t₂ = 5/4 — ratios are NOT equal
NOT a GP (difference between terms is constant = 1, so it is an AP)
v) 7, 14, 21, 28, …
1
t₂/t₁ = 14/7 = 2, t₃/t₂ = 21/14 = 3/2 — ratios are NOT equal
NOT a GP (this is an AP with common difference 7)
Q2
For the G.P.:
i) r = 1/3, a = 9, find t₇   ii) a = 7/243, r = 3, find t₆   iii) r = −3, t₆ = 1701, find a   iv) a = 2/3, t₆ = 162, find r

i) r = 1/3, a = 9, find t₇
1
t₇ = a·r⁶ = 9·(1/3)⁶ = 9·(1/729) = 9/729
t₇ = 1/81
ii) a = 7/243, r = 3, find t₆
1
t₆ = a·r⁵ = (7/243)·(3)⁵ = (7/243)·243
t₆ = 7
iii) r = −3, t₆ = 1701, find a
1
t₆ = a·r⁵ → 1701 = a·(−3)⁵ = a·(−243)
2
a = 1701/(−243) = −7
a = −7
iv) a = 2/3, t₆ = 162, find r
1
t₆ = a·r⁵ → 162 = (2/3)·r⁵
2
r⁵ = 162 × 3/2 = 243 = 3⁵
r = 3

Q5
If for a sequence {tₙ}, tₙ = 5ⁿ⁻³/2ⁿ⁻³, show the sequence is a G.P. Find first term and common ratio.
Solution
1
tₙ = 5ⁿ⁻³/2ⁿ⁻³ = (5/2)ⁿ⁻³
2
tₙ₊₁ = (5/2)ⁿ⁻²
3
tₙ₊₁/tₙ = (5/2)ⁿ⁻²/(5/2)ⁿ⁻³ = (5/2)¹ = 5/2 = constant for all n ∈ ℕ
4
t₁ = (5/2)¹⁻³ = (5/2)⁻² = (2/5)² = 4/25
The sequence is a GP with first term a = 4/25 and common ratio r = 5/2
Q6
Find three numbers in G.P. such that their sum is 21 and sum of their squares is 189.
Solution — Assume three numbers as a/r, a, ar
1
Product: (a/r)·a·ar = a³ (this doesn't directly help here)
2
Sum: a/r + a + ar = 21 → a(1/r + 1 + r) = 21 ...(1)
3
Sum of squares: a²/r² + a² + a²r² = 189 → a²(1/r² + 1 + r²) = 189 ...(2)
4
Dividing (2) by (1): a·(1/r² + 1 + r²)/(1/r + 1 + r) = 9
5
Note: (1/r² + 1 + r²) = (1/r + 1 + r)² − 2(1/r + 1 + r) + 2... Let S = 1/r + 1 + r
6
From (1): aS = 21. From (2): a(S² − 2) = 189. So a(S² − 2) = 189 and aS = 21 → S = 21/a
7
a(S² − 2) = 189 → a·S² − 2a = 189 → S·(aS) − 2a = 189 → 21S − 2a = 189
8
Also aS = 21 → a = 21/S. Substitute: 21S − 42/S = 189 → 21S² − 189S − 42 = 0 → S² − 9S − 2 = 0... Let's try a = 3:
9
Try a = 3: 3(1/r + 1 + r) = 21 → 1/r + 1 + r = 7 → 1/r + r = 6 → r² − 6r + 1 = 0... not clean. Try a = 7:
10
Try a = 7: 7(1/r + 1 + r) = 21 → 1/r + 1 + r = 3 → 1/r + r = 2 → r² − 2r + 1 = 0 → (r−1)² = 0 → r = 1 (all terms equal = 7). Check: 7+7+7=21✓, 49+49+49=147≠189. So a≠7.
11
Let's redo: Let three numbers be a/r, a, ar. Sum = 21, sum of squares = 189. Divide: (sum of sq)/(sum)² = 189/441 = 3/7. This means (a²/r² + a² + a²r²)/(a/r + a + ar)² = 3/7. With a = 3, 1/r + r = 4 → r² − 4r + 1 = 0 → r = (4±√12)/2 = 2±√3.
12
With a = 3, r = 2+√3: numbers are 3/(2+√3), 3, 3(2+√3) = 3(2−√3), 3, 3(2+√3)... but textbook gives a cleaner answer. From sum=21: if the three numbers are 3, 6, 12 → sum=21✓, squares: 9+36+144=189✓
13
Check GP: 6/3 = 2, 12/6 = 2 ✓ r = 2, a = 3
The three numbers are 3, 6, 12 (with a = 3, r = 2) OR 12, 6, 3 (with r = 1/2)
Q7
Find four numbers in G.P. such that sum of middle two is 10/3 and their product is 1.
Solution — Assume four numbers as a/r³, a/r, ar, ar³ (common ratio = r²)
1
Product: (a/r³)·(a/r)·(ar)·(ar³) = a⁴ = 1 → a = 1
2
Sum of middle two: a/r + ar = 10/3 → 1/r + r = 10/3
3
Multiply by r: 1 + r² = 10r/3 → 3r² − 10r + 3 = 0
4
(3r − 1)(r − 3) = 0 → r = 1/3 or r = 3
5
If r = 3, a = 1: numbers are 1/27, 1/3, 3, 27. If r = 1/3: 27, 3, 1/3, 1/27
Four numbers: 1/27, 1/3, 3, 27
Q8
Find five numbers in G.P. such that their product is 1024 and fifth term is square of the third term.
Solution — Assume five numbers as a/r², a/r, a, ar, ar²
1
Product: (a/r²)·(a/r)·a·(ar)·(ar²) = a⁵ = 1024 = 4⁵ → a = 4
2
5th term = (ar²), 3rd term = a. Condition: ar² = a² → r² = a = 4 → r = 2
3
Numbers: 4/4, 4/2, 4, 4×2, 4×4 = 1, 2, 4, 8, 16
Five numbers: 1, 2, 4, 8, 16
Q9
Fifth term of G.P. is x, eighth term is y, eleventh term is z. Verify y² = xz.
Solution
1
t₅ = ar⁴ = x, t₈ = ar⁷ = y, t₁₁ = ar¹⁰ = z
2
y² = (ar⁷)² = a²r¹⁴
3
xz = (ar⁴)(ar¹⁰) = a²r¹⁴
4
∴ y² = xz ✓
Verified: y² = xz (The 5th, 8th, 11th terms are equally spaced in GP, so middle term squared = product of outer terms)
Q10
If p, q, r, s are in G.P., show that p+q, q+r, r+s are also in G.P.
Solution
1
Since p, q, r, s are in GP with ratio k: q = pk, r = pk², s = pk³
2
p+q = p+pk = p(1+k), q+r = pk+pk² = pk(1+k), r+s = pk²+pk³ = pk²(1+k)
3
Ratio of (q+r)/(p+q) = pk(1+k)/p(1+k) = k
4
Ratio of (r+s)/(q+r) = pk²(1+k)/pk(1+k) = k
Both ratios = k (constant) ∴ p+q, q+r, r+s are in GP ✓

Exercise 2.2 — Sum of G.P. (Sₙ)
Q1
For the following G.P.s, find Sₙ:
i) 3, 6, 12, 24, …   ii) p, q, q²/p, q³/p², …   iii) 0.7, 0.07, 0.007, …   iv) √5, −5, 5√5, −25, …
Solution — Formula: Sₙ = a(rⁿ−1)/(r−1) for r > 1
i) 3, 6, 12, 24, … → a = 3, r = 2
1
Sₙ = 3·(2ⁿ−1)/(2−1) = 3(2ⁿ−1)
Sₙ = 3(2ⁿ − 1)
ii) p, q, q²/p, … → a = p, r = q/p
1
r = q/p. Sₙ = p·[(q/p)ⁿ − 1]/[(q/p) − 1] = p·[qⁿ/pⁿ − 1]/[(q−p)/p]
2
= p²·[qⁿ − pⁿ] / [pⁿ(q−p)] = p[qⁿ − pⁿ] / [pⁿ⁻¹(q−p)]
Sₙ = p(qⁿ − pⁿ) / [pⁿ⁻¹(q − p)]
iii) 0.7, 0.07, 0.007, … → a = 0.7, r = 0.1
1
Since r < 1: Sₙ = a(1−rⁿ)/(1−r) = 0.7·(1−0.1ⁿ)/(1−0.1) = 0.7·(1−0.1ⁿ)/0.9
Sₙ = 7/9 · [1 − (0.1)ⁿ]
iv) √5, −5, 5√5, −25, … → a = √5, r = −5/√5 = −√5
1
Sₙ = √5·[(−√5)ⁿ − 1]/[(−√5) − 1] = √5·[(−√5)ⁿ − 1]/(−√5 − 1)
Sₙ = √5·[(−√5)ⁿ − 1] / (−√5 − 1)

Verified: (S/R)ⁿ = P²

Q1
Does sum to infinity exist? If yes, find it.
i) 1/2, 1/4, 1/8, …   ii) 2, 4/3, 8/9, …   iii) −3, 1, −1/3, 1/9, …   iv) 1/5, −2/5, 4/5, −8/5, …   v) 9, 8.1, 7.29, …
Solution — S∞ exists only if |r| < 1. S∞ = a/(1−r)
i) a = 1/2, r = 1/2, |r| = 1/2 < 1 ✓
S∞ = (1/2)/(1−1/2) = (1/2)/(1/2) = 1
ii) a = 2, r = (4/3)/2 = 2/3, |r| = 2/3 < 1 ✓
S∞ = 2/(1−2/3) = 2/(1/3) = 6
iii) a = −3, r = 1/(−3) = −1/3, |r| = 1/3 < 1 ✓
S∞ = −3/(1−(−1/3)) = −3/(4/3) = −9/4
iv) a = 1/5, r = (−2/5)/(1/5) = −2, |r| = 2 > 1
Sum to infinity does NOT exist (|r| = 2 > 1)
v) a = 9, r = 8.1/9 = 0.9, |r| = 0.9 < 1 ✓
S∞ = 9/(1−0.9) = 9/0.1 = 90

ii) Reciprocals: 3, 6, 12, 24, … → ratio = 2 (GP, NOT AP)

iii) Reciprocals: 1/5, 17/10, 32/10, 47/10, … → 0.2, 1.7, 3.2, 4.7, … → d = 1.5 (AP) ✓

Exercise 2.5 — Arithmetico-Geometric Progression (AGP)

AGP Formula

Sₙ = a/(1−r) + dr(1−rⁿ⁻¹)/(1−r)² − [a+(n−1)d]rⁿ/(1−r)
S∞ = a/(1−r) + dr/(1−r)²
Q1
Find Sₙ of the following AGP sequences:
i) 2, 4x, 6x², 8x³, 10x⁴, …   ii) 1, 4x, 7x², 10x³, 13x⁴, …   iii) 1, 2×3, 3×9, 4×27, 5×81, …   iv) 3, 12, 36, 96, 240, …
Solution — Identify AP and GP parts
i) 2, 4x, 6x², 8x³, … AP part: 2,4,6,8,… (a=2,d=2). GP part: 1,x,x²,… (r=x). tₙ = 2n·xⁿ⁻¹
1
Using AGP formula with a=2, d=2, r=x: Sₙ = 2/(1−x) + 2x(1−xⁿ⁻¹)/(1−x)² − 2n·xⁿ/(1−x)
Sₙ = 2/(1−x) + 2x(1−xⁿ⁻¹)/(1−x)² − 2n·xⁿ/(1−x)   (x ≠ 1)
ii) 1, 4x, 7x², 10x³, … AP: 1,4,7,10,… (a=1,d=3). GP: 1,x,x²,… (r=x). tₙ = (3n−2)xⁿ⁻¹
Sₙ = 1/(1−x) + 3x(1−xⁿ⁻¹)/(1−x)² − (3n−2)xⁿ/(1−x)
iii) 1, 2×3, 3×9, 4×27, 5×81, … AP: 1,2,3,4,5,… (a=1,d=1). GP: 1,3,9,27,… (r=3). tₙ = n·3ⁿ⁻¹
1
Sₙ = 1/(1−3) + 1×3(1−3ⁿ⁻¹)/(1−3)² − n·3ⁿ/(1−3)
2
= −1/2 + 3(1−3ⁿ⁻¹)/4 − n·3ⁿ/(−2)
3
= −1/2 + 3/4 − 3ⁿ/4 + n·3ⁿ/2 = 1/4 + 3ⁿ(n/2 − 1/4) = 1/4 + 3ⁿ(2n−1)/4
Sₙ = [1 + 3ⁿ(2n−1)] / 4
iv) 3, 12, 36, 96, 240, … = 3×1, 3×4, 3×12, 3×32, 3×80 ... Write as: 1×3, 2×6, 3×12, 4×24, 5×48. AP:1,2,3,4,5 GP:3,6,12,24 (r=2). tₙ = n·3·2ⁿ⁻¹
Sₙ = 3[1 + (n−1)·2ⁿ] (using AGP formula with a=1, d=1, r=2 then ×3)
Q2
Find sum to infinity of AGP:
i) 1, 2/4, 3/16, 4/64, …   ii) 3, 6/5, 9/25, 12/125, …   iii) 1, −4/3, 7/9, −10/27, …
Solution — S∞ = a/(1−r) + dr/(1−r)²
i) AP: 1,2,3,4,… (a=1,d=1). GP: 1,1/4,1/16,… (r=1/4). tₙ = n·(1/4)ⁿ⁻¹
1
S∞ = 1/(1−1/4) + 1×(1/4)/(1−1/4)² = 1/(3/4) + (1/4)/(9/16)
2
= 4/3 + (1/4)×(16/9) = 4/3 + 4/9 = 12/9 + 4/9
i) S∞ = 16/9
ii) AP: 3,6,9,12,… (a=3,d=3). GP: 1,1/5,1/25,… (r=1/5). tₙ = 3n·(1/5)ⁿ⁻¹
1
S∞ = 3/(1−1/5) + 3·(1/5)/(1−1/5)² = 3/(4/5) + (3/5)/(16/25)
2
= 15/4 + (3/5)×(25/16) = 15/4 + 15/16 = 60/16 + 15/16
ii) S∞ = 75/16
iii) AP: 1,4,7,10,… d=3. GP: 1,−1/3,1/9,… r=−1/3. tₙ = (3n−2)·(−1/3)ⁿ⁻¹
1

= 3/4 − 9/16 = 12/16 − 9/16
iii) S∞ = 3/16

Key Results

Σr = n(n+1)/2  |  Σr² = n(n+1)(2n+1)/6  |  Σr³ = [n(n+1)/2]²
