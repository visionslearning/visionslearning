⭐ Key Points at a Glance

  • Sequence: Numbers arranged in a definite order. General form: t₁, t₂, t₃, ..., tₙ
  • A.P.: tₙ₊₁ − tₙ = d (constant). nth term: tₙ = a + (n−1)d. Sum: Sₙ = n/2[2a + (n−1)d]
  • G.P.: tₙ₊₁/tₙ = r (constant). nth term: tₙ = arⁿ⁻¹. Sum: Sₙ = a(rⁿ−1)/(r−1)
  • Sum of infinite G.P.: S∞ = a/(1−r), only when |r| < 1
  • H.P.: Reciprocals of terms are in A.P. nth term of H.P. = 1/(nth term of corresponding A.P.)
  • A.M. = (x+y)/2, G.M. = √(xy), H.M. = 2xy/(x+y)
  • Relation: G² = AH and A ≥ G ≥ H (for positive numbers)
  • A.G.P.: Each term = product of corresponding A.P. and G.P. terms. tₙ = [a+(n−1)d]rⁿ⁻¹
  • Sum of natural numbers: Σr = n(n+1)/2
  • Sum of squares: Σr² = n(n+1)(2n+1)/6
  • Sum of cubes: Σr³ = [n(n+1)/2]²
1

Sequences — Definitions

Sequence: A set of numbers arranged in a definite order. Written as t₁, t₂, t₃, ..., tₙ where t₁ = first term, tₙ = nth term.
  • Finite sequence: Contains finite number of terms. Written as {t₁, t₂, ..., tₙ}
  • Infinite sequence: Never ends. Written as {t₁, t₂, t₃, ...} or {tₙ} n ≥ 1
  • Progression: A sequence that follows a specific pattern
2

Arithmetic Progression (A.P.)

A.P.: A sequence where the difference between any term and its preceding term (tₙ₊₁ − tₙ) is constant. This constant is the common difference d.
nth Termtₙ = a + (n−1)d where a = first term, d = common difference
Sum of n termsSₙ = n/2 × [2a + (n−1)d]  OR  Sₙ = n/2 × (first term + last term)

Properties of A.P.: If t₁, t₂, ..., tₙ are in A.P. then:

  • t₁±k, t₂±k, ..., tₙ±k are also in A.P.
  • kt₁, kt₂, ..., ktₙ are also in A.P. (k ≠ 0)

Examples of A.P.: 2,5,8,11,14 (d=3); 4,10,16,22 (d=6); −3,2,7,12 (d=5)

NOT A.P.: 4,16,64,256 (ratio constant, not difference) — this is G.P.

3

Geometric Progression (G.P.)

G.P.: A sequence where the ratio tₙ₊₁/tₙ = r is constant for all n. This constant r is called the common ratio.
nth Termtₙ = arⁿ⁻¹ where a = first term, r = common ratio
Sum of n terms (r ≠ 1)Sₙ = a(rⁿ−1)/(r−1) [use when r > 1]  OR  Sₙ = a(1−rⁿ)/(1−r) [use when r < 1]
Sum when r = 1Sₙ = a × n (G.P. becomes a, a, a, ... n times)
Sum of Infinite G.P. (|r| < 1)S∞ = a/(1−r)  |  If |r| ≥ 1, sum to infinity does NOT exist

Properties of G.P.:

  • 1/t₁, 1/t₂, ..., 1/tₙ are also in G.P.
  • kt₁, kt₂, ..., ktₙ are also in G.P. (k ≠ 0)
  • t₁ⁿ, t₂ⁿ, t₃ⁿ, ... are also in G.P.

Convenient assumptions:

Terms neededAssume asCommon ratio
3 terms in G.P.a/r, a, arr
4 terms in G.P.a/r³, a/r, ar, ar³r²
5 terms in G.P.a/r², a/r, a, ar, ar²r

Expressing recurring decimals as rational numbers:

0.6̄ = 0.6+0.06+0.006+... → a=0.6, r=0.1 → S∞ = 0.6/(1−0.1) = 0.6/0.9 = 2/3
4

Harmonic Progression (H.P.)

H.P.: A sequence t₁, t₂, t₃, ..., tₙ (tₙ ≠ 0) is H.P. if 1/t₁, 1/t₂, 1/t₃, ..., 1/tₙ are in A.P.

To find nth term of H.P.:

  • Write the reciprocals → they form an A.P. with first term a and common difference d
  • Find tₙ of that A.P. = a + (n−1)d
  • nth term of H.P. = 1/[a + (n−1)d]

Example: 1/2, 2/5, 1/3, 2/7 → reciprocals: 2, 5/2, 3, 7/2 → A.P. with a=2, d=1/2 → tₙ of A.P. = 2+(n−1)(1/2) = (n+3)/2 → tₙ of H.P. = 2/(n+3)

5

Arithmetic Mean, Geometric Mean, Harmonic Mean

MeanFormula (2 numbers x and y)Formula (n numbers)
A.M. (A)A = (x+y)/2A = (x₁+x₂+...+xₙ)/n
G.M. (G)G = √(xy)G = (x₁·x₂·...·xₙ)^(1/n)
H.M. (H)H = 2xy/(x+y)H = n ÷ (1/x₁+1/x₂+...+1/xₙ)
Key TheoremG² = AH    and    A ≥ G ≥ H (for positive numbers x, y)
If x = y then A = G = H

Example: x=4, y=16 → A=(4+16)/2=10, G=√(4×16)=√64=8, H=2×4×16/(4+16)=128/20=32/5
Verify: G²=64 = A×H = 10×32/5 = 64 ✓ and 10 ≥ 8 ≥ 6.4 ✓

6

Arithmetico-Geometric Progression (A.G.P.)

A.G.P.: A sequence where each term is the product of corresponding terms of an A.P. and a G.P.

General form: a, (a+d)r, (a+2d)r², (a+3d)r³, ...

nth Term of A.G.P.tₙ = [a + (n−1)d] × rⁿ⁻¹
Sum of n terms (r ≠ 1)Sₙ = a/(1−r) + dr(1−rⁿ⁻¹)/(1−r)² − [a+(n−1)d]rⁿ/(1−r)
Sum to Infinity (|r| < 1)S∞ = a/(1−r) + dr/(1−r)²
7

Important Summation Results

Sum of first n natural numbersΣr = n(n+1)/2
Sum of squares of first n natural numbersΣr² = n(n+1)(2n+1)/6
Sum of cubes of first n natural numbersΣr³ = [n(n+1)/2]²

Properties of Summation:

  • Σ(k·tᵣ) = k·Σtᵣ (k = constant)
  • Σ(aᵣ + bᵣ) = Σaᵣ + Σbᵣ
  • Σ1 = n (sum of n ones)
  • Σk = kn (k = constant, summed n times)

🔁 Quick Revision — All Formulas

  • A.P. nth term: tₙ = a + (n−1)d | Sum: Sₙ = n/2[2a+(n−1)d]
  • G.P. nth term: tₙ = arⁿ⁻¹ | Sum: Sₙ = a(rⁿ−1)/(r−1) for r≠1
  • G.P. infinite sum: S∞ = a/(1−r) only if |r| < 1
  • 3 numbers in G.P.: take a/r, a, ar → product = a³
  • 4 numbers in G.P.: take a/r³, a/r, ar, ar³ → product = a⁴
  • H.P. nth term: take reciprocals → find A.P. nth term → take reciprocal back
  • A.M. = (x+y)/2 | G.M. = √(xy) | H.M. = 2xy/(x+y)
  • G² = AH | A ≥ G ≥ H for positive numbers
  • A.G.P. tₙ = [a+(n−1)d]rⁿ⁻¹ | S∞ = a/(1−r) + dr/(1−r)²
  • Σr = n(n+1)/2 | Σr² = n(n+1)(2n+1)/6 | Σr³ = [n(n+1)/2]²
  • Recurring decimal → G.P. with |r|<1 → use S∞ = a/(1−r)

Show ▾

i) 2, 6, 18, 54, ...r = 6/2 = 3; 18/6 = 3; 54/18 = 3 → r = 3 (constant) → YES, G.P.

ii) 1, −5, 25, −125, ...r = −5/1 = −5; 25/(−5) = −5 → r = −5 (constant) → YES, G.P.

iv) 3, 4, 5, 6, ...r = 4/3; 5/4 — these are NOT equal → NOT a G.P. (This is an A.P. with d=1)

Find Sₙ of: i) 2,4x,6x²,8x³,...   ii) 1,4x,7x²,10x³,...   iii) 1,2×3,3×9,4×27,...
Show ▾
i) 2,4x,6x²,8x³,... → A.P. part: 2,4,6,8 (a=2,d=2); G.P. part: 1,x,x²,x³ (r=x)tₙ = [2+(n−1)×2]×xⁿ⁻¹ = 2n×xⁿ⁻¹
Using A.G.P. formula: Sₙ = a/(1−r) + dr/(1−r)² − [a+(n−1)d]rⁿ/(1−r)
= 2/(1−x) + 2x/(1−x)² − 2n×xⁿ/(1−x) for x ≠ 1
Sₙ = 2/(1−x) + 2x/(1−x)² − 2nxⁿ/(1−x)
ii) 1,4x,7x²,10x³,... → A.P.: 1,4,7,10 (a=1,d=3); G.P.: 1,x,x²,x³ (r=x)tₙ = [1+(n−1)×3]×xⁿ⁻¹ = (3n−2)xⁿ⁻¹
Sₙ = 1/(1−x) + 3x/(1−x)² − (3n−2)xⁿ/(1−x) for x ≠ 1
iii) 1,2×3,3×9,4×27,... = 1×1, 2×3, 3×9, 4×27 → A.P.: 1,2,3,4 (a=1,d=1); G.P.: 1,3,9,27 (r=3)tₙ = n×3^(n−1)
Sₙ = 1/(1−3) + 1×3/(1−3)² − n×3ⁿ/(1−3) = −1/2 + 3/4 + n×3ⁿ/2 = 1/4 + n×3ⁿ/2
Sₙ = (2n−1)×3ⁿ/4 + 1/4 = [(2n−1)×3ⁿ + 1]/4
Q2
Find sum to infinity: i) 1,2/4,3/16,4/64,...   ii) 3,6/5,9/25,12/125,...
Show ▾
Formula for S∞ of A.G.P.: S∞ = a/(1−r) + dr/(1−r)² (when |r| < 1)

i) 1, 2/4, 3/16, 4/64,... = 1×1, 2×(1/4), 3×(1/4)², 4×(1/4)³ → A.P.: 1,2,3,4 (a=1,d=1); r=1/4S∞ = 1/(1−1/4) + 1×(1/4)/(1−1/4)² = 1/(3/4) + (1/4)/(9/16) = 4/3 + (1/4)×(16/9) = 4/3 + 4/9 = 12/9+4/9 = 16/9
ii) 3,6/5,9/25,12/125,... = 3×1, 3×2×(1/5), 3×3×(1/5)², 3×4×(1/5)³ → 3×[1, 2/5, 3/25,...] → a=1, d=1, r=1/5S∞ of inner = 1/(1−1/5) + (1/5)/(1−1/5)² = 1/(4/5) + (1/5)/(16/25) = 5/4 + 5/16 = 20/16+5/16 = 25/16
Multiply by 3: S∞ = 3×25/16 = 75/16

📝 Exercise 2.6 — Summation using Σr, Σr², Σr³ (Solved)

Q1
Find the sum Σ(r+1)(2r−1) from r=1 to n
Show ▾
Expand (r+1)(2r−1) = 2r²+2r−r−1 = 2r²+r−1Σ(2r²+r−1) = 2Σr² + Σr − Σ1
= 2×n(n+1)(2n+1)/6 + n(n+1)/2 − n
= n(n+1)(2n+1)/3 + n(n+1)/2 − n
= n[((n+1)(2n+1)/3) + (n+1)/2 − 1]
= n[2(n+1)(2n+1) + 3(n+1) − 6]/6
= n[(2n+2)(2n+1) + 3n+3 − 6]/6
= n[4n²+2n+4n+2 + 3n−3]/6
= n[4n²+9n−1]/6 → Sₙ = n(4n²+9n−1)/6
Q2
Find Σ(3r²−2r+1) from r=1 to n
Show ▾
Expand using standard results= 3Σr² − 2Σr + Σ1
= 3×n(n+1)(2n+1)/6 − 2×n(n+1)/2 + n
= n(n+1)(2n+1)/2 − n(n+1) + n
= n[(n+1)(2n+1)/2 − (n+1) + 1]
= n[(n+1)(2n+1) − 2(n+1) + 2]/2
= n[(2n²+3n+1) − 2n−2+2]/2
= n[2n²+n+1]/2 → Sₙ = n(2n²+n+1)/2

Find sum of 2²+4²+6²+8²+... upto n terms.
Show ▾
General term: (2r)² = 4r²Sₙ = Σ4r² (r=1 to n) = 4Σr² = 4×n(n+1)(2n+1)/6 = 2n(n+1)(2n+1)/3
Q5
Find sum of 5×7 + 9×11 + 13×15 + ... upto n terms.
Show ▾
Find rth termFirst factors: 5,9,13,... → A.P. with a=5, d=4 → rth term = 5+(r−1)×4 = 4r+1
Second factors: 7,11,15,... → A.P. with a=7, d=4 → rth term = 7+(r−1)×4 = 4r+3
