Q.4 (i) [4 Marks]
Solve by Cramer's rule: x − y + z = 4, x + y + z = 2, 2x + y − 3z = 0.
AX=B: Cramer's rule uses determinants; matrix method uses A⁻¹
Determinants D = |1,−1,1;1,1,1;2,1,−3| = 1(−3−1)+1(−3−2)+1(1−2) = −4−5−1 = −10 Dx = |4,−1,1;2,1,1;0,1,−3| = 4(−3−1)+1(−6−0)+1(2−0) = −16−6+2 = −20 Dy = |1,4,1;1,2,1;2,0,−3| = 1(−6)−4(−3−2)+1(0−4) = −6+20−4 = 10 Dz = |1,−1,4;1,1,2;2,1,0| = 1(0−2)+1(0−4)+4(1−2) = −2−4−4 = −10
Answer
x = Dx/D = 2  |  y = Dy/D = −1  |  z = Dz/D = 1
Q.4 (iii) [4 Marks]
Evaluate ∫₀^π x/(1 + sin x) dx.
Area under curve from a to b equals the definite integral ∫ₐᵇf(x)dx
Method I = ∫₀^π x/(1+sinx) dx. Using ∫₀^a f(x)dx = ∫₀^a f(a−x)dx: I = ∫₀^π (π−x)/(1+sin(π−x)) dx = ∫₀^π (π−x)/(1+sinx) dx Adding: 2I = π∫₀^π 1/(1+sinx) dx = π∫₀^π (1−sinx)/cos²x dx = π[tanx − secx]₀^π = π[(0+1)−(0+1)] ... = π[0−(−1)−(0−1)] = π[(1)+( 1)] = 2π
Answer
I = π

Q.4 (viii) [4 Marks]
A window is in the form of a rectangle surmounted by a semicircle. If the perimeter is 30 m, find the dimensions for maximum area.
Window: rectangle (width 2r, height h) + semicircle (radius r)
Setup Width = 2r, height = h. Perimeter: 2h + 2r + πr = 30 → h = (30−2r−πr)/2 Area: A = 2rh + πr²/2 = r(30−2r−πr) + πr²/2 = 30r − 2r² − πr²/2
Maximise dA/dr = 30 − 4r − πr = 0 → r = 30/(4+π) ≈ 4.2 m
Answer
r ≈ 4.2 m (width = 2r ≈ 8.4 m), h = (30−2r−πr)/2 ≈ 4.2 m
