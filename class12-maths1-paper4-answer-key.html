Q.1 (i)
For a 2×2 matrix A with |A| = 0, A is:
✔ Answer: (A) singular
Explanation |A| = 0 → matrix is singular (no inverse exists) |A| ≠ 0 → non-singular (invertible)
Q.1 (ii)
The range of y = tan⁻¹x is:
✔ Answer: (B) (−π/2, π/2)
Explanation tan⁻¹x is defined for all real x. Range is the open interval (−π/2, π/2) Note: endpoints excluded (tan(±π/2) = ±∞ — not finite)
Q.1 (iii)
The lines y = 2x + 3 and y = 2x − 5 are:
✔ Answer: (A) parallel
Explanation Both lines have slope m = 2 (same slope). Different y-intercepts (3 ≠ −5) Same slope, different intercepts → parallel lines
Q.1 (iv)
dy/dx of y = eˣ cos x is:
✔ Answer: (B) eˣ(cos x − sin x)
Solution Using product rule: dy/dx = eˣ cos x + eˣ(−sin x) = eˣ(cos x − sin x)
Q.1 (v)
∫(1/x) dx =
✔ Answer: (C) log|x| + c
Explanation ∫(1/x) dx = ln|x| + c = log|x| + c (natural logarithm) The |x| is needed because log is defined only for positive x, but 1/x can be integrated for negative x too.
Q.1 (vi)
Degree of √(1 + (dy/dx)²) = d²y/dx² is:
✔ Answer: (B) 2
Explanation First, remove the square root by squaring: 1 + (dy/dx)² = (d²y/dx²)² Now highest order derivative = d²y/dx². Its power = 2 Order = 2, Degree = 2

Q.3 (iv)

Q.4 (iv)
Find the area between y = cos x and y = sin x on [0, π/2].
Intersection sin x = cos x → tan x = 1 → x = π/4 on [0, π/2] On [0, π/4]: cos x > sin x  |  On [π/4, π/2]: sin x > cos x
