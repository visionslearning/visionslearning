Q.1 (i)
P(A∩B) = P(A)·P(B) implies A and B are:
✔ Answer: (B) independent
Explanation Two events are independent if and only if P(A∩B) = P(A) × P(B) Mutually exclusive means P(A∩B) = 0 (different concept)
Q.1 (ii)
For B(n,p), mean > variance when:
✔ Answer: (D) always true
Explanation Mean = np  |  Variance = npq = np(1−p) Mean/Variance = np/npq = 1/q = 1/(1−p) > 1 always (since 0 < p < 1) So Mean > Variance is always true for binomial distribution
Q.1 (iii)
Both regression lines pass through:
✔ Answer: (B) (x̄, ȳ)
Explanation Both regression lines (y on x and x on y) pass through the point (x̄, ȳ) — the point of means This is because when x = x̄, y = ȳ in both regression equations
Q.1 (iv)
If the feasible region in LPP is bounded, then:
✔ Answer: (C) both maximum and minimum exist
Explanation Bounded feasible region (finite, enclosed) → both optimal solutions (max and min) exist at corner points Unbounded region → max may not exist (or min may not exist)
Q.1 (v)
The cyclical variation has a period of:
✔ Answer: (B) more than one year
Explanation Cyclical variation: multi-year business cycles (typically 2–10 years) Seasonal: within one year (quarterly, monthly, daily patterns)
Q.1 (vi)
Fisher's ideal index is:
✔ Answer: (C) √(L × P)
Explanation Fisher's Ideal Index = √(Laspeyre's × Paasche's) It is the geometric mean of Laspeyre's and Paasche's indices. Satisfies both time reversal and factor reversal tests.
Q.1 (vii)
The normal curve is symmetric about:
✔ Answer: (D) all of these (mean = median = mode)
Explanation For normal distribution: mean = median = mode (all three are equal and = μ) The curve is symmetric about each of these measures. All three coincide at the peak.
Q.1 (viii)
For Poisson, Variance = λ. Then SD =
✔ Answer: (C) √λ
Explanation SD = √Variance = √λ

Q.4 (ii)
(a) Prove Bayes' theorem. (b) Die+Box: P(white from Box I).
Bayes' Theorem P(Aᵢ|B) = P(Aᵢ)×P(B|Aᵢ) / [P(A₁)×P(B|A₁)+P(A₂)×P(B|A₂)] Proof: P(Aᵢ|B) = P(Aᵢ∩B)/P(B). P(Aᵢ∩B) = P(Aᵢ)P(B|Aᵢ). P(B) = ΣP(Aᵢ)P(B|Aᵢ) (total probability). Substituting → Bayes' formula. ✓
Numerical P(Box I) = P(die ≤ 3) = 3/6 = 1/2  |  P(Box II) = 1/2 P(W|Box I) = 3/5  |  P(W|Box II) = 2/5 P(W) = (1/2)(3/5) + (1/2)(2/5) = 3/10 + 2/10 = 5/10 = 1/2 P(Box I|W) = (1/2×3/5)/(1/2) = 3/5
P(from Box I | white ball drawn) = 3/5

Part (a) P(400 < X < 600) = P((400−500)/100 < Z < (600−500)/100) = P(−1 < Z < 1) = 2×P(0<Z<1) = 2×0.3413

Part (b) P(X<40) = 0.0228 = P(Z>2) = P(Z<−2) → z = −2 (40−μ)/10 = −2 → 40−μ = −20 → μ = 60
