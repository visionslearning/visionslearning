Theory — Definitions & Key Concepts
Function (Mapping): A function f : A → B is a relation that associates for each element x in A, a unique (exactly one) element y in B. Written as y = f(x).

Domain: Set A (set of inputs / pre-images)
Co-domain: Set B
Range: f(A) = {y ∈ B | y = f(x) for some x ∈ A} ⊆ Co-domain
When is a relation NOT a function?
① If any element in A is not mapped to any element in B.
② If any element in A is mapped to more than one element in B.
🔢
Types of Functions

One-One (Injective)

Different elements in A have different images in B.
f(a) = f(b) ⟹ a = b
a ≠ b ⟹ f(a) ≠ f(b)

Test: Horizontal Line Test — no horizontal line crosses graph at more than one point.

Onto (Surjective)

Every element y in B has a pre-image x in A. Range = Co-domain.
f(A) = B

Bijective = One-One + Onto

f is bijective ⟺ f is both injective and surjective

6.2 Algebra of Functions

Operations on f and g (defined on A ∩ B)

(f + g)(x) = f(x) + g(x)
(f − g)(x) = f(x) − g(x)
(f·g)(x) = f(x)·g(x)
(f/g)(x) = f(x)/g(x), g(x) ≠ 0
🔗
6.2.1 Composition of Functions
Composition: If f : A→B and g : B→C, then
(g ∘ f)(x) = g[f(x)] — read as "g composed with f"

Domain of g∘f ⊆ Domain of f    Range of g∘f ⊆ Range of g
🔄
6.2.2 Inverse Functions
Inverse Function: If f : A→B is one-one and onto, then f⁻¹ : B→A is defined as:
f⁻¹(y) = x if f(x) = y

f[f⁻¹(x)] = f⁻¹[f(x)] = x
Note: f⁻¹(x) ≠ [f(x)]⁻¹ (inverse ≠ reciprocal)
✂️
6.2.3 Piecewise Defined Functions
Piecewise Function: Defined by two or more formulas on different parts of the domain.

Example: f(x) = x+1 if x<1 ; 4−x if x≥1

Q.1 — Check if the following relations are functions
1(a)
Relation with arrows: every element in A maps to exactly one element in B.
Solution

Each element of A has exactly one image in B.

∴ It IS a function.
1(b)
Relation where element p maps to multiple elements in B.
Solution

p ∈ A maps to more than one element in B (arrows split).

∴ It is NOT a function.
1(c)
Relation where arrows from A cross to B with some elements in A having multiple images.
Solution

Some elements in A have more than one image in B (e.g. 0 maps to both 6 and 3).

∴ It is NOT a function.

2(a)
{(1,0),(3,3),(2,−1),(4,1),(2,2)}
Solution

Element 2 appears twice: (2,−1) and (2,2) → two images for x=2.

∴ NOT a function.
2(b)
{(1,2),(2,−1),(3,1),(4,3)}
Solution

Each of 1,2,3,4 appears exactly once. All images are in B.

∴ It IS a function. Domain = {1,2,3,4}, Range = {−1,1,2,3}

{(1,3),(4,1),(2,2)}
Solution

Element 3 ∈ A has no image → not every element of A is mapped.

∴ NOT a function.
2(d)
{(1,1),(2,1),(3,1),(4,1)}
Solution

Each element of A has exactly one image (all map to 1). Valid many-one function.

∴ It IS a function. (Constant function) Domain = {1,2,3,4}, Range = {1}

Q.14 — Check injectivity and surjectivity
14(a)
f : ℕ → ℕ given by f(x) = x²
Solution

Injective: f(x₁)=f(x₂) → x₁²=x₂² → x₁=x₂ (since x∈ℕ, positive) ✓ Injective.

Surjective: Is every n∈ℕ a perfect square? No (e.g. 2,3 not perfect squares) ✗ Not surjective.

Injective but NOT surjective.
14(b)
f : ℤ → ℤ given by f(x) = x²
Solution

Injective: f(2) = f(−2) = 4 but 2 ≠ −2 ✗ Not injective.

Surjective: −1 ∈ ℤ has no preimage (x²≥0 always) ✗ Not surjective.

Neither injective nor surjective.
14(c)
f : ℝ → ℝ given by f(x) = x²
Solution

Injective: f(2) = f(−2) = 4, 2 ≠ −2 ✗ Not injective.

Surjective: y = −1 has no real preimage ✗ Not surjective.

Neither injective nor surjective.
14(d)
f : ℕ → ℕ given by f(x) = x³
Solution

Injective: x₁³=x₂³ → x₁=x₂ ✓ Injective.

Surjective: 2 ∈ ℕ has no preimage (∛2 ∉ ℕ) ✗ Not surjective.

Injective but NOT surjective.
14(e)
f : ℝ → ℝ given by f(x) = x³
Solution

Injective: x₁³=x₂³ → x₁=x₂ ✓ Injective.

Surjective: For every y∈ℝ, x = ∛y ∈ ℝ ✓ Surjective.

Bijective (both injective and surjective).

(g∘g)(x) = g[g(x)] = 5(5x−2) − 2 = 25x − 10 − 2

(g∘g)(x) = 25x − 12
Q.4 — Verify f and g are inverse functions
4(a)
f(x) = (x−7)/4, g(x) = 4x + 7
Solution

f[g(x)] = (4x+7−7)/4 = 4x/4 = x ✓

g[f(x)] = 4·(x−7)/4 + 7 = x − 7 + 7 = x ✓

∴ f and g are inverse functions.
4(b)
f(x) = x³ + 4, g(x) = ∛(x−4)
Solution

f[g(x)] = (∛(x−4))³ + 4 = (x−4) + 4 = x ✓

g[f(x)] = ∛(x³+4−4) = ∛(x³) = x ✓

∴ f and g are inverse functions.
4(c)
f(x) = (x+3)/(x−2), g(x) = (2x+3)/(x−1)
Solution

f[g(x)] = [(2x+3)/(x−1) + 3] / [(2x+3)/(x−1) − 2]

= [(2x+3+3x−3)/(x−1)] / [(2x+3−2x+2)/(x−1)]

= (5x)/(5) = x ✓

Similarly g[f(x)] = x ✓

∴ f and g are inverse functions.

Constant function — many-to-one → NOT one-one.

Inverse does not exist.
5(c)

Solution

Linear → one-one and onto. Inverse exists.

5(d)

Solution

Domain: 4x+5 ≥ 0 → x ≥ −5/4. Range: [0,∞). f is one-one (increasing). Inverse exists.

y = √(4x+5) → y² = 4x+5 → x = (y²−5)/4

f⁻¹(x) = (x² − 5)/4, x ≥ 0
5(e)
f(x) = 9x³ + 8
Solution

Strictly increasing → one-one and onto on ℝ. Inverse exists.

y = 9x³+8 → x³ = (y−8)/9 → x = ∛[(y−8)/9]

f⁻¹(x) = ∛[(x−8)/9]
5(f)
f(x) = x+7 for x<0; 8−x for x≥0
Solution

For x<0: f is increasing. For x≥0: f is decreasing. Check: at x=0, f(0)=8; as x→−∞, f→−∞.

Range of first piece: (−∞,7); Range of second: (−∞,8]. Combined range: (−∞,8].

Check one-one: f(−1)=6, can any x≥0 give 6? 8−x=6→x=2 ✗ (different input, same output)

Inverse does NOT exist (not one-one overall).

Critical points: x=2, x=4. Three regions:
