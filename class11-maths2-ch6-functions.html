Theory — Definitions & Key Concepts

6.1 Function (Mapping)

A function f : A → B associates to each element x ∈ A, a unique (exactly one) element y ∈ B.

  • y = f(x) — y is the image of x under f
  • Domain = Set A (all valid inputs)
  • Co-domain = Set B
  • Range = f(A) = {y ∈ B | y = f(x) for some x ∈ A} ⊆ Co-domain

When is a Relation NOT a Function?

  • ① Any element in A has no image in B → NOT a function
  • ② Any element in A has more than one image in B → NOT a function

6.1.1 Types of Functions

One-One (Injective): Different elements have different images.

f(a) = f(b) ⟹ a = b

Onto (Surjective): Every element of B is an image of some element of A. Range = Co-domain.

f(A) = B

Bijective = One-One + Onto

Vertical Line Test — A graph is a function if no vertical line cuts it at more than one point.

Horizontal Line Test — A function is one-one if no horizontal line cuts it at more than one point.

6.1.4 Value of Function

f(a) is the value of f(x) at x = a. Substitute x = a into the formula.

Q.1 — Check if the following relations are functions
Q 1(a)

Observe
Each element in A has exactly one arrow going to B.

R₁ IS a function.

An element in A has more than one image in B.

One element → two images → violates uniqueness. ✗
∴ Answer
R₂ is NOT a function.
Q 1(c)
Relation R₃: Element 0 in A has two images in B.

Element 0 ∈ A maps to both 6 and 3 in B.
Condition
One input has two outputs → violates function definition. ✗
∴ Answer
R₃ is NOT a function.

Q.8 — Find domain and range of the following functions
Q 8(a)
f(x) = 7x² + 4x − 1
Given
f(x) = 7x² + 4x − 1 (polynomial)
Domain
Polynomial is defined for all x ∈ ℝ.
Range
a = 7 > 0 (upward parabola). Minimum value = (4ac − b²)/4a = (4·7·(−1) − 16)/28 = (−28−16)/28 = −44/28 = −11/7
Conclusion
f(x) ≥ −11/7 for all x
∴ Answer
Domain = ℝ,   Range = [−11/7, ∞)
Q 8(b)
g(x) = (x + 4)/(x − 2)
Domain
Denominator x − 2 ≠ 0  ⟹  x ≠ 2
Range
Let y = (x+4)/(x−2)  ⟹  y(x−2) = x+4  ⟹  yx − 2y = x + 4
Step 2
x(y − 1) = 2y + 4  ⟹  x = (2y + 4)/(y − 1)
Step 3
x is defined when y ≠ 1. So y = 1 is not in the range.
∴ Answer
Domain = ℝ − {2},   Range = ℝ − {1}
Q 8(c)
h(x) = (√x + 5)/(5 + x)
Domain
√x is defined for x ≥ 0. Denominator 5 + x ≠ 0 → x ≠ −5 (already excluded since x ≥ 0)
Domain
x ≥ 0 → Domain = [0, ∞)
Range
At x = 0: h = 5/5 = 1. As x → ∞: h = √x/(x+5) → 0
Conclusion
h(x) is continuous, decreasing from 1 to 0 (not reaching 0).
∴ Answer
Domain = [0, ∞),   Range = (0, 1]
Q 8(d)
f(x) = ∛(x + 1)
Domain
Cube root is defined for all real numbers.
Range
As x ranges over ℝ, ∛(x+1) also ranges over ℝ.
∴ Answer
Domain = ℝ,   Range = ℝ
Q 8(e)
f(x) = √[(x − 2)(5 − x)]
Condition
(x − 2)(5 − x) ≥ 0
Critical pts
x = 2 and x = 5
Sign test
x < 2: (−)(+) = − ✗    2 ≤ x ≤ 5: (+)(+) = + ✓    x > 5: (+)(−) = − ✗
Range
Max at midpoint x = 7/2: (7/2−2)(5−7/2) = (3/2)(3/2) = 9/4 → √(9/4) = 3/2
∴ Answer
Domain = [2, 5],   Range = [0, 3/2]
Q 8(f)
f(x) = √[(x − 3)/(7 − x)]
Condition
(x − 3)/(7 − x) ≥ 0 and 7 − x ≠ 0
Analysis
Both numerator and denominator same sign:
Case 1
x − 3 ≥ 0 and 7 − x > 0  ⟹  x ≥ 3 and x < 7  ⟹  3 ≤ x < 7
Case 2
x − 3 ≤ 0 and 7 − x < 0  ⟹  x ≤ 3 and x > 7 → impossible
∴ Answer
Domain = [3, 7),   Range = [0, ∞)
Q 8(g)
f(x) = √(16 − x²)
Condition
16 − x² ≥ 0  ⟹  x² ≤ 16  ⟹  −4 ≤ x ≤ 4
Range
Max at x = 0: √16 = 4. Min at x = ±4: √0 = 0
∴ Answer
Domain = [−4, 4],   Range = [0, 4]

Q.14 — Check injectivity and surjectivity
Q 14(a)
f : ℕ → ℕ, f(x) = x²
Injective?
Let f(x₁) = f(x₂) ⟹ x₁² = x₂² ⟹ x₁ = x₂ (since x ∈ ℕ, both positive) ✓
Surjective?
Is every n ∈ ℕ a perfect square? No. e.g., 2 ∈ ℕ has no preimage in ℕ. ✗
∴ Answer
Injective but NOT surjective.
Q 14(b)
f : ℤ → ℤ, f(x) = x²
Injective?
f(2) = 4 = f(−2), but 2 ≠ −2. ✗ Not injective.
Surjective?
−1 ∈ ℤ has no preimage (x² ≥ 0 always). ✗ Not surjective.
∴ Answer
Neither injective nor surjective.
Q 14(c)
f : ℝ → ℝ, f(x) = x²
Injective?
f(2) = f(−2) = 4, but 2 ≠ −2. ✗
Surjective?
y = −1 has no real preimage. ✗
∴ Answer
Neither injective nor surjective.
Q 14(d)
f : ℕ → ℕ, f(x) = x³
Injective?
x₁³ = x₂³ ⟹ x₁ = x₂ ✓
Surjective?
2 ∈ ℕ: ∛2 ∉ ℕ. Not every n ∈ ℕ is a perfect cube. ✗
∴ Answer
Injective but NOT surjective.
Q 14(e)
f : ℝ → ℝ, f(x) = x³
Injective?
x₁³ = x₂³ ⟹ x₁ = x₂ (cube root is unique in ℝ) ✓
Surjective?
For every y ∈ ℝ, x = ∛y ∈ ℝ exists and f(x) = y. ✓
∴ Answer
Bijective (both injective and surjective).

Let's Remember — Quick Revision

✅ 3 Conditions for a Function f : A → B

  • Every element of A has an image in B
  • Each element of A has exactly ONE image in B
  • Range ⊆ Co-domain

⚡ Key Formulas at a Glance

PropertyCondition / Formula
One-onef(x₁)=f(x₂) ⟹ x₁=x₂
OntoRange = Co-domain
Composition(g∘f)(x) = g[f(x)]
Inversef⁻¹ exists iff f is bijective; f[f⁻¹(x)]=x
PiecewiseDifferent formula on different parts of domain

{x}x − [x]; Domain ℝ, Range [0,1)
|x|x if x≥0, −x if x<0; Domain ℝ, Range [0,∞)

Total functions = nᵐ One-one (m≤n): n!/(n−m)! One-one (m>n): 0 Constant functions = n
