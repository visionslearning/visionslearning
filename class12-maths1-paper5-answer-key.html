✔ Answer: (B) kⁿ|A|

Solution Range of cos⁻¹ is [0, π]. cos(π/3) = 1/2 → cos(π − π/3) = −1/2 cos⁻¹(−1/2) = π − π/3 = 2π/3

✔ Answer: (B) −1
Solution m = tan(135°) = tan(180° − 45°) = −tan(45°) = −1
Q.1 (iv)
d/dx(log(tan x)) =
✔ Answer: (A) 2/sin 2x
Solution d/dx(log(tanx)) = (1/tanx) × sec²x = cosx/sinx × 1/cos²x = 1/(sinx cosx) = 2/sin2x
Q.1 (v)

✔ Answer: (B) tan x + c

Q.1 (vi)
x²(d²y/dx²) + x(dy/dx) + y = 0 has order and degree:
✔ Answer: (B) order 2, degree 1
Explanation Highest derivative = d²y/dx² → order = 2 Power of d²y/dx² = 1 → degree = 1 (This is Euler-Cauchy equation)
Q.1 (vii)
Projection of î + ĵ + k̂ on î + ĵ is:
✔ Answer: (B) √2
Solution Projection = a⃗·b̂ = a⃗·(b⃗/|b⃗|) a⃗ = î+ĵ+k̂, b⃗ = î+ĵ, |b⃗| = √2 Projection = (î+ĵ+k̂)·(î+ĵ)/√2 = (1+1+0)/√2 = 2/√2 = √2
Q.1 (viii)

✔ Answer: (A) 1
Explanation Direction cosines: l = cosα, m = cosβ, n = cosγ (angles with x, y, z axes) l² + m² + n² = 1 (always, by definition)

Q.2 (i)
If A = [[2,1],[3,4]], find adj(A).
Solution Cofactors: C₁₁ = +4, C₁₂ = −3, C₂₁ = −1, C₂₂ = +2 Cofactor matrix = [[4,−3],[−1,2]] adj(A) = Transpose of cofactor matrix = [[4,−1],[−3,2]]
Answer
adj(A) = [[4,−1],[−3,2]]
Verify: A × adj(A) = |A| × I = (8−3)I = 5I ✓
Q.2 (iii)
Show x² + y² + 2x − 4y + 1 = 0 is a circle. Find centre and radius.
Solution Complete the square: (x²+2x+1) + (y²−4y+4) = −1+1+4 (x+1)² + (y−2)² = 4
Answer
Centre = (−1, 2), Radius = 2

Q.2 (xi)
Find intervals of increase and decrease of f(x) = x³ − 3x² + 4.
Solution f'(x) = 3x² − 6x = 3x(x − 2) = 0 → x = 0 or x = 2 f'(x) > 0 (increasing): x ∈ (−∞, 0) ∪ (2, ∞) f'(x) < 0 (decreasing): x ∈ (0, 2)
Answer
Increasing on (−∞,0) and (2,∞) | Decreasing on (0,2)

Q.4 (viii)
A ladder 13 m long leans against a wall. Lower end moves away at 5 cm/s. Find rate at which upper end slides down when lower end is 5 m from wall.
Setup x = distance of lower end from wall, y = height on wall x² + y² = 13² = 169 Given: dx/dt = 5 cm/s = 0.05 m/s, x = 5 m
Solution At x = 5: 25 + y² = 169 → y = 12 m Differentiate: 2x(dx/dt) + 2y(dy/dt) = 0 dy/dt = −x(dx/dt)/y = −5 × 5/12 = −25/12 cm/s
Answer
Rate of sliding down = 25/12 cm/s ≈ 2.08 cm/s (downward)
