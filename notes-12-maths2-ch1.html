All Derivative Formulas — Chapter 1

⛓️ Chain Rule & Standard Results
d/dx [f(g(x))] = f'(g(x)) · g'(x)
d/dx [xⁿ] = nxⁿ⁻¹
d/dx [eˣ] = eˣ | d/dx [aˣ] = aˣ log a
d/dx [log x] = 1/x
d/dx [sin x] = cos x
d/dx [cos x] = −sin x
d/dx [tan x] = sec²x
d/dx [cot x] = −cosec²x
d/dx [sec x] = sec x · tan x
d/dx [cosec x] = −cosec x · cot x
🔄 Inverse Trigonometric Derivatives
d/dx [sin⁻¹x] = 1/√(1−x²), |x|<1
d/dx [cos⁻¹x] = −1/√(1−x²), |x|<1
d/dx [tan⁻¹x] = 1/(1+x²)
d/dx [cot⁻¹x] = −1/(1+x²)
d/dx [sec⁻¹x] = 1/(x√(x²−1)), x>1
d/dx [cosec⁻¹x] = −1/(x√(x²−1)), x>1
sin⁻¹x + cos⁻¹x = π/2
tan⁻¹x + cot⁻¹x = π/2
dx/dy = 1/(dy/dx), dy/dx ≠ 0
📝 Logarithmic Differentiation
If y = [f(x)]^g(x), take log both sides:
log y = g(x)·log[f(x)]
Differentiate → (1/y)(dy/dx) = ...
∴ dy/dx = y × [RHS]

d/dx(xˣ) = xˣ(1 + log x)
d/dx(aˣ) = aˣ log a
📐 Parametric & Higher Order
If x=f(t), y=g(t): dy/dx = (dy/dt)/(dx/dt)

d²y/dx² = d/dx(dy/dx)
For parametric: d²y/dx² = [d/dt(dy/dx)] / (dx/dt)

nth derivative of sin(ax+b) = aⁿ sin(ax+b+nπ/2)
nth derivative of cos(ax+b) = aⁿ cos(ax+b+nπ/2)
nth derivative of eˣ = eˣ
nth derivative of log x = (−1)ⁿ⁻¹(n−1)!/xⁿ
🔑 Key Substitutions
√(1−x²) → x = sinθ or cosθ
√(1+x²) → x = tanθ or cotθ
√(x²−1) → x = secθ or cosecθ
2x/(1+x²) → x = tanθ (gives sin2θ)
(1−x²)/(1+x²) → x = tanθ (gives cos2θ)
3x−4x³ → x = sinθ (gives sin3θ)
4x³−3x → x = cosθ (gives cos3θ)
📌 tan⁻¹ Addition Formulas
tan⁻¹x + tan⁻¹y = tan⁻¹[(x+y)/(1−xy)]
tan⁻¹x − tan⁻¹y = tan⁻¹[(x−y)/(1+xy)]

tan⁻¹(4x/(1+21x²)) = tan⁻¹7x − tan⁻¹3x
(split numerator/denominator method)

Implicit: Differentiate both sides w.r.t x,
treat y as function of x,
collect dy/dx terms, solve.
