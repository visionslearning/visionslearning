Choose the correct alternative. (MCQ)
5 Marks
Ch1 i. If n(A) = 10, n(B) = 8, n(A∩B) = 4, then n(A∪B) = ________.
Formula n(A∪B) = n(A) + n(B) − n(A∩B) Step 1 = 10 + 8 − 4 = 14 n(A∪B) = 14
Ch2 ii. The number π (pi) is ________.
π is an irrational number (non-terminating, non-repeating: 3.14159265...)
Ch3 iii. The value of p(0) for p(x) = 3x² − 5x + 2 is ________.
Step 1 p(0) = 3(0)² − 5(0) + 2 = 0 − 0 + 2 = 2 p(0) = 2
Ch4 iv. If a : b :: c : d, then which of the following is true?
ad = bc   (product of extremes = product of means)
Ch3 v. Remainder when x³ + 3x + 1 is divided by (x − 2) is ________.
Remainder Thm Remainder = p(2) = (2)³ + 3(2) + 1 Step 1 = 8 + 6 + 1 = 15 Remainder = 15
2
State whether True or False. Correct the false statements.
4 Marks
Ch1 i. A ∪ A' = Universal set (U).
TRUE ✓ — A and its complement A' together make up the universal set.
Ch3 ii. (a + b)(a − b) = a² + b²
FALSE ✗ — Correct: (a+b)(a−b) = a² − b²   [difference of squares identity]
Ch4 iii. In a proportion a:b::c:d, b and c are called extremes.
FALSE ✗ — Correct: b and c are called means. a and d are called extremes.
Ch2 iv. Between any two rational numbers, there are infinitely many rational numbers.
TRUE ✓ — The set of rational numbers is dense; between any two rationals there are infinitely many.

Fill in the blanks.
4 Marks
Ch1 i. If A ⊆ B and B ⊆ A, then A = ________.
A = B   (A and B are equal sets)
Ch3 ii. The zero of the polynomial p(x) = 2x − 6 is ________.
Step 1 Set p(x) = 0: 2x − 6 = 0 Step 2 2x = 6  →  x = 3 Zero = 3
Ch4 iii. If 3 : 4 = 6 : x, find x.
Step 1 3 × x = 4 × 6  (cross multiply) Step 2 3x = 24  →  x = 8 x = 8
Ch2 iv. Simplify: √18 = ________.
Step 1 18 = 9 × 2 Step 2 √18 = √(9×2) = √9 × √2 = 3√2 √18 = 3√2

Ch1 A. Draw a Venn diagram for A ∩ B' (A intersection complement of B) where A = {1,2,3,4}, B = {3,4,5,6}, U = {1,2,3,4,5,6,7}.
Step 1 B' = U − B = {1,2,7} Step 2 A ∩ B' = A ∩ {1,2,7} = {1,2} (elements in A that are NOT in B) A ∩ B' = {1, 2}   (this is also called A − B)
Ch2 B. Find 5 rational numbers between 1/3 and 1/2.
Step 1 Convert to same denominator (LCM method — multiply by 10): Step 2 1/3 = 10/30    1/2 = 15/30 Step 3 Five rationals between 10/30 and 15/30: 11/30, 12/30 (=2/5), 13/30, 14/30 (=7/15), 11/30  →  i.e., 11/30, 2/5, 13/30, 7/15, 14/30
Ch3 C. Factorise: x² + 7x + 12.
Step 1 Find two numbers: product = 12, sum = 7 → 3 and 4 Step 2 x² + 7x + 12 = x² + 3x + 4x + 12 Step 3 = x(x+3) + 4(x+3) = (x+3)(x+4) x² + 7x + 12 = (x+3)(x+4)
Ch4 D. Ages of Arjun and Bheem are in ratio 5:7. After 4 years the ratio will be 3:4. Find their present ages.
Step 1 Let Arjun = 5x, Bheem = 7x Step 2 After 4 years: (5x+4)/(7x+4) = 3/4 Step 3 4(5x+4) = 3(7x+4) → 20x+16 = 21x+12 → x = 4 Arjun = 20 years   Bheem = 28 years
Ch3 E. Verify that x = −1 is a zero of p(x) = x³ + x² − x − 1.
Step 1 p(−1) = (−1)³ + (−1)² − (−1) − 1 Step 2 = −1 + 1 + 1 − 1 = 0 p(−1) = 0 ∴ x = −1 is a zero of p(x). ✓

Ch2 A. Rationalise the denominator: (i) 1/√3    (ii) (√5+1)/(√5−1)
(i) 1/√3: Step 1 Multiply numerator and denominator by √3: Step 2 = 1×√3 / (√3×√3) = √3/3 1/√3 = √3/3 (ii) (√5+1)/(√5−1): Step 1 Multiply by conjugate (√5+1)/(√5+1): Step 2 = (√5+1)² / [(√5)²−(1)²] = (5+2√5+1)/(5−1) Step 3 = (6+2√5)/4 = (3+√5)/2 (√5+1)/(√5−1) = (3+√5)/2
Ch3 B. If p(x) = x³ − 2x² − x + 2, show that x = 1, x = −1, x = 2 are all zeros. Factorise completely.
p(1) = 1−2−1+2 = 0 ✓  →  (x−1) is a factor p(−1) = −1−2+1+2 = 0 ✓  →  (x+1) is a factor p(2) = 8−8−2+2 = 0 ✓  →  (x−2) is a factor Factorised form Since degree 3 and three factors found: p(x) = (x−1)(x+1)(x−2) = x³ − 2x² − x + 2 ✓
Ch4 C. The income of A and B are in ratio 5:3 and their expenditures are in ratio 9:5. If each saves ₹1600, find their incomes.
Step 1 Let income of A = 5x, income of B = 3x Step 2 Let expenditure of A = 9y, expenditure of B = 5y Step 3 Savings: 5x − 9y = 1600  ...(1) 3x − 5y = 1600  ...(2) Step 4 From (1): 5x − 9y = 1600 × multiply by 5 → 25x − 45y = 8000 From (2): multiply by 9 → 27x − 45y = 14400 Step 5 Subtract: 2x = 6400 → x = 3200 Income of A = 5 × 3200 = ₹16,000   Income of B = 3 × 3200 = ₹9,600

Ch1 A. If U = {1,2,3,...,10}, A = {2,4,6,8,10}, B = {1,2,3,4,5}. Verify De Morgan's Laws: (i) (A∪B)' = A'∩B'   (ii) (A∩B)' = A'∪B' (5M)
Given A' = {1,3,5,7,9}   B' = {6,7,8,9,10} (i) LHS: (A∪B)' Step 1 A∪B = {1,2,3,4,5,6,8,10} Step 2 (A∪B)' = U − (A∪B) = {7,9} RHS: A'∩B' Step 3 A'∩B' = {1,3,5,7,9}∩{6,7,8,9,10} = {7,9} (A∪B)' = A'∩B' = {7,9} ✓ Verified (ii) LHS: (A∩B)' Step 1 A∩B = {2,4} Step 2 (A∩B)' = U − {2,4} = {1,3,5,6,7,8,9,10} RHS: A'∪B' Step 3 A'∪B' = {1,3,5,7,9}∪{6,7,8,9,10} = {1,3,5,6,7,8,9,10} (A∩B)' = A'∪B' = {1,3,5,6,7,8,9,10} ✓ Verified
Ch3 B. Using identity (a+b+c)² = a²+b²+c²+2ab+2bc+2ca, expand: (x + 2y + 3z)². Also find the value if x=1, y=2, z=3. (6M)
Step 1 a = x, b = 2y, c = 3z Step 2 = x² + (2y)² + (3z)² + 2(x)(2y) + 2(2y)(3z) + 2(3z)(x) Step 3 = x² + 4y² + 9z² + 4xy + 12yz + 6zx (x+2y+3z)² = x² + 4y² + 9z² + 4xy + 12yz + 6zx Value at x=1, y=2, z=3: Step 4 = (1)² + 4(4) + 9(9) + 4(1)(2) + 12(2)(3) + 6(3)(1) Step 5 = 1 + 16 + 81 + 8 + 72 + 18 = 196 Verify x+2y+3z = 1+4+9 = 14; 14² = 196 ✓ Value = 196 ✓
