🧠 MHT-CET Exam Strategy

Tried & tested strategy from Shashikant Sir — students who followed this scored 140+ in CET

📅 3-Month Study Plan

  • Month 1: Complete Class 12 chapters + practice MCQs
  • Month 2: Class 11 chapters + chapter-wise tests
  • Month 3: Previous years papers + full mock tests
  • Solve minimum 50 MCQs daily
  • Revise formula sheets every Sunday

⏰ On Exam Day Tips

  • Attempt Physics first (most scoring if prepared)
  • Skip difficult questions — come back later
  • No negative marking → attempt ALL questions
  • Mark questions to review (use rough work space)
  • Last 20 min: fill remaining guesses (B or C statistically better)
  • Keep calm — 200 Q in 180 min = 54 sec per question

⚛️ Physics Strategy

  • Memorise all standard formulas (derivation not needed in CET)
  • Draw quick diagram for optics/electrostatics questions
  • Dimensional analysis — eliminate wrong options quickly
  • High priority: Electrostatics, Current Electricity, Optics
  • Numericals: substitute directly, don't overthink
  • Semiconductor logic gates — always 2-3 easy marks

🧪 Chemistry Strategy

  • Organic: learn IUPAC names + reaction mechanisms
  • Memorise activity series and standard reduction potentials
  • Colligative properties: formula-based, always numerical
  • p-block: properties & preparation reactions are direct marks
  • Coordination compounds: IUPAC naming is guaranteed 2-3 Q
  • Biomolecules: read once — mostly factual/definition MCQs

📐 Maths Strategy

  • Integration is the single biggest topic — master it first
  • Derivatives & applications together = 17 Q (~17% of Maths)
  • Matrices: practice row operations and Cramer's rule daily
  • Probability: conditional probability & Bayes' theorem must-do
  • 3D Geometry & Vectors: direction cosines, angle formulas
  • Never leave Straight Lines — always 3-4 straightforward Q

🌿 Biology Strategy (PCB)

  • Genetics is the most scoring — solve all Mendel problems
  • Biotechnology: rDNA steps, PCR, applications — direct questions
  • Learn all diagrams: reproductive system, Z-scheme, DNA, lac operon
  • Ecology: food chains, ecological pyramids, biodiversity numbers
  • Human physiology: hormone table (which gland → which hormone)
  • Plant physiology: photosynthesis reactions and products
🎯 Score Target Guide:
140–160 → Engineering (most branches)  |  160–180 → Top engineering colleges (VJTI, COEP, ICT)  |  180–200 → MBBS / BDS (with Biology)
Score 120+ in 3 months? Focus only on: Integration, Electrostatics + Current Electricity, Organic Chemistry, Genetics = covers ~45% of total marks.

📐 MHT-CET Formula Sheet

All must-know formulas for CET — print this and revise every weekend

⚛️ Physics — Key Formulas

  • E = σ/(2ε₀) — infinite plane sheet
  • C = Kε₀A/d — capacitor with dielectric
  • R = ρL/A — resistance
  • F/L = μ₀I₁I₂/(2πd) — parallel wires
  • θ = (NBA/k)·I — galvanometer
  • V_S/V_P = N_S/N_P — transformer
  • 1/v + 1/u = 1/f — mirror/lens
  • β = λD/d — fringe width (YDSE)
  • KE_max = hν − φ — photoelectric
  • E_n = −13.6/n² eV — Bohr atom
  • t₁/₂ = 0.693/λ — radioactive decay
  • ΔE = Δmc² — mass-energy

🧪 Chemistry — Key Formulas

  • p_A = p°_A · x_A — Raoult's law
  • ΔTb = Kb·m — boiling pt elevation
  • ΔTf = Kf·m — freezing pt depression
  • π = CRT — osmotic pressure
  • k = (2.303/t)·log[A₀]/[A] — 1st order
  • t₁/₂ = 0.693/k — 1st order half-life
  • E°cell = E°cathode − E°anode
  • ΔG° = −nFE°cell
  • m = ZIt = MIt/(nF) — Faraday
  • pH = −log[H⁺]
  • Kw = Ka · Kb = 10⁻¹⁴

📐 Maths — Key Formulas

  • ∫xⁿdx = xⁿ⁺¹/(n+1) + c
  • ∫(1/x)dx = ln|x| + c
  • ∫eˣdx = eˣ + c
  • d/dx(uv) = u'v + uv' (product rule)
  • d/dx(u/v) = (u'v − uv')/v²
  • Distance = |ax₁+by₁+c|/√(a²+b²)
  • Area = ½|x₁(y₂−y₃)+x₂(y₃−y₁)+x₃(y₁−y₂)|
  • P(A|B) = P(A∩B)/P(B)
  • Mean of Binomial = np; Variance = npq
  • ∫₀^(π/2)sinⁿx dx = Wallis formula
  • d²y/dx²<0 → maxima; >0 → minima

🌿 Biology — Key Facts

  • Monohybrid ratio: 3:1 (F₂)
  • Dihybrid ratio: 9:3:3:1 (F₂)
  • DNA: A=T (2H-bonds), G≡C (3H-bonds)
  • Pitch of DNA = 3.4 nm, 10 bp/turn
  • PCR: 94°C → 55°C → 72°C
  • Restriction enzyme = EcoRI, BamHI
  • Lac operon: Jacob-Monod model (1961)
  • Hormone insulin — from β-cells of Islets of Langerhans
  • Photolysis: 2H₂O → 4H⁺ + 4e⁻ + O₂
  • Calvin cycle: 3-carbon fixation (C₃ pathway)
  • Human chromosomes: 46 (23 pairs)
  • Blood groups: ABO — co-dominance
