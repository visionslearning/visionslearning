📖 3.1 — Compound Angles
Definition
Compound angle : An angle formed by the sum or difference of two or more angles is called a compound angle.
Example : (A + B), (A − B), (A + B + C) are compound angles.
📐 Theorem 1 — cos(A − B)
cos(A − B) = cosA cosB + sinA sinB
Proof idea
Draw a unit circle. P makes angle A, Q makes angle B with positive X-axis.
∴ P = (cosA, sinA), Q = (cosB, sinB)
Compute d(PQ)² from coordinates, then re-compute with OQ as new X-axis (angle = A−B).
Equating both gives: cos(A − B) = cosA cosB + sinA sinB
📐 Theorem 2 — cos(A + B)
cos(A + B) = cosA cosB − sinA sinB
Proof
In cos(A − B) = cosA cosB + sinA sinB, replace B with −B:
cos(A + B) = cosA cos(−B) + sinA sin(−B) = cosA cosB − sinA sinB
∵ cos(−θ) = cosθ and sin(−θ) = −sinθ
📐 Theorem 3 — sin(A − B)
sin(A − B) = sinA cosB − cosA sinB
Proof
Use: sin θ = cos(π/2 − θ). Put θ = A − B:
sin(A−B) = cos(π/2 − (A−B)) = cos((π/2 − A) + B)
= cos(π/2 − A)cosB − sin(π/2 − A)sinB = sinA cosB − cosA sinB
📐 Theorem 4 — sin(A + B)
sin(A + B) = sinA cosB + cosA sinB
📐 Theorem 5 — tan(A + B)
tan(A + B) = (tanA + tanB) / (1 − tanA tanB)
Proof idea
tan(A+B) = sin(A+B)/cos(A+B). Divide numerator and denominator by cosA cosB.
📐 Theorem 6 — tan(A − B)
tan(A − B) = (tanA − tanB) / (1 + tanA tanB)
📐 Results for cot
cot(A + B) = (cotA cotB − 1) / (cotB + cotA)
cot(A − B) = (cotA cotB + 1) / (cotB − cotA)
📋 3.2 — Allied Angles
Definition
If the sum or difference of two angles is an integral multiple of π/2, they are called allied angles.
For angle θ, its allied angles are: −θ, π/2 ± θ, π ± θ, 3π/2 ± θ, 2π ± θ
Function −θ π/2 − θ π/2 + θ π − θ π + θ 3π/2 − θ 3π/2 + θ 2π − θ 2π + θ

Quick Rule
For π/2 ± θ : sin ↔ cos swap, tan ↔ cot swap. Sign depends on quadrant of the original angle.
For π ± θ, 2π ± θ : Function name stays same. Sign depends on quadrant.
ASTC Rule : All (Q1) → Sin (Q2) → Tan (Q3) → Cos (Q4) positive.
⭐ Important Results to Remember
cos(π/2 − θ) = sinθ      sin(π/2 − θ) = cosθ
cos(π/2 + θ) = −sinθ     sin(π/2 + θ) = cosθ
cos(π − θ) = −cosθ      sin(π − θ) = sinθ
cos(π + θ) = −cosθ      sin(π + θ) = −sinθ
cos(2π − θ) = cosθ      sin(2π − θ) = −sinθ
tan(π/2 − θ) = cotθ      tan(π/2 + θ) = −cotθ

Q.1 — Find the values of
Q1 (i) Find the value of sin 15°
Solution Write 15° as a difference of known angles : sin 15° = sin(45° − 30°) Using : sin(A − B) = sinA cosB − cosA sinB = sin 45° · cos 30° − cos 45° · sin 30° = 1√2 · √32 − 1√2 · 12 = √32√2 − 12√2 = √3 − 12√2 Rationalise: multiply and divide by √2: = (√3 − 1)√22√2 · √2 = √6 − √24 sin 15° = (√6 − √2) / 4
Q1 (ii) Find the value of cos 75°
Solution Write 75° = 45° + 30° cos 75° = cos(45° + 30°) Using : cos(A + B) = cosA cosB − sinA sinB = cos 45° · cos 30° − sin 45° · sin 30° = 1√2 · √32 − 1√2 · 12 = √32√2 − 12√2 = √3 − 12√2 = √6 − √24 ∵ cos 75° = sin 15° (complementary angles) cos 75° = (√6 − √2) / 4
Q1 (iii) Find the value of tan 105°
Solution Write 105° = 60° + 45° tan 105° = tan(60° + 45°) Using : tan(A + B) = (tanA + tanB) / (1 − tanA tanB) = tan 60° + tan 45°1 − tan 60° · tan 45° = √3 + 11 − √3 · 1 = √3 + 11 − √3 Rationalise — multiply by (1 + √3)/(1 + √3) : = (√3 + 1)(1 + √3)(1 − √3)(1 + √3) = √3 + 3 + 1 + √31 − 3 = 4 + 2√3−2 = −2 − √3 tan 105° = −(2 + √3)
Q1 (iv) Find the value of cot 225°
Solution Write 225° = 180° + 45° cot 225° = cot(180° + 45°) Using allied angle: tan(π + θ) = tanθ, so cot(π + θ) = cotθ = cot 45° = 1 cot 225° = 1
Q.2 — Prove the following
Q2 (i) Prove: cos(π/2 − x)cos(π/2 − y) − sin(π/2 − x)sin(π/2 − y) = −cos(x + y)
Solution Use allied angle results: cos(π/2 − θ) = sinθ and sin(π/2 − θ) = cosθ L.H.S. = cos(π/2 − x) · cos(π/2 − y) − sin(π/2 − x) · sin(π/2 − y) sinx · siny − cosx · cosy −(cosx cosy − sinx siny) −cos(x + y) = R.H.S. Hence proved.
Q2 (ii) Prove: tan(π/4 + θ) = (1 + tanθ) / (1 − tanθ)
Solution L.H.S. = tan(π/4 + θ) Using : tan(A + B) = (tanA + tanB) / (1 − tanA tanB) = tan(π/4) + tanθ1 − tan(π/4) · tanθ ∵ tan(π/4) = 1 : = 1 + tanθ1 − 1 · tanθ = 1 + tanθ1 − tanθ = R.H.S. Hence proved.
Q2 (iii) Prove: ((1 + tanx)/(1 − tanx))² = tan(π/4 + x) / tan(π/4 − x)
Solution R.H.S. = tan(π/4 + x)tan(π/4 − x) = (1 + tanx)/(1 − tanx)(1 − tanx)/(1 + tanx) ∵ tan(π/4 + x) = (1+tanx)/(1−tanx) and tan(π/4 − x) = (1−tanx)/(1+tanx) = 1 + tanx1 − tanx × 1 + tanx1 − tanx = (1 + tanx)²(1 − tanx)² = (1 + tanx)(1 − tanx)² = L.H.S. Hence proved.
Q2 (iv) Prove: sin[(n+1)A]·sin[(n+2)A] + cos[(n+1)A]·cos[(n+2)A] = cosA
Solution L.H.S. = sin[(n+1)A] · sin[(n+2)A] + cos[(n+1)A] · cos[(n+2)A] Using : cosP cosQ + sinP sinQ = cos(P − Q), with P = (n+2)A, Q = (n+1)A = cos[(n+2)A − (n+1)A] cos[nA + 2A − nA − A] cos A = R.H.S. Hence proved.
Q2 (v) Prove: √2 · cos(π/4 − A) = cosA + sinA
Solution L.H.S. = √2 · cos(π/4 − A) Using : cos(A − B) = cosA cosB + sinA sinB = √2 · [cos(π/4) cosA + sin(π/4) sinA] = √2 · [1√2 · cosA + 1√2 · sinA] = √2 · 1√2 · cosA + √2 · 1√2 · sinA cosA + sinA = R.H.S. Hence proved.
Q2 (vi) Prove: cos(x−y)/cos(x+y) = (cotx coty + 1)/(cotx coty − 1)
Solution L.H.S. = cos(x − y)cos(x + y) = cosx cosy + sinx sinycosx cosy − sinx siny Divide numerator and denominator by sinx siny : = (cosx cosy)/(sinx siny) + 1(cosx cosy)/(sinx siny) − 1 = (cosx/sinx)(cosy/siny) + 1(cosx/sinx)(cosy/siny) − 1 cotx · coty + 1cotx · coty − 1 = R.H.S. Hence proved.
Q2 (vii) Prove: cos(x+y)·cos(x−y) = cos²y − sin²x
Solution L.H.S. = cos(x + y) · cos(x − y) = (cosx cosy − sinx siny)(cosx cosy + sinx siny) Using (a − b)(a + b) = a² − b² with a = cosx cosy, b = sinx siny cos²x cos²y − sin²x sin²y = cos²x cos²y − sin²x sin²y = cos²x(1 − sin²y) − sin²x sin²y cos²x − cos²x sin²y − sin²x sin²y cos²x − sin²y(cos²x + sin²x) cos²x − sin²y · 1 Alternatively write as: (1 − sin²x) − sin²y ... But standard result uses cos²y: Re-write: cos²x cos²y − sin²x sin²y = cos²y(1 − sin²x) − sin²x(1 − cos²y) cos²y − cos²y sin²x − sin²x + sin²x cos²y cos²y − sin²x = R.H.S. Hence proved.
Q2 (viii) Prove: (tan5A − tan3A)/(tan5A + tan3A) = sin2A/sin8A
Solution Note that 5A − 3A = 2A and 5A + 3A = 8A L.H.S. = tan5A − tan3Atan5A + tan3A = sin5A/cos5A − sin3A/cos3Asin5A/cos5A + sin3A/cos3A = (sin5A cos3A − cos5A sin3A)/(cos5A cos3A)(sin5A cos3A + cos5A sin3A)/(cos5A cos3A) = sin5A cos3A − cos5A sin3Asin5A cos3A + cos5A sin3A Using: sin(A−B) = sinA cosB − cosA sinB and sin(A+B) = sinA cosB + cosA sinB = sin(5A − 3A)sin(5A + 3A) = sin 2Asin 8A = R.H.S. Hence proved.
Q2 (ix) Prove: tan8θ − tan5θ − tan3θ = tan8θ · tan5θ · tan3θ
Solution Key idea: 8θ = 5θ + 3θ, so tan8θ = tan(5θ + 3θ) tan 8θ = tan5θ + tan3θ1 − tan5θ · tan3θ ∴ tan8θ (1 − tan5θ tan3θ) = tan5θ + tan3θ ∴ tan8θ − tan8θ · tan5θ · tan3θ = tan5θ + tan3θ ∴ tan8θ − tan5θ − tan3θ = tan8θ · tan5θ · tan3θ Hence proved.
Q2 (x) Prove: tan50° = tan40° + 2 tan10°
Solution Write 50° = 40° + 10°, so tan50° = tan(40° + 10°) tan 50° = tan40° + tan10°1 − tan40° · tan10° ∴ tan50°(1 − tan40° tan10°) = tan40° + tan10° ∴ tan50° − tan50° · tan40° · tan10° = tan40° + tan10° ... (i) Also write 50° = 90° − 40°, so tan50° = cot40° = 1/tan40° ∴ tan50° · tan40° = 1 So : tan50° · tan40° · tan10° = tan10° Substituting in (i): tan50° − tan10° = tan40° + tan10° ∴ tan50° = tan40° + 2 tan10° Hence proved.
Q2 (xi) Prove: (cos27° + sin27°)/(cos27° − sin27°) = tan72°
Solution L.H.S. = cos27° + sin27°cos27° − sin27° Divide numerator and denominator by cos27° : = 1 + tan27°1 − tan27° Using: tan(π/4 + θ) = (1 + tanθ)/(1 − tanθ), with θ = 27° = tan(45° + 27°) tan 72° = R.H.S. Hence proved.
Q2 (xii) Prove: tan10° + tan35° + tan10° · tan35° = 1
Solution Note: 10° + 35° = 45°, so tan(10° + 35°) = tan45° = 1 tan(10° + 35°) = tan10° + tan35°1 − tan10° · tan35° = 1 ∴ tan10° + tan35° = 1 − tan10° · tan35° ∴ tan10° + tan35° + tan10° · tan35° = 1 Hence proved.
Q2 (xiii) Prove: (cotA cot4A + 1)/(cotA cot4A − 1) = cos3A/cos5A
Solution L.H.S. = cotA cot4A + 1cotA cot4A − 1 Using: cot(A − B) = (cotA cotB + 1)/(cotB − cotA) and cot(A + B) = (cotA cotB − 1)/(cotB + cotA) Numerator: cotA cot4A + 1 = cot4A cotA + 1 This matches the formula for cot(4A − A) × (cot4A − cotA) — let's use a direct approach: Multiply numerator and denominator by sinA sin4A : Numerator: cosA cos4A + sinA sin4A = cos(4A − A) = cos3A Denominator: cosA cos4A − sinA sin4A = cos(4A + A) = cos5A = cos3Acos5A = R.H.S. Hence proved.
Q2 (xiv) Prove: (cos15° − sin15°)/(cos15° + sin15°) = 1/√3
Solution L.H.S. = cos15° − sin15°cos15° + sin15° Divide numerator and denominator by cos15° : = 1 − tan15°1 + tan15° Using: tan(π/4 − θ) = (1 − tanθ)/(1 + tanθ), with θ = 15° = tan(45° − 15°) = tan 30° = 1√3 = R.H.S. Hence proved.
Q.3 — Find sin(A+B), cos(A−B), tan(A+B)
Q3 sinA = −5/13, π < A < 3π/2 and cosB = 3/5, 3π/2 < B < 2π. Find sin(A+B), cos(A−B), tan(A+B).
Solution Step 1 — Find all ratios for A : sinA = −5/13, A is in 3rd quadrant (π < A < 3π/2) → cosA is also negative cos²A = 1 − sin²A = 1 − 25/169 = 144/169 cosA = −12/13 (negative in 3rd quadrant) tanA = sinA/cosA = (−5/13)/(−12/13) = 5/12 Step 2 — Find all ratios for B : cosB = 3/5, B is in 4th quadrant (3π/2 < B < 2π) → sinB is negative sin²B = 1 − cos²B = 1 − 9/25 = 16/25 sinB = −4/5 (negative in 4th quadrant) tanB = sinB/cosB = (−4/5)/(3/5) = −4/3 Step 3 — (i) sin(A + B) : sin(A+B) = sinA cosB + cosA sinB = (−5/13)(3/5) + (−12/13)(−4/5) = −15/65 + 48/65 = 33/65 sin(A + B) = 33/65 Step 4 — (ii) cos(A − B) : cos(A−B) = cosA cosB + sinA sinB = (−12/13)(3/5) + (−5/13)(−4/5) = −36/65 + 20/65 = −16/65 cos(A − B) = −16/65 Step 5 — (iii) tan(A + B) : tan(A+B) = (tanA + tanB)/(1 − tanA tanB) = (5/12 + (−4/3)) / (1 − (5/12)(−4/3)) = (5/12 − 16/12) / (1 + 20/36) = (−11/12) / (56/36) = (−11/12) × (36/56) = −396/672 = −33/56 tan(A + B) = −33/56
Q.4 — Prove A + B = π/4
Q4 If tanA = 5/6 and tanB = 1/11, prove that A + B = π/4
Solution To prove A + B = π/4, it is sufficient to show tan(A + B) = tan(π/4) = 1 tan(A + B) = tanA + tanB1 − tanA · tanB = 5/6 + 1/111 − (5/6)(1/11) Numerator: 5/6 + 1/11 = 55/66 + 6/66 = 61/66 Denominator: 1 − 5/66 = 66/66 − 5/66 = 61/66 = 61/6661/66 = 1 ∴ tan(A + B) = 1 = tan(π/4) Since A + B is in the first quadrant, ∴ A + B = π/4. Hence proved.

📚 3.2 — Trigonometric Functions of Allied Angles
Definition

Q.2 — Prove the following
Q2 (i) Prove: [cos(π+x)·cos(−x)] / [sin(π−x)·cos(π/2+x)] = cot²x
