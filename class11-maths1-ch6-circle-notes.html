Definition of a Circle

Circle: A circle is a set of all points in a plane which are equidistant from a fixed point in the plane.
Centre: The fixed point is called the centre of the circle.
Radius: The distance from the centre to any point on the circle is called the radius.
Key terms to remember:
  • Chord: A line segment joining any two points on the circle
  • Diameter: A chord passing through the centre (= 2r)
  • Tangent: A line that touches the circle at exactly one point
  • Secant: A line that intersects the circle at two points
📐

6.1 Different Forms of Equation of a Circle

(1) Standard Form — Centre at origin O(0, 0), radius = r, point P(x, y) on circle.
OP = r → OP² = (x−0)² + (y−0)² = r²
x² + y² = r²
Standard form — Centre at origin
(2) Centre-Radius Form — Centre C(h, k), radius = r, point P(x, y) on circle.
CP = r → CP² = (x−h)² + (y−k)² = r²
(x − h)² + (y − k)² = r²
Centre-radius form | Centre C(h,k), radius r
Standard form is a special case of centre-radius form with h = 0, k = 0.
(3) Diameter Form — A(x₁, y₁) and B(x₂, y₂) are endpoints of a diameter. P(x, y) is any point on the circle.
Angle in semicircle = 90° → AP ⊥ BP → product of slopes = −1
(x − x₁)(x − x₂) + (y − y₁)(y − y₂) = 0
Diameter form | A(x₁,y₁) and B(x₂,y₂) are ends of diameter
(4) General Form — Expanding (x−h)² + (y−k)² = r²:
x² + y² + 2gx + 2fy + c = 0
General form | g = −h, f = −k, c = h² + k² − r²
From general form: Centre = (−g, −f)    Radius = √(g² + f² − c)
Condition for real circle: g² + f² − c > 0
📏

6.2 Equation of Tangent to a Circle

Tangent: A line that touches the circle at exactly one point (point of contact). The radius to the point of contact is perpendicular to the tangent.
Tangent to x² + y² = r² at point (x₁, y₁):
xx₁ + yy₁ = r²
Tangent to standard circle at point (x₁, y₁) on circle
Tangent to (x−h)² + (y−k)² = r² at point (x₁, y₁):
(x₁ − h)(x − h) + (y₁ − k)(y − k) = r²
Tangent to centre-radius form at point (x₁, y₁)
Tangent to x² + y² + 2gx + 2fy + c = 0 at point (x₁, y₁):
xx₁ + yy₁ + g(x + x₁) + f(y + y₁) + c = 0
Tangent to general form at point (x₁, y₁)
Condition for line y = mx + c to be tangent to x² + y² = r²:
c² = r²(1 + m²)    i.e.    c = ± r√(1 + m²)
Condition for tangency
Length of tangent from external point P(x₁, y₁) to circle x² + y² + 2gx + 2fy + c = 0:
Length = √(x₁² + y₁² + 2gx₁ + 2fy₁ + c)
🎯

6.3 Director Circle

Director Circle: The locus of the point from which two tangents drawn to the given circle are perpendicular to each other is called the director circle.
For circle x² + y² = r², the director circle has equation:
x² + y² = 2r²
Director circle of x² + y² = r² | Radius of director circle = r√2
The director circle is concentric with the given circle and its radius is r√2 (√2 times the original radius).
📍

6.4 Position of a Point w.r.t. Circle

For circle x² + y² = r² and point P(x₁, y₁):
ConditionPosition of Point
x₁² + y₁² < r²Point is INSIDE the circle
x₁² + y₁² = r²Point is ON the circle
x₁² + y₁² > r²Point is OUTSIDE the circle

6.5 Relative Position of Two Circles

For two circles with centres C₁, C₂ and radii r₁, r₂, let d = d(C₁C₂) = distance between centres.
ConditionPositionCommon Tangents
d > r₁ + r₂Circles are external (disjoint)4 tangents
d = r₁ + r₂Externally touching3 tangents
|r₁ − r₂| < d < r₁ + r₂Intersecting (2 common points)2 tangents
d = |r₁ − r₂|Internally touching1 tangent
d < |r₁ − r₂|One inside other0 tangents
d = 0Concentric circles0 tangents
Radical axis: The line joining the two points of intersection of two circles is called the radical axis (common chord).

Short & Long Answer Questions

1. Define a circle. What is its standard equation? ▼
A circle is a set of all points in a plane equidistant from a fixed point (centre). The fixed distance is the radius r.
Standard equation (centre at origin):
x² + y² = r²
Derivation: P(x,y) on circle, O(0,0) centre. OP = r → OP² = x² + y² = r².
2. Write the centre-radius form of a circle and derive it. ▼
For centre C(h, k) and radius r, any point P(x, y) on circle satisfies CP = r.
CP = √[(x−h)² + (y−k)²] = r
Squaring:
(x − h)² + (y − k)² = r²
This is the centre-radius form. Standard form is a special case with h = 0, k = 0.
3. Derive the diameter form of a circle. ▼
Let A(x₁,y₁) and B(x₂,y₂) be endpoints of diameter. P(x,y) is any point on circle.
Since angle in semicircle = 90°: AP ⊥ BP
Slope of AP × slope of BP = −1
[(y−y₁)/(x−x₁)] × [(y−y₂)/(x−x₂)] = −1
(y−y₁)(y−y₂) = −(x−x₁)(x−x₂)
(x−x₁)(x−x₂) + (y−y₁)(y−y₂) = 0
4. Write the general form of a circle. Find its centre and radius. ▼
General form: x² + y² + 2gx + 2fy + c = 0
Comparing with (x−h)²+(y−k)²=r²:
x²+y²−2hx−2ky+(h²+k²−r²)=0
So: 2g = −2h → h = −g; 2f = −2k → k = −f; c = h²+k²−r²
Centre = (−g, −f)
Radius = √(g² + f² − c)
Condition for real circle: g² + f² − c > 0
5. What is the equation of tangent to circle x² + y² = r² at point (x₁, y₁)? ▼
The tangent to the circle x² + y² = r² at the point (x₁, y₁) on the circle is:
xx₁ + yy₁ = r²
Note: This is obtained by replacing x² by xx₁ and y² by yy₁ in the equation of the circle.
6. State the condition for the line y = mx + c to be tangent to the circle x² + y² = r². ▼
For the line y = mx + c to be a tangent to x² + y² = r², the perpendicular distance from centre (0,0) to the line must equal r.
Distance from (0,0) to line mx − y + c = 0:
d = |c| / √(m² + 1) = r
Squaring: c² = r²(1 + m²)
So tangent: y = mx ± r√(1+m²)
7. What is a director circle? Write its equation. ▼
Director circle: The locus of a point from which two tangents drawn to the given circle are perpendicular to each other.
For circle x² + y² = r²:
x² + y² = 2r²
The director circle has the same centre as the original circle, and its radius is r√2.
8. How many common tangents can be drawn to two circles? State conditions. ▼
  • 4 tangents: d > r₁ + r₂ (circles are external/disjoint)
  • 3 tangents: d = r₁ + r₂ (circles touch externally)
  • 2 tangents: |r₁−r₂| < d < r₁+r₂ (circles intersect at 2 points)
  • 1 tangent: d = |r₁−r₂| (circles touch internally)
  • 0 tangents: d < |r₁−r₂| or d = 0 (one inside other / concentric)
9. How do you find the length of the tangent from an external point? ▼
For circle x² + y² + 2gx + 2fy + c = 0 and external point P(x₁, y₁):
Length of tangent = √(x₁² + y₁² + 2gx₁ + 2fy₁ + c)
This is the distance from the external point to the point of tangency on the circle.
10. What is the position of a point with respect to a circle? ▼
For circle x² + y² = r² and point P(x₁, y₁):
Let S₁ = x₁² + y₁² − r²
  • S₁ < 0: Point is inside the circle
  • S₁ = 0: Point is on the circle
  • S₁ > 0: Point is outside the circle

Solved Numericals

1. Find the equation of a circle with centre (3, −2) and radius 5.
Centre C(h,k) = (3, −2), r = 5
(x − h)² + (y − k)² = r²
(x − 3)² + (y − (−2))² = 5²
(x − 3)² + (y + 2)² = 25
x² − 6x + 9 + y² + 4y + 4 = 25
x² + y² − 6x + 4y + 13 − 25 = 0
x² + y² − 6x + 4y − 12 = 0
2. Find the centre and radius of the circle x² + y² − 6x + 4y − 12 = 0.
x² + y² − 6x + 4y − 12 = 0 → comparing with x²+y²+2gx+2fy+c=0
2g = −6 → g = −3
2f = 4 → f = 2
c = −12
Centre = (−g, −f) = (3, −2)
Radius = √(g²+f²−c) = √(9+4+12) = √25 = 5
Centre = (3, −2) | Radius = 5
3. Find the equation of a circle with diameter endpoints A(1, 2) and B(5, 6).
A(x₁,y₁) = (1,2), B(x₂,y₂) = (5,6)
Using diameter form:
(x−x₁)(x−x₂) + (y−y₁)(y−y₂) = 0
(x−1)(x−5) + (y−2)(y−6) = 0
x²−6x+5 + y²−8y+12 = 0
x² + y² − 6x − 8y + 17 = 0
4. Find the equation of tangent to circle x² + y² = 25 at point (3, 4).
Circle: x²+y²=25 (r=5), Point (x₁,y₁) = (3,4)
First check: 3²+4² = 9+16 = 25 ✓ (point is on circle)
Tangent: xx₁ + yy₁ = r²
x(3) + y(4) = 25
3x + 4y = 25
5. Show that the line y = x + 2 is a tangent to the circle x² + y² = 2. Find the point of tangency.
Line: y = x + 2 (m=1, c=2), Circle: x²+y²=2 (r=√2)
Condition for tangency: c² = r²(1+m²)
LHS: c² = (2)² = 4
RHS: r²(1+m²) = 2(1+1) = 4
LHS = RHS ✓ → Line is tangent
Point of contact: substitute y = x+2 in x²+y²=2
x² + (x+2)² = 2 → 2x²+4x+4=2 → 2x²+4x+2=0 → x²+2x+1=0 → (x+1)²=0 → x=−1
y = −1+2 = 1
Tangent confirmed | Point of contact = (−1, 1)
6. Find the length of the tangent drawn from point (5, 4) to the circle x² + y² − 4x − 6y + 3 = 0.
Point P(x₁,y₁) = (5,4), Circle: x²+y²−4x−6y+3=0
Length = √(x₁²+y₁²+2gx₁+2fy₁+c)
Here: 2g=−4→g=−2, 2f=−6→f=−3, c=3
Substituting P(5,4):
= √(25+16+(−4)(5)+(−6)(4)+3)
= √(25+16−20−24+3)
= √0 = 0
Length = 0 → Point (5,4) lies ON the circle
7. Find the equation of the director circle of x² + y² = 9.
Circle: x²+y²=9, so r²=9, r=3
Director circle: x²+y² = 2r²
x²+y² = 2×9 = 18
x² + y² = 18 (radius = 3√2)
