Q 1 Operations on Complex Numbers ⭐ Most IMP Addition · Multiplication · Division
(i) If z₁ = 2 + 3i and z₂ = 1 − 2i, find z₁ + z₂, z₁ − z₂, z₁ · z₂
Given z₁ = 2 + 3i    z₂ = 1 − 2i Addition z₁ + z₂ = (2+1) + (3+(−2))i = 3 + i Subtraction z₁ − z₂ = (2−1) + (3−(−2))i = 1 + 5i Multiplication z₁ · z₂ = (2+3i)(1−2i) = 2(1) + 2(−2i) + 3i(1) + 3i(−2i) = 2 − 4i + 3i − 6i² = 2 − i − 6(−1)    [∵ i² = −1] = 2 − i + 6 = 8 − i ∴ z₁+z₂ = 3+i  |  z₁−z₂ = 1+5i  |  z₁·z₂ = 8−i
(ii) Find z₁/z₂ if z₁ = 4 + 3i, z₂ = 2 − i
Method Multiply numerator & denominator by conjugate of z₂ Step 1 z₁/z₂ = (4+3i)/(2−i) Step 2 = (4+3i)(2+i) / [(2−i)(2+i)] Step 3 Denominator = 2² + 1² = 4 + 1 = 5 Step 4 Numerator = 8 + 4i + 6i + 3i² = 8 + 10i − 3 = 5 + 10i Step 5 = (5 + 10i)/5 = 1 + 2i ∴ z₁/z₂ = 1 + 2i
(iii) Express (3 + 2i)(2 − 5i) in a + bi form.
Step 1 = 3(2) + 3(−5i) + 2i(2) + 2i(−5i) Step 2 = 6 − 15i + 4i − 10i² Step 3 = 6 − 11i − 10(−1) Step 4 = 6 − 11i + 10 = 16 − 11i ∴ (3+2i)(2−5i) = 16 − 11i
Q 2 Find Modulus and Argument (Amplitude) ⭐ Most IMP |z| and arg(z)
(i) z = 1 + i√3
Given z = 1 + i√3    a = 1, b = √3 Formulae |z| = √(a²+b²)    arg(z) = tan⁻¹(b/a) adjusted for quadrant Modulus Step 1 |z| = √(1² + (√3)²) = √(1+3) = √4 = 2 |z| = 2 Argument Step 2 a = 1 > 0, b = √3 > 0 → 1st quadrant Step 3 arg(z) = tan⁻¹(√3/1) = tan⁻¹(√3) = π/3 = 60° arg(z) = π/3 (60°)
(ii) z = −√3 + i
Given a = −√3, b = 1 Modulus Step 1 |z| = √((−√3)² + 1²) = √(3+1) = √4 = 2 |z| = 2 Argument Step 2 a < 0, b > 0 → 2nd quadrant Step 3 Reference angle α = tan⁻¹(1/√3) = π/6 Step 4 arg(z) = π − π/6 = 5π/6 arg(z) = 5π/6 (150°)
(iii) z = −2 − 2i
Given a = −2, b = −2 Modulus Step 1 |z| = √(4+4) = √8 = 2√2 |z| = 2√2 Argument Step 2 a < 0, b < 0 → 3rd quadrant Step 3 α = tan⁻¹(2/2) = tan⁻¹(1) = π/4 Step 4 arg(z) = −(π − π/4) = −3π/4 arg(z) = −3π/4 (−135°)
Q 3 Conjugate of Complex Numbers and Properties ⭐ IMP Conjugate
(i) Find conjugate of z = (3+4i)/(2−3i)
Step 1 Simplify z first: multiply by conjugate of denominator Step 2 = (3+4i)(2+3i) / [(2−3i)(2+3i)] Step 3 Denominator = 4 + 9 = 13 Step 4 Numerator = 6+9i+8i+12i² = 6+17i−12 = −6+17i Step 5 z = (−6+17i)/13 = −6/13 + 17i/13 Step 6 z̄ = −6/13 − 17i/13 ∴ z̄ = −6/13 − 17i/13
(ii) Prove: z · z̄ = |z|² for z = 3 − 4i
Given z = 3 − 4i    z̄ = 3 + 4i LHS z · z̄ = (3−4i)(3+4i) Step 1 = 3² − (4i)² = 9 − 16i² = 9 + 16 = 25 RHS |z|² = (√(9+16))² = 25 ∴ z · z̄ = |z|² = 25   Proved ✓
Q 4 Find the square root of the complex number. ⭐ Most IMP √z
(i) Find √(3 + 4i)
Method Let √(a+bi) = x+iy  →  (x+iy)² = a+bi Step 1 Let √(3+4i) = x + iy Step 2 (x+iy)² = 3+4i Step 3 x² − y² = 3     ...(1)    [real parts] 2xy = 4         ...(2)    [imaginary parts] Step 4 |z|² = x² + y² = √(3²+4²) = √25 = 5    ...(3) Step 5 From (1)+(3): 2x² = 8  →  x² = 4  →  x = ±2 Step 6 From (3)−(1): 2y² = 2  →  y² = 1  →  y = ±1 Step 7 From (2): 2xy = 4 → xy > 0 → same sign ∴ x = 2, y = 1  or  x = −2, y = −1 ∴ √(3+4i) = 2+i  or  −(2+i)
(ii) Find √(−5 + 12i)
Step 1 Let √(−5+12i) = x + iy Step 2 x² − y² = −5    ...(1) 2xy = 12        ...(2) Step 3 x² + y² = √(25+144) = √169 = 13    ...(3) Step 4 From (1)+(3): 2x² = 8 → x = ±2 Step 5 From (3)−(1): 2y² = 18 → y = ±3 Step 6 2xy = 12 > 0 → x and y same sign ∴ x = 2, y = 3  or  x = −2, y = −3 ∴ √(−5+12i) = 2+3i  or  −(2+3i)
Q 5 Express in Polar (Trigonometric) Form: z = r(cosθ + i sinθ) ⭐ Most IMP Polar Form
(i) z = 1 + i
Given z = 1 + i    a = 1, b = 1 Polar form z = r(cosθ + i sinθ)    where r = |z|, θ = arg(z) Step 1 r = |z| = √(1²+1²) = √2 Step 2 a > 0, b > 0 → 1st quadrant Step 3 θ = tan⁻¹(1/1) = tan⁻¹(1) = π/4 Step 4 z = √2(cos π/4 + i sin π/4) ∴ Polar form = √2(cos 45° + i sin 45°)
(ii) z = √3 − i
Given a = √3, b = −1 Step 1 r = √(3+1) = 2 Step 2 a > 0, b < 0 → 4th quadrant Step 3 α = tan⁻¹(1/√3) = π/6 Step 4 θ = −π/6 Step 5 z = 2(cos(−π/6) + i sin(−π/6)) ∴ z = 2(cos 330° + i sin 330°)
Q 6 Evaluate powers of i. ⭐ IMP Powers of i
(i) Evaluate i³⁵ + i⁴⁰ + i⁴⁹ + i⁵⁸
Rule i¹=i, i²=−1, i³=−i, i⁴=1 (cycle of 4) Method Divide power by 4, use remainder: 0→1, 1→i, 2→−1, 3→−i i³⁵ 35 = 4×8 + 3 → remainder 3 → i³ = −i i⁴⁰ 40 = 4×10 + 0 → remainder 0 → i⁰ = 1 i⁴⁹ 49 = 4×12 + 1 → remainder 1 → i¹ = i i⁵⁸ 58 = 4×14 + 2 → remainder 2 → i² = −1 Sum = −i + 1 + i + (−1) = 0 ∴ i³⁵ + i⁴⁰ + i⁴⁹ + i⁵⁸ = 0
(ii) Find the value of (1 + i)⁴
Step 1 (1+i)² = 1 + 2i + i² = 1 + 2i − 1 = 2i Step 2 (1+i)⁴ = [(1+i)²]² = (2i)² = 4i² = 4(−1) = −4 ∴ (1+i)⁴ = −4
(iii) Show that (1+i/1−i)² = −1
Step 1 (1+i)/(1−i) × (1+i)/(1+i) = (1+i)²/(1²+1²) Step 2 = (1+2i+i²)/2 = (1+2i−1)/2 = 2i/2 = i Step 3 (1+i/1−i)² = i² = −1 ∴ (1+i/1−i)² = −1   Proved ✓

Q 7 Arithmetic Progression (AP) — nth term ⭐ Most IMP AP: tₙ = a + (n−1)d
(i) Find the 15th term of AP: 3, 7, 11, 15, ...
Given a = 3    d = 7−3 = 4    n = 15 Formula tₙ = a + (n−1)d Step 1 t₁₅ = 3 + (15−1)(4) Step 2 = 3 + 14 × 4 = 3 + 56 = 59 ∴ 15th term = 59
(ii) Which term of AP 5, 8, 11, ... is 320?
Given a = 5    d = 3    tₙ = 320 Step 1 tₙ = a + (n−1)d Step 2 320 = 5 + (n−1)(3) Step 3 315 = (n−1)(3) Step 4 n−1 = 105    n = 106 ∴ 320 is the 106th term
(iii) Find the AP whose 3rd term is 7 and 7th term is 15.
Given t₃ = 7    t₇ = 15 Step 1 t₃ = a + 2d = 7    ...(1) Step 2 t₇ = a + 6d = 15   ...(2) Step 3 (2)−(1): 4d = 8  →  d = 2 Step 4 From (1): a + 4 = 7  →  a = 3 ∴ AP: 3, 5, 7, 9, 11, ... (a=3, d=2)
Q 8 Sum of n Terms of AP ⭐ Most IMP Sₙ = n/2[2a+(n−1)d]
(i) Find the sum of first 20 terms of AP: 2, 5, 8, ...
Given a = 2    d = 3    n = 20 Formula Sₙ = n/2 × [2a + (n−1)d] Step 1 S₂₀ = 20/2 × [2(2) + (20−1)(3)] Step 2 = 10 × [4 + 57] Step 3 = 10 × 61 = 610 ∴ S₂₀ = 610
(ii) The sum of n terms of an AP is 3n² + 2n. Find the AP and common difference.
Given Sₙ = 3n² + 2n Step 1 t₁ = S₁ = 3(1)² + 2(1) = 5 Step 2 t₂ = S₂ − S₁ = [3(4)+4] − 5 = 16 − 5 = 11 Step 3 t₃ = S₃ − S₂ = [3(9)+6] − 16 = 33 − 16 = 17 Step 4 d = t₂ − t₁ = 11 − 5 = 6 Note tₙ = Sₙ − Sₙ₋₁ = (3n²+2n) − [3(n−1)²+2(n−1)] = 6n − 1 ∴ AP: 5, 11, 17, ... (a=5, d=6)  |  tₙ = 6n−1
(iii) How many terms of AP 9, 17, 25, ... give a sum of 636?
Given a = 9    d = 8    Sₙ = 636 Step 1 Sₙ = n/2[2a + (n−1)d] Step 2 636 = n/2[18 + 8(n−1)] Step 3 636 = n/2[8n + 10] Step 4 636 = n(4n + 5) Step 5 4n² + 5n − 636 = 0 Step 6 n = [−5 ± √(25 + 10176)] / 8 = [−5 ± √10201] / 8 = [−5 ± 101] / 8 Step 7 n = 96/8 = 12    (taking positive value) ∴ n = 12 terms
Q 9 Geometric Progression (GP) — nth term and Sum ⭐ Most IMP GP: tₙ = arⁿ⁻¹
(i) Find the 8th term of GP: 3, 6, 12, 24, ...
Given a = 3    r = 6/3 = 2    n = 8 Formula tₙ = a · rⁿ⁻¹ Step 1 t₈ = 3 × 2⁷ = 3 × 128 = 384 ∴ 8th term = 384
(ii) Find the sum of first 6 terms of GP: 2, 6, 18, 54, ...
Given a = 2    r = 3    n = 6 Formula Sₙ = a(rⁿ − 1)/(r − 1)    for r ≠ 1 Step 1 S₆ = 2(3⁶ − 1)/(3 − 1) Step 2 = 2(729 − 1)/2 = 728 ∴ S₆ = 728
(iii) The 3rd term of GP is 4 and 6th term is 32. Find the GP.
Given t₃ = 4    t₆ = 32 Step 1 t₃ = ar² = 4     ...(1) Step 2 t₆ = ar⁵ = 32    ...(2) Step 3 (2)÷(1): r³ = 8  →  r = 2 Step 4 From (1): a(4) = 4  →  a = 1 ∴ GP: 1, 2, 4, 8, 16, 32, ... (a=1, r=2)
Q 10 Sum to Infinity of GP ⭐ Most IMP S∞ = a/(1−r)
(i) Find S∞ of GP: 1, 1/3, 1/9, ...
Given a = 1    r = 1/3    |r| < 1 ✓ Formula S∞ = a/(1−r) Step 1 S∞ = 1/(1 − 1/3) = 1/(2/3) = 3/2 ∴ S∞ = 3/2
(ii) Express 0.7̄ = 0.7777... as a fraction using infinite GP.
Step 1 0.7̄ = 0.7 + 0.07 + 0.007 + ... Step 2 a = 7/10    r = 1/10 Step 3 S∞ = (7/10)/(1 − 1/10) = (7/10)/(9/10) = 7/9 ∴ 0.7̄ = 7/9
(iii) If S∞ = 3 and a = 1, find the common ratio r.
Given S∞ = 3    a = 1 Step 1 3 = 1/(1−r) Step 2 1 − r = 1/3 Step 3 r = 1 − 1/3 = 2/3 ∴ r = 2/3
Q 11 Arithmetic Mean (AM), Geometric Mean (GM) and AM ≥ GM ⭐ IMP AM · GM
(i) Insert 3 arithmetic means between 3 and 19.
Given a = 3    b = 19    n = 3 AMs to insert Formula d = (b−a)/(n+1) Step 1 d = (19−3)/(3+1) = 16/4 = 4 Step 2 A₁ = 3+4 = 7 Step 3 A₂ = 7+4 = 11 Step 4 A₃ = 11+4 = 15 ∴ 3 AMs are: 7, 11, 15  |  AP: 3, 7, 11, 15, 19
(ii) Insert 2 geometric means between 4 and 256.
Given a = 4    b = 256    n = 2 GMs Formula r = (b/a)^(1/(n+1)) Step 1 r = (256/4)^(1/3) = (64)^(1/3) = 4 Step 2 G₁ = ar = 4 × 4 = 16 Step 3 G₂ = ar² = 4 × 16 = 64 ∴ 2 GMs are: 16, 64  |  GP: 4, 16, 64, 256
(iii) Prove AM ≥ GM for two positive numbers a and b.
Given a, b > 0    AM = (a+b)/2    GM = √(ab) Step 1 AM − GM = (a+b)/2 − √(ab) Step 2 = (a + b − 2√(ab)) / 2 Step 3 = (√a − √b)² / 2 ≥ 0    [∵ square is always ≥ 0] Step 4 ∴ AM − GM ≥ 0 → AM ≥ GM Equality holds when a = b ∴ AM ≥ GM   Proved ✓
Q 12 Special Series — Σn, Σn², Σn³ ⭐ Most IMP Sum Formulae
(i) Find: 1² + 2² + 3² + ... + 10²
Formula Σn² = n(n+1)(2n+1)/6 Step 1 = 10(11)(21)/6 Step 2 = 10 × 11 × 21 / 6 = 2310/6 = 385 ∴ 1²+2²+...+10² = 385
(ii) Find: 1³ + 2³ + 3³ + ... + n³ for n = 5
Formula Σn³ = [n(n+1)/2]² Step 1 = [5(6)/2]² = [15]² = 225 ∴ 1³+2³+3³+4³+5³ = 225 Verify 1+8+27+64+125 = 225 ✓
(iii) Find the sum: 1·2 + 2·3 + 3·4 + ... + n(n+1)
Step 1 Σr(r+1) = Σ(r² + r) = Σr² + Σr Step 2 = n(n+1)(2n+1)/6 + n(n+1)/2 Step 3 = n(n+1)/6 × [(2n+1) + 3] Step 4 = n(n+1)(2n+4)/6 Step 5 = n(n+1) × 2(n+2)/6 = n(n+1)(n+2)/3 ∴ Σr(r+1) = n(n+1)(n+2)/3
(iv) Find the sum of series: 3 + 33 + 333 + ... to n terms
Step 1 Sₙ = 3(1 + 11 + 111 + ...) Step 2 = (3/9)(9 + 99 + 999 + ...) Step 3 = (1/3)[(10−1) + (10²−1) + ... + (10ⁿ−1)] Step 4 = (1/3)[(10+10²+...+10ⁿ) − n] Step 5 = (1/3)[10(10ⁿ−1)/9 − n] ∴ Sₙ = 10(10ⁿ−1)/27 − n/3
