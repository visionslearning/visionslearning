Q.1 — All 8 MCQ Answers
Select the correct alternative — all answers with explanations:
Probability P(A∩B) = P(A)P(B) for independent events  |  P(A∪B) = P(A)+P(B)−P(A∩B) For mutually exclusive: P(A∩B) = 0 → P(A∪B) = P(A)+P(B) P(A|B) = P(A∩B)/P(B)   (Conditional probability)
Distributions Binomial B(n,p): Mean = np, Variance = npq  |  Poisson: Mean = Variance = λ Normal N(0,1): mean=0, SD=1, P(Z<0) = 0.5, symmetric about 0
Regression b_yx = r·σy/σx  |  b_xy = r·σx/σy  |  r = ±√(b_yx × b_xy) Both regression lines pass through (x̄, ȳ). b_yx = slope in y on x.
LPP Optimal value occurs at corner point of feasible region. Bounded feasible region → both max and min exist. Feasible region = set of all points satisfying ALL constraints.
Time Series Trend (T): long-term. Seasonal (S): within 1 year. Cyclical (C): multi-year. Irregular (I): random. Additive: Y = T+S+C+I  |  Multiplicative: Y = T×S×C×I
Index Numbers Laspeyre's L = (Σp₁q₀/Σp₀q₀)×100   (base year quantities q₀) Paasche's P = (Σp₁q₁/Σp₀q₁)×100   (current year quantities q₁) Fisher's F = √(L×P)   (satisfies time reversal + factor reversal tests)

Q.3 (v) [3 Marks]
Calculate Karl Pearson's r: x: 2,4,6,8,10; y: 5,7,9,8,11.
Solution x̄ = 6, ȳ = 8 Σ(x−x̄)² = 4+4+0+4+16 = 40  |  Σ(y−ȳ)² = 9+1+1+0+9 = 20  |  Σ(x−x̄)(y−ȳ) = 6+2+0+0+12 = 20 r = Σ(x−x̄)(y−ȳ)/√[Σ(x−x̄)²·Σ(y−ȳ)²] = 20/√(40×20) = 20/√800 = 20/28.28
Answer
r ≈ 0.707 (strong positive correlation)

Section D — Long Answers 5 × 4 = 20 Marks
Q.4 (i) [4 Marks]
State and prove the addition theorem of probability. Find P(sum=8 OR divisible by 3) when two dice are thrown.
Venn diagram: A∪B includes overlap A∩B which must be subtracted once
Theorem
P(A∪B) = P(A) + P(B) − P(A∩B)
Proof A∪B = A ∪ (B−A). Since A and (B−A) are mutually exclusive: P(A∪B) = P(A) + P(B−A) = P(A) + P(B)−P(A∩B) ✓
Numerical Sum=8: (2,6)(3,5)(4,4)(5,3)(6,2) = 5/36 Sum divisible by 3 (3,6,9,12): 12/36 Both (sum=12, div by 3): (6,6) = 1/36 P = 5/36 + 12/36 − 1/36 = 16/36 = 4/9
Q.4 (ii) [4 Marks]
(a) State Bayes' theorem. (b) Three bags: A has 2R3B, B has 4R1B, C has 3R2B. One ball drawn is red. Find P(from bag A).
Probability tree: Bayes' theorem finds posterior probability from prior and likelihood
Bayes' TheoremP(Aᵢ|B) = P(B|Aᵢ)·P(Aᵢ) / [P(B|A₁)P(A₁)+P(B|A₂)P(A₂)+P(B|A₃)P(A₃)]
Numerical P(each bag) = 1/3. P(R|A)=2/5, P(R|B)=4/5, P(R|C)=3/5 P(R) = (1/3)(2/5)+(1/3)(4/5)+(1/3)(3/5) = (2+4+3)/15 = 9/15 = 3/5 P(A|R) = (2/5 × 1/3)/(3/5) = (2/15)/(9/15) = 2/9
Answer
P(from bag A | red ball drawn) = 2/9
Q.4 (v) [4 Marks]
(a) Find both regression lines: n=5, Σx=30, Σy=40, Σx²=220, Σy²=340, Σxy=262. (b) Find r.
Regression line y on x: passes through (x̄,ȳ), slope = b_yx
Givenx̄ = 30/5 = 6, ȳ = 40/5 = 8
b_yx b_yx = (262−5×6×8)/(220−5×36) = 22/40 = 0.55 y on x: y − 8 = 0.55(x − 6) → y = 0.55x + 4.7
b_xy b_xy = 22/(340−5×64) = 22/20 = 1.1 x on y: x − 6 = 1.1(y − 8) → x = 1.1y − 2.8
r and Answer
y = 0.55x + 4.7  |  x = 1.1y − 2.8  |  r = √(0.55×1.1) = √0.605 ≈ 0.778
