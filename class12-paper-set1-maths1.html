SECTION A — MCQ Solutions 8 × 1 = 8
(i) A² where A = [[1,2],[0,1]]
Answer: (A) [[1,4],[0,1]]
A² = A × A = [[1,2],[0,1]] × [[1,2],[0,1]] Row 1 × Col 1: 1×1 + 2×0 = 1 Row 1 × Col 2: 1×2 + 2×1 = 4 Row 2 × Col 1: 0×1 + 1×0 = 0 Row 2 × Col 2: 0×2 + 1×1 = 1 A² = [[1, 4], [0, 1]]
(ii) tan⁻¹(√3) + cot⁻¹(√3)
Answer: (B) π/2
tan⁻¹(x) + cot⁻¹(x) = π/2 for all x > 0 (standard identity) Here x = √3: tan⁻¹(√3) + cot⁻¹(√3) = π/2
(iii) Slope perpendicular to 3x − 4y + 7 = 0
Answer: (B) −4/3
Given line: 3x − 4y + 7 = 0 → y = (3/4)x + 7/4 Slope of given line m₁ = 3/4 Slope of perpendicular line m₂ = −1/m₁ = −4/3 m₂ = −4/3
(iv) d/dx(sin²x)
Answer: (C) sin2x
Let y = sin²x. Using chain rule: dy/dx = 2sinx · cosx = sin2x d/dx(sin²x) = sin 2x
(v) ∫ cos²x dx
Answer: (C) x/2 + sin2x/4 + c
cos²x = (1 + cos2x)/2 ∫ cos²x dx = ∫ (1 + cos2x)/2 dx x/2 + sin2x/4 + c x/2 + sin2x/4 + c
(vi) Order of (d²y/dx²)³ + dy/dx = x
Answer: (B) 2
Order = highest order derivative present = d²y/dx² → order = 2 The cube applies to the derivative, not the order. Degree = 3 but order = 2.
(vii) |a⃗| where a⃗ = 3î + 4ĵ
Answer: (A) 5
|a⃗| = √(3² + 4²) = √(9 + 16) = √25 = 5
(viii) Direction cosines of Y-axis
Answer: (B) (0, 1, 0)
Y-axis makes: α = 90° with X-axis, β = 0° with Y-axis, γ = 90° with Z-axis l = cos90° = 0, m = cos0° = 1, n = cos90° = 0 Direction cosines = (0, 1, 0)
SECTION B — Solutions (2 marks each) Any 8
(i) Find 2A − B where A = [[2,3],[1,4]], B = [[1,−1],[2,0]]
2A = [[4,6],[2,8]] 2A − B = [[4−1, 6−(−1)],[2−2, 8−0]] 2A − B = [[3, 7],[0, 8]]
(ii) Prove: 2tan⁻¹(1/3) + tan⁻¹(1/7) = π/4
First: 2tan⁻¹(1/3) = tan⁻¹(2×(1/3)/(1−(1/3)²)) = tan⁻¹(2/3 ÷ 8/9) = tan⁻¹(3/4) Now: tan⁻¹(3/4) + tan⁻¹(1/7) = tan⁻¹((3/4 + 1/7)/(1 − 3/28)) tan⁻¹((21/28 + 4/28)/(28/28 − 3/28)) = tan⁻¹(25/28 ÷ 25/28) tan⁻¹(1) = π/4 2tan⁻¹(1/3) + tan⁻¹(1/7) = π/4 ✓
(iii) Equation of line: slope = −2, y-intercept = 5
Using slope-intercept form: y = mx + c y = −2x + 5 y = −2x + 5 or 2x + y − 5 = 0
(iv) Differentiate y = x³·eˣ
Product rule: d(uv)/dx = u·dv/dx + v·du/dx u = x³, du/dx = 3x²;   v = eˣ, dv/dx = eˣ dy/dx = x³·eˣ + eˣ·3x² dy/dx = eˣ(x³ + 3x²) = x²eˣ(x + 3)
(v) Evaluate ∫(3x² + 2x + 1) dx
= ∫3x² dx + ∫2x dx + ∫1 dx 3x³/3 + 2x²/2 + x + c = x³ + x² + x + c
(vi) dy/dx when x² + y² = 25
Differentiating implicitly with respect to x: 2x + 2y·(dy/dx) = 0 2y·(dy/dx) = −2x dy/dx = −x/y
(vii) Evaluate ∫₀^(π/2) cosx dx
∫₀^(π/2) cosx dx = [sinx]₀^(π/2) sin(π/2) − sin(0) = 1 − 0 = 1
(viii) Area bounded by y = 2x, x-axis, x = 0 to x = 3
Area = ∫₀³ 2x dx [x²]₀³ = 9 − 0 = 9 Area = 9 sq. units
(ix) Solve: dy/dx = (x+1)/(y+1)
Separating variables: (y+1)dy = (x+1)dx Integrating: ∫(y+1)dy = ∫(x+1)dx y²/2 + y = x²/2 + x + c y² + 2y = x² + 2x + C
(x) a⃗ + b⃗ and |a⃗ + b⃗|
a⃗ + b⃗ = (1+2)î + (2−1)ĵ + (−1+3)k̂ = 3î + ĵ + 2k̂ |a⃗ + b⃗| = √(9 + 1 + 4) = √14 a⃗ + b⃗ = 3î + ĵ + 2k̂, |a⃗ + b⃗| = √14
(xi) Angle between lines with slopes 1 and −1
tanθ = |(m₁ − m₂)/(1 + m₁m₂)| = |(1 − (−1))/(1 + (1)(−1))| = |2/0| This is undefined → tanθ → ∞ → θ = 90° Angle = 90° (lines are perpendicular)
(xii) Rolle's theorem for f(x) = x² − 5x + 4 on [1,4]
f(x) = x² − 5x + 4 is a polynomial → continuous on [1,4] and differentiable on (1,4) ✓ f(1) = 1 − 5 + 4 = 0; f(4) = 16 − 20 + 4 = 0; f(1) = f(4) = 0 ✓ All three conditions satisfied. ∃ c ∈ (1,4) such that f'(c) = 0 f'(x) = 2x − 5 = 0 → x = 5/2 = 2.5 ∈ (1,4) ✓ c = 5/2 — Rolle's theorem verified ✓
SECTION C — Solutions (3 marks each) Any 8
(i) Matrix method: 2x + y = 5, x + 3y = 10
Matrix form: AX = B where A = [[2,1],[1,3]], X = [[x],[y]], B = [[5],[10]] |A| = 6 − 1 = 5 ≠ 0 → unique solution exists A⁻¹ = (1/5)[[3,−1],[−1,2]] X = A⁻¹B = (1/5)[[3,−1],[−1,2]] × [[5],[10]] = (1/5)[[15−10],[−5+20]] = (1/5)[[5],[15]] x = 1, y = 3
(ii) Area of triangle with vertices (1,2), (3,4), (5,0)
Area = (1/2)|x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)| = (1/2)|1(4−0) + 3(0−2) + 5(2−4)| (1/2)|4 − 6 − 10| = (1/2)|−12| = 6 Area = 6 sq. units
(iii) Prove: tan⁻¹x + tan⁻¹(1/x) = π/2 for x > 0
Let tan⁻¹x = θ → tanθ = x (x > 0, so θ ∈ (0, π/2)) Then tan⁻¹(1/x) = tan⁻¹(1/tanθ) = tan⁻¹(cotθ) = tan⁻¹(tan(π/2 − θ)) = π/2 − θ ∴ tan⁻¹x + tan⁻¹(1/x) = θ + (π/2 − θ) = π/2 ✓
(iv) Circle with centre (3,−4), radius 5
Equation: (x − h)² + (y − k)² = r² (x − 3)² + (y − (−4))² = 5² (x − 3)² + (y + 4)² = 25 Expanding: x² − 6x + 9 + y² + 8y + 16 = 25 x² + y² − 6x + 8y = 0   or   (x−3)² + (y+4)² = 25
(v) y = √(sinx + √(sinx + ... ∞)), find dy/dx
Since the expression is infinite: y = √(sinx + y) Squaring: y² = sinx + y Differentiating: 2y·(dy/dx) = cosx + dy/dx (2y − 1)·dy/dx = cosx dy/dx = cosx/(2y − 1)
(vi) dy/dx if y = x^(log x)
Take log: log y = log x · log x = (log x)² Differentiate: (1/y)(dy/dx) = 2 log x · (1/x) dy/dx = y · (2 log x / x) dy/dx = x^(logx) · (2 log x / x)
(vii) Approximate value of √26 using differentials
Let f(x) = √x, x = 25, Δx = 1 f'(x) = 1/(2√x) → f'(25) = 1/10 Δf ≈ f'(x)·Δx = (1/10)×1 = 0.1 √26 ≈ f(25) + Δf = 5 + 0.1 √26 ≈ 5.1
(viii) ∫ (2x+1)/(x²+x+1) dx
Note: d/dx(x²+x+1) = 2x+1 — the numerator is the derivative of denominator! ∫ (2x+1)/(x²+x+1) dx = log|x²+x+1| + c = log|x² + x + 1| + c
(ix) ∫ x²eˣ dx (integration by parts twice)
First IBP: u = x², dv = eˣdx → du = 2x dx, v = eˣ x²eˣ − ∫ 2xeˣ dx Second IBP: ∫ 2xeˣ dx: u=2x, dv=eˣdx → 2xeˣ − ∫ 2eˣ dx = 2xeˣ − 2eˣ ∫ x²eˣ dx = x²eˣ − (2xeˣ − 2eˣ) + c = eˣ(x² − 2x + 2) + c
(x) Area between y = x² and y = x
Intersections: x² = x → x(x−1) = 0 → x = 0, x = 1 On [0,1]: y = x is above y = x² Area = ∫₀¹ (x − x²) dx = [x²/2 − x³/3]₀¹ 1/2 − 1/3 = 1/6 Area = 1/6 sq. units
(xi) Solve: (x + y) dy/dx = 1
Rewrite: dx/dy = x + y dx/dy − x = y — this is linear in x with P = −1, Q = y IF = e^(∫−1 dy) = e⁻ʸ x·e⁻ʸ = ∫y·e⁻ʸ dy = −ye⁻ʸ − e⁻ʸ + c (IBP) x = −y − 1 + ceʸ x + y + 1 = ceʸ
SECTION D — Solutions (4 marks each) Any 5
(i) Cramer's Rule: x−y+z=4, x+y+z=2, 2x+y−3z=0
D = |[1,−1,1],[1,1,1],[2,1,−3]| = 1(1×(−3)−1×1) − (−1)(1×(−3)−1×2) + 1(1×1−1×2) 1(−4) + 1(−5) + 1(−1) = −4−5−1 = −10 Dx = |[4,−1,1],[2,1,1],[0,1,−3]| 4(−3−1)−(−1)(−6−0)+1(2−0) = 4(−4)+1(−6)+2 = −16−6+2 = −20 Dy = |[1,4,1],[1,2,1],[2,0,−3]| 1(−6−0)−4(−3−2)+1(0−4) = −6+20−4 = 10 Dz = |[1,−1,4],[1,1,2],[2,1,0]| 1(0−2)−(−1)(0−4)+4(1−2) = −2−4−4 = −10 x = Dx/D = −20/−10 = 2; y = Dy/D = 10/−10 = −1; z = Dz/D = −10/−10 = 1 x = 2, y = −1, z = 1
(iii) Evaluate ∫₀^π x/(1 + sinx) dx
Let I = ∫₀^π x/(1+sinx) dx Using property ∫₀^a f(x)dx = ∫₀^a f(a−x)dx with a = π: I = ∫₀^π (π−x)/(1+sin(π−x)) dx = ∫₀^π (π−x)/(1+sinx) dx Adding: 2I = π ∫₀^π 1/(1+sinx) dx Multiply by (1−sinx)/(1−sinx): ∫ (1−sinx)/cos²x dx = ∫(sec²x − secx·tanx) dx [tanx − secx]₀^π = (0−(−1)) − (0−1) = 1+1 = 2 2I = π×2 = 2π → I = π I = π
(iv) Area between y = x²−4 and y = 2−x
Intersections: x²−4 = 2−x → x²+x−6 = 0 → (x+3)(x−2) = 0 → x = −3, x = 2 On [−3,2]: y = 2−x is above y = x²−4 Area = ∫₋₃² [(2−x) − (x²−4)] dx = ∫₋₃² (6−x−x²) dx [6x − x²/2 − x³/3]₋₃² (12 − 2 − 8/3) − (−18 − 9/2 + 9) = 22/3 − (−27/2) 22/3 + 27/2 = 44/6 + 81/6 = 125/6 Area = 125/6 sq. units
(vii) Window optimization: rectangle + semicircle, perimeter = 30 m
Let width = 2r (so radius of semicircle = r), height of rectangle = h Perimeter = 2h + 2r + πr = 30 (bottom 2r, two sides 2h, semicircle πr) → h = (30 − 2r − πr)/2 = 15 − r − πr/2 Area = 2rh + πr²/2 2r(15 − r − πr/2) + πr²/2 30r − 2r² − πr² + πr²/2 = 30r − 2r² − πr²/2 dA/dr = 30 − 4r − πr = 0 → r = 30/(4+π) d²A/dr² = −4 − π < 0 → maximum r = 30/(4+π) ≈ 4.2 m; h = 15 − r − πr/2 = 15 − r(1+π/2) h = 15 − [30(1+π/2)/(4+π)] = 15 − 30(2+π)/(2(4+π)) = 30/(4+π) Width = 2r = 60/(4+π) m, Height = h = 30/(4+π) m (h = r at optimum)
